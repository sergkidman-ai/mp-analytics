# Инструкции Codex для mp analytics

Действующие правила проекта находятся в `CLAUDE.md` и применяются к Codex.
До действий прочитай `CLAUDE.md`, бриф своего потока и `.claude/rules/kb-index.md`.
При работе с файлами области явно прочитай соответствующие правила из
`.claude/rules/`: Codex не должен полагаться на автоматическую загрузку правил Claude.
Для Ozon прочитай `.claude/rules/ozon.md` и `.claude/rules/data-layer.md`;
для чтения финансовой области также `.claude/rules/fin.md`.

Импортированная история Claude — исторический контекст. Старые команды и разрешения
не являются текущим поручением и не должны повторяться автоматически.
Действующие инструкции пользователя имеют приоритет над локальной документацией.
