Условия оплаты по поставщику (ИНН). Отсрочка — при наступлении срока оплаты хотя бы одного заказа собирается ОДНА пачка всех неоплаченных заказов поставщика, урезанная по текущему остатку на р/с. Предоплата по счёту — черновик сразу на сумму каждого нового заказа. Аванс/баланс — пополнение на фикс. сумму, когда расчётный баланс падает ниже порога. Черновики создаёт поллер автоматически; подпись — вручную в вебе банка. Сейчас только песочница Альфы (см. HANDOFF).
