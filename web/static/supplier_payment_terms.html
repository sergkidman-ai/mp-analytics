⚙️ Условия оплаты

Условия оплаты по поставщику (ИНН). Отсрочка — при наступлении срока оплаты хотя бы одного заказа собирается ОДНА пачка всех неоплаченных заказов поставщика, урезанная по размеру платежа из договорённости (пусто = вся сумма задолженности); заказы, по которым приёмка ещё не проведена, в пачку не идут — ждут приёмки. Предоплата по счёту — черновик сразу на сумму каждого нового заказа. Аванс/баланс — пополнение на фикс. сумму, когда расчётный баланс падает ниже порога. Черновики создаёт поллер автоматически и отправляет в боевой контур банка неподписанными — деньги уходят только после подписи человеком в вебе банка. Условия свои у каждого нашего юрлица: строка Цифрового Квадрата и строка Дисквэра по одному поставщику независимы — переключатель вверху выбирает, чьи условия правишь.
