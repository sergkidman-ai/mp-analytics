По неделям тыс. ₽ · клик по ячейке — из чего сложилось

Прошлые недели — факт по банку. Текущая — факт по сегодня + план до конца недели. Будущие — план; ≈ — оценка (нет документа: среднее, прогноз по графику площадки). «Переводы и неучтённое» — разница остатков банка и операций: переводы со счетов без выписки, сдвиг дат проводки.

Счета и остатки

Альфа и Сбер — остаток по API банка на конец вчерашнего дня. Озон Банк API не имеет: остаток = опорный остаток из выписки + операции загруженных выписок.

Плановые платежи

«авто» — посчитано по факту за 3 месяца и пересчитывается каждую ночь. Правка любой строки делает статью «ручной»: её автоправила больше не создаются. Аренда — из графика аренды (раздел поставщиков), поставщики — из графика оплат + добор до среднего недельного факта, площадки — по их графикам выплат.
