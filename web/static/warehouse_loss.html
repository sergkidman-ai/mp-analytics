Пострадавшие товары ВБ

Официальные отчёты ВБ об утраченном товаре — Цифровой квадрат и Дисквэр. Количество указано в единицах ВБ: набор считается одной единицей. Себестоимость — фактическая по самым поздним подходящим отгрузкам МС до 15.07.2026 включительно (МСК).

При возврате на склад ВБ товар обезличивается. Найденные отгрузки — кандидаты для определения себестоимости; они не доказывают движение конкретной утраченной единицы. Каждая отгрузка используется один раз. Между складами с одинаковым товаром распределение условное — по названию склада. Непокрытые единицы в денежный итог не включены.
