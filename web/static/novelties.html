Строки прайса, которых нет в МойСкладе по артикулу. Сверка ищет тот же товар в нашем каталоге по четырём признакам: модель, цвет, ресурс печати (расхождение до 25% — норма) и чип. Выберите верный вариант или впишите код руками; если такой модели у нас нет вовсе — NEW. Решение принимается по модели картриджа: одна строка флакона тонера — это несколько карточек, по одной на модель, и заводим только те, которым флакон даёт полную заправку. «Спросить сеть» отвечает по каждой модели: рынок РФ, спрос, доза заправки и полный список принтеров — запрос платный, смету покажем до запуска, и спрашиваем только по строкам NEW, тем, которым заводим карточку с новым внешним кодом.

Артикулы, снятые с разбора: в «Новинках» они больше не показываются. Остаток и цена — по последнему загруженному прайсу каждого поставщика; один артикул может лежать у нескольких, тогда он и показан несколько раз. Позиции, которых нет ни в одном свежем прайсе, — фильтр «нет ни в одном прайсе». Кнопка «Вернуть из ЧС» убирает артикул из списка, и со следующим прайсом поставщика строка снова придёт на разбор; карточку в МС это не заводит. Бренд, забракованный правилом (например «ТУ» у Одиссея), возвратом не вернуть — правило поставит его в ЧС снова, о таких предупредим отдельно.
