Яндекс Маркет — сводный отчёт по месяцам

Как читать этот отчёт

Данные из витрины Яндекс.Маркета (Партнёр-API: заказы + отчёт услуг + закрытие месяца) + себестоимость из МойСклад. Оборот = «Оплата покупателя» — от него считаются все % и подсветка. Субсидия Маркета — справочно (доплата за скидку покупателю, отдельными деньгами на счёт не поступает, в деньги/чистую не берётся). Строки — водопад: оборот → минус комиссия, логистика, перевод, продвижение (буст + полки + лояльность), агентское, прочие, подписка → Итого удержания (услуги) → минус возвраты → Итого к перечислению (сверено с ЛК «Подлежит перечислению на счёт Заказчика») → минус COGS → Чистая. Одно юрлицо (Цифровой квадрат) — одна таблица. Столбцы — календарные месяцы. Справа — доля от оборота и тренд. Подсветка — три блока относительно среднего: зелёное = выше среднего (хорошо), янтарное = ниже среднего (обратить внимание), без заливки — норма. Для расходов инверсия (ниже — лучше). Два правых столбца — текущий месяц (оценка) и прогноз на конец месяца, живьём из БД.

выше среднего — хорошо ниже среднего — обратить внимание в норме (около среднего) наша не из отчёта МП (МойСклад) расчёт производная над константами

Все строки — из витрины Яндекс.Маркета (Партнёр-API). Оборот = Оплата покупателя (payment). Субсидия Маркета (subsidy) — доплата за скидку покупателю, показана справочно: отдельными деньгами на счёт не приходит (сверено с ЛК), в чистую не берём. «Итого удержания Маркета» = комиссия + логистика + перевод/эквайринг + продвижение (буст-продажи + буст-показы + полки + программа лояльности и отзывы) + агентское + прочие + подписка (без возвратов). «Итого к перечислению» = Оборот − Итого удержания − Возвраты = ЛК «Подлежит перечислению на счёт Заказчика» (июнь-2026 ≈ 758к, Δ к ЛК <0.5%). Себестоимость — order-based из МойСклад (Σ себест×кол-во по позициям заказа в месяц заказа; сторно возвратов в месяц заказа, кроме склада «Брак»). «Возвраты, шт» = физический возврат товара на склад: товарные возвраты (RETURNED) + невыкупы (покупатель не забрал — товар вернулся на сток), по месяцу возврата (сверено с МС salesreturn, июнь ≈44 ≈ МС 39). Деньги «Возвраты (удержано)» — из закрытия ЛК («Возвращено потребителям»), охватывают все денежные возвраты покупателям и уже включают невыкупы — счётчик (склад) и деньги (касса) намеренно в разных осях. ⚠ Живой месяц Яндекса структурно занижает маржу: COGS списывается в месяц заказа целиком, а выручка/субсидия реализуются по мере доставки — часть заказов ещё «в пути» (несут себест до реализации выручки). Поэтому «тек.» — заниженный факт «пока набрано», а «прогноз» проецирует полный месяц по юнит-экономике закрытых месяцев × ожидаемое число заказов (маржа-прогноз сходится к норме). Данные Ozon и WB — на соседних вкладках.
