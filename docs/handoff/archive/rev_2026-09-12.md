- **Недельный дайджест контентщику и закупщику — влит (`c1dafc3`), таймер стоит.**
  `reports/feedback_digest.py`, `feedback-digest.timer` — понедельник 09:00 МСК (в юните
  `06:00 UTC`: systemd 249 на этой машине не понимает суффикс таймзоны в `OnCalendar`).

  LLM здесь нет и быть не должно: дайджест — счёт по регуляркам, а не мнение.
  Контентщику: ≥2 вопроса одной темы по артикулу (чип / совместимость / комплектация /
  заправка / оригинальность / тип чернил — это НЕ классы `request_class`, там три из них
  слиты в «характеристики»), отзывы «на фото другое», модели принтера из утверждённых «да».

  чёрного продаётся больше всех, и по абсолютному счёту он был бы первым всегда.
