**Знаменатель важен.** У 12 481 карточки acc1 и 3 941 acc2 индекса нет вообще
(`WITHOUT_INDEX` = конкурента Ozon не нашёл). Доля красной зоны считается ТОЛЬКО от карточек
с индексом: **acc1 15.1 %, acc2 30.2 %**. Разведочные 47/48 % из `/v1/rating/summary` —
другая метрика (Ozon там считает по своему кругу товаров), совпадения не ждать.

**Грабли, стоившие первого прогона расчёта:**
- `min_price` в блоке цен — НАША установленная минималка, `min_price` внутри `*_index_data` —
  цена рынка. Разные поля, в таблице разведены.
- `индекс ≠ цена / external_min_price` (проверено: 14890/5161 = 2.9 при индексе 1.41).
  Нужную скидку считать ИЗ ИНДЕКСА: `1 − 1.05/индекс`. Порог 1.05 выведен по нашим же

- `margin_by_sku.qty` для Ozon **не заполнен** (только суммы) — считать в рублях, не в штуках.
- Мост к продажам: `price_index.offer_id → ozon_product.sku → margin_by_sku.article`.
  Прямое `price_index.sku = margin.article` даёт **0** совпадений (product_id ≠ Ozon SKU).

## Юнит-экономика Ozon — проверка 06.08 (СПИСОК НА СНИЖЕНИЕ ЗАМОРОЖЕН)

Источник фактов: `raw_ozon_posting → payload.financial_data.products[]` (поля `price`,
`customer_price`, `payout`, `commission_amount`, `actions`) и `raw_ozon_transaction`.
Считать ТОЛЬКО по строкам `quantity = 1`: `payout` и `commission_amount` — суммы на СТРОКУ,
а `price` — на штуку; при qty>1 отношение payout/price даёт 1.37 вместо 0.59.

**1. Скидка покупателю — деньги Озона, не наши.** Июль, доставленные, qty=1:
выплата = 59 % от НАШЕЙ цены на обоих аккаунтах (комиссия 40–41 %). При этом покупатель
заплатил 57 % нашей цены на acc1 (Озон доплатил 3.42 млн ₽) и 86 % на acc2 (270 тыс. ₽).
Строка-иллюстрация: наша 1158 → покупатель 655 → нам 671.64 (= 1158 − 42 %), `actions` =
«Скидка (за счёт Озон) — AI benefit system», «Льготный период по кредитке Озон Банка».
Механика та же, что СПП на WB (память `project_mp_wb_spp_economics`): наш payout от
покупательской скидки НЕ зависит.

**2. Баллы — 1.6 % выручки, не 20 %.** Июль по транзакциям: `points` (Звёздные товары)
1.6 % на обоих аккаунтах; `subscription` (PremiumMembershipCommission — комиссия за покупку
подписчиком Premium) 2.8 % acc1 / 1.1 % acc2. 20 % — это кэшбэк баллами на стороне покупателя,
его финансирует Озон. Наши реальные статьи: комиссия 40.5 %, реклама 7.6 %, логистика 2.8 %,
эквайринг 0.6 %, партнёрские 1.0 %, штрафы 0.9 %.

**3. Индекс смотрит на цену ПОКУПАТЕЛЯ, а не на нашу** (июль × снимок индекса):
скидка Озона >45 % → средний индекс 0.80, RED 7 % (67 SKU); скидка 25–45 % → индекс 1.02,
RED 31 % (103 SKU). Чем глубже Озон субсидирует, тем лучше индекс.
**Следствие: снижение нашей цены на X % не обязано двигать индекс на X %** — Озон может
снять свою скидку. Рублёвые колонки в `ozon_red_zone.md` — направление, не план.

**Чего не хватает для точного счёта:** цены покупателя по каждому SKU. В `/v5/product/info/prices`
поле `marketing_price` пусто у всех 35 869 карточек; `marketing_seller_price` = 0.969 × `price`
(это наша собственная скидка). Источник искать отдельно — либо другой эндпоинт, либо считать
из постингов (`customer_price`), но там только продававшиеся SKU.

**Мосты (проверено):** `financial_data.product_id` = `ozon_product.sku` (804 совпадения),
а НЕ `ozon_price_index.sku` (0 совпадений — там `product_id` из другого пространства).
Единственный рабочий мост к продажам — через `offer_id`.
