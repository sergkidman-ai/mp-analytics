## Вывоз остатков с Яндекс.Маркета (FBY) — 22.08.2026, ветка `ev/ya-fby-removal`

Повод: с 01.09.2026 Маркет считает хранение от даты поставки (льгота 120 дней для наших
категорий, КГТ 30, одежда 365), дальше 2,5 ₽/л/день (КГТ 0,25) со скидкой 90 %.
Оборачиваемость на цену больше не влияет. Задача Натальи: Маркет подключить к вторничному
списку вывоза, который бот MC_invoice уже шлёт по Ozon FBO.

Сделано:

  available/frozen/defect/expired + turnover_days).

  кампания FBY 21589415. Блокер API не роняет прогон, а печатает, что включить.
- `reports/ya_removal_candidates.py` — кандидаты: льгота кончается (≥ 120−30 дней) или застой ≥60 дней;
  оценка платы за хранение из объёма короба МС.
- `invoice_bot/tg_bot.py` — `ya_removal_report()` + `removal_report_all()`; `/vyvoz` теперь отдаёт
  Ozon и Маркет одним ответом. Вторничная рассылка шлёт оба блока.

- Дневник: задачи #78 (включить доступ к API FBY, срок 26.08) и #79 (вывезти до конца льготы, 01.09).

(business-эндпоинты при этом работают). Включает владелец кабинета: ЛК Маркета → Настройки →
Доступ к API → магазин «Цифровой квадрат» (FBY). До этого блок Маркета в рассылке честно
пишет «данных нет, включите доступ».

Следующий шаг: после включения API — прогнать сбор, сверить список с ЛК, при необходимости
подкрутить пороги (сейчас 120/30/60) и добавить Маркет в дашборд-страницу вывоза.

### Правка 22.08.2026 — проверка фактов по Маркету (Наталья)

Первая версия была построена на неверной предпосылке (FBY). Проверено по API и закрытиям:

- Магазинов в кабинете 8: **FBY «Цифровой квадрат» (21589415) — пустой**, доступ к API у него
  выключен; **семь FBS-магазинов** (Полюстровский экспресс/FBS/наш склад, Москва Звездный/
  экспресс/наш склад/SUP) по API отвечают нормально.
- У каждой FBS-кампании ровно один склад — **наш собственный** (`businesses/{id}/warehouses`,
  campaignId совпадает). То есть остатки FBS = наш склад, вывозить у Маркета нечего.
- **Маркет возвраты у себя не держит** — везёт нам на ПВЗ. Услуга «Хранение невыкупов и
  возвратов» за всю историю = **630 ₽** (15 ₽/шт: 28 строк 01.2026, 8 — 06.2026, 6 — 07.2026),
  в августе ноль. Против 466–633 тыс. ₽ услуг Маркета в месяц это шум.
- Возвраты уже собирает поток `ret` (`returns_bot/sources/yandex.py` → `mp_returns`): 426 «забран»,
  сейчас 1 готов к выдаче (до 05.09), 1 «потерян» с 29.04, 9 в пути, 1 в утилизации с 22.12.2025.

Что переделано:
- `migrations/508_ya_mp_stock.sql` — `ya_fby_stock` → `ya_mp_stock` + `placement`, `campaign_name`.
- `collectors/yandex_stocks.py` — сбор по ВСЕМ магазинам из `GET /campaigns` (новый подхватится
  сам), FBY с выключенным API пропускается с пометкой.
- `reports/ya_removal_candidates.py` — блок Маркета теперь про то, что реально стоит денег:
  забрать с ПВЗ (со сроком), «разобраться» (потерян/утилизация), плата за хранение за последний
  месяц как сторож, и вывоз с FBY — только если товар там появится.
- Дневник: #78 понижена (включить API FBY на будущее, срок 01.10), #79 переформулирована —
  следить за возвратами и забирать до просрочки (срок 05.09).
