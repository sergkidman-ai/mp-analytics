## Где работаю
- Ветка `gab/dims`, worktree `.claude/worktrees/gab` (`venv` и `.env` — симлинки на общий чекаут).
- **Модель сессии: Sonnet** (сбор, прогоны, сводки). Opus — только вердикт по методу или спорному
  источнику. Модель выбирается на старте и по ходу не меняется.
- Общий чекаут `/opt/mp-analytics` сейчас на чужой ветке. Переключать его нельзя:
  30.07 такой switch убил идущий прогон харвестера.

## Зона ответственности
Габариты (Д×Ш×В) и вес товарных карточек на ВБ и Ozon: поиск реальных замеров, их сверка,
подтверждение независимым валидатором и — только по прямой команде Сергея — запись на площадку.
Плюс расследование заниженных/завышенных коробов и штрафных рисков ВБ.

## Границы
Read-only: `raw_wb_*`, `raw_ozon_*`, витрины маржи (потоки fin/mkt). Писать в них нельзя.
`tools/territory_guard.py` — общий: на ветках `gab/*` печатает «домен сессии не определён», но
коммит пропускает. Добавление домена `gab` — предложено, не сделано, нужен владелец файла.

## Запреты потока
1. **Никаких оценок, медиан, прокси и коэффициентов вместо замера.** Только реальные габариты
   с явным источником. Синтетика один раз уже ушла на ВБ и была откачена целиком.
2. **CONFIRMED ставит только независимый валидатор**, не сборщик.
3. **Отправка на ВБ / Ozon / Яндекс — только по прямой команде Сергея на конкретную пачку.**
4. **Платные ресурсы (Icecat Full, `web_search` релея) — заморожены** до решения Сергея
   (CLAUDE.md, правило 13: смета до запуска, молчание согласием не считается).
5. Мастер-короба (объём > 25 л) в загрузку не пускать — фильтр по абсолютному объёму.

## Состояние на 2026-07-30
- **Метод «габариты с карточек конкурентов ВБ» — ЗАКРЫТ.** Слепая калибровка 300 моделей против
  эталона из 1141 (отчёт `docs/reports/17_kalibrovka_harvestera_wb_2026-07-30.md`):
  через фильтр редкости прошло 85 моделей, 57 из них (67 %) не бьются с эталоном; на массовке
  попадание 3 %, медианная ошибка объёма 58 %. 121 модель в покрытие НЕ идёт, 431 модель
  дефолтной массовки (2,2 млн ₽) — отказ. Возобновлять направление не нужно.
- Эталонная база собрана и переиспользуема: `docs/web_search_v2/calibration/calibration_truth.csv`,
  1141 модель (216 консенсус ≥2 чистых поставщиков, 915 замер SolutionsPrint, 10 паспорт Icecat).
  Сборщик — `tools/gab_calibration_set.py`, годится как источник покрытия сам по себе.
- Solutions Print: 6004 строки с габаритами в `supplier_dims`, 742 из 808 подтверждены по названиям.
  Остальные чистые поставщики: cactus 3939, изи 2040, sakura 1446, rapid 2030 (грязный — сборка
  со стороннего API, в эталон не берётся), profiline 0.
- Хвост отката синтетики закрыт: 124 карточки добиты и подтверждены перечиткой 124/124;
  23 без оригинала не тронуты.
- Заниженные габариты: 999 из 1969 карточек отобраны в волну 1 (≤12 л). 601 карточка «К загрузке»
  оказалась мастер-коробом (до 535 л) — отфильтрованы.
- ВТТ (`b2b.vtt.ru`) и Булат закрыты для габаритов: размеров короба на сайтах нет
  (`docs/VTT_B2B_RECON.md`).
- Ozon: правка габаритов идёт минимальным payload `/v3/product/import` (категория + тип + Д×Ш×В),
  не всей карточкой.
