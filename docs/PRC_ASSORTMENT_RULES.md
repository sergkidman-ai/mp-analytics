# Ассортимент в прайсах поставщиков

Поток: prc. Восстановлено 06.11.2026 по обращению о мониторах и воздушных фильтрах в «Новинках».

Общий фильтр `prices/assortment.py` применяется к каждому поставщику до поиска карточек МС, расчёта загрузки и сбора новинок. Отдельные ограничения категорий поставщиков действуют дополнительно: у Кактуса сохраняется существующий список разрешённых категорий и исключений.

Разрешены готовые расходники для печати: картриджи, тонер и чернила, фотобарабаны, девелопер, ёмкости отработки, ленты, печатающие головки, СНПЧ, сервисные комплекты и блоки переноса/проявки/закрепления, фьюзерное масло, наборы для заправки и печати. Набор для печати с картриджами и бумагой сохраняется. Совместимость с принтером или МФУ в названии не превращает расходник в оборудование. Объём тонера/чернил сам по себе не ограничивается.

Исключаются оборудование (включая игровые и офисные мониторы, принтеры, МФУ, проекторы), экраны, воздушные и другие посторонние фильтры, аксессуары проекторов, отдельная бумага, крепления, кабели, чипы и ремонтные запчасти, ПЗК и промывочная жидкость. Неизвестный тип без подтверждённой разрешённой категории поставщика не считается новым картриджем. Категория не отменяет явный запрет оборудования.

При выборе почтового вложения считаются строки разрешённого ассортимента с положительным остатком; сохраняется приоритет актуального дня. Смешанный прайс проходит построчную фильтрацию. Файл без разрешённых строк не запускает поиск МС и не применяется как пустая загрузка остатков.

Дополнительные проверки стоят на входе очередей «Новинки» и «Несопоставлено». При передаче новинок сохраняются группа/подгруппа исходного прайса для проверки разрешённой категории. Исключения из существующей очереди архивируются вместе с решениями и кандидатами в `prc_assortment_excluded`; глобальный чёрный список артикулов для этого не используется. Ручной возврат из архива требует проверки исходного прайса и вида товара.

Эта правка не меняет карточки/документы МС и данные маркетплейсов. Штатные следующие загрузки используют восстановленный отбор.
