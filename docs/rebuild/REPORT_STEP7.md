## 4. Разведка по nix.ru — НЕ ВЫПОЛНЕНА, сайт с этого сервера недоступен

Ни одна из 10 карточек не открыта, разведочных выводов о разметке nix.ru у меня нет, и придумывать их я не буду.

| Дата | Что пробовал | Ответ |
|---|---|---|
| 31.07 | `/`, `/price/price_list.html`, `/search/?q=CE285A`, `/robots.txt` — curl | 302 → `www.nix.ru/vpnerr.html`, тело пустое |
| 31.07 | тот же адрес через WebFetch | пусто |
| 01.08 | `https://www.nix.ru/`, `https://nix.ru/`, `http://.../robots.txt` — curl и urllib | TCP-отказ: `91.233.230.52:443 connection refused` |

Наш egress-IP `155.212.189.66` сайт относит к VPN/датацентру (заглушка так и называется — `vpnerr`), сейчас соединение рвётся уже на уровне TCP.
Обход не искал: маскировка под другой IP — это обход блокировки, на такое нужна ваша команда.

**Проверил вместо nix** (только доступность и наличие блока габаритов, 8 запросов с паузой 3–4 с, никуда ничего не писал):

| Площадка | Доступ | Габариты упаковки |
|---|---|---|
| `regard.ru` | открывается, поиск по артикулу работает (`/catalog?search=CC388A` → 27 ссылок `/product/`), Next.js c `__NEXT_DATA__`, есть sitemap | **нет.** В карточке `/product/179011/kartridz-cactus-cs-cf381a-cyan` только «Количество в упаковке» |
| `dns-shop.ru` / `citilink.ru` / `onlinetrade.ru` | 401 антибот / 429 / 1.5 КБ JS-заглушка, sitemap 404 | не проверить |
| `openapi.icecat.biz` | соединение не устанавливается | — |
| `nvprint.ru`, `hi-black.ru`, `colortek.ru` | главные 200, поиск на JS — карточку одним GET не достал | не проверил |

**Вывод прямой.** Через nix история нерабочая — не из-за разметки, а из-за доступа. Розничные площадки как класс сомнительны: у regard, единственного
открывшегося целиком, габаритов упаковки в карточке нет вовсе, и это типично — магазину нужны вес и «шт в упаковке», а не короб.

**Где данные лежат машинно-читаемо, по убыванию дешевизны.** (1) **Прайсы брендов, которых у нас нет.** Веб-пачка — это в основном NV Print,
Colortek, Blossom, S'OK, GP: чужие бренды, а не «нет данных в природе». У cactus/sakura/izi габариты пришли колонкой в прайсе — значит есть и
у остальных; один запрос менеджеру за выгрузкой с ДхШхВ закрывает сотни моделей и даёт указатель того же качества (файл+лист+строка+sha256),
денег 0. (2) **Сайты этих брендов** — с сервера открываются, нужен короткий заход: есть ли на карточке блок размеров и берётся ли она одним GET.
(3) **Платные каталоги** (Icecat Full, 1С:Номенклатура) — правило 13, только с вашего «да» на конкретную сумму. (4) **Ваш браузер**
(`claude-in-chrome`, резидентный IP) — nix, вероятно, откроется, но это ручной канал: парсер снова упрётся в IP сервера.

**Цена сбора 3000 моделей парсером**, если источник найдётся: 2 запроса на модель ≈ 6000 запросов, пауза 3 с в один поток ≈ 5 часов, трафик ~5 ГБ,
денег 0, модель в разборе не участвует. Узкое место не цена, а доступ и наличие блока габаритов.
