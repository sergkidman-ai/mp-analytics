**Гипотеза подтверждается, но не на том поле.** В МС три кандидата, проверены все три:

`article` — это обычно сам код поставщика (`BS-X106R03694`, `NV-TK450`), структуры не несёт; структура
«4 цифры + окончание» живёт в **`code`** (`2345bs`), `external_code` — та же основа без окончания
(37 905 таких значений). Дальше «наш артикул» = `ms_product.code`.

**1.** Подходят 36 429 из 37 225 (97.9 %). Не подходят **796**: 631 — вид «4 цифры + окончание, начинающееся
с цифры» (`00357q`, `10497q`, `54077q` — бренд 7Q; правилу не отвечают, но основа читается); 155 — не
начинаются с цифры: `CN055AE`, `PFI-107C`, `PG-445XL`, `MRV-TH-B2050`, `wb7lcevdr4`, `3261-or`, `TBH 0101 TC`.

**2.** Окончаний **68**; только 4 цифры без окончания — **296** товаров. Полный список с частотой —
`data/step3_stats.json`. Топ-12: `cs` 4141, `sp` 3470, `bs` 3083, `ct` 2547, `pl` 2045, `sf` 1912, `sk` 1833,
`wb` 1527, `gp` 1495, `nv` 1399, `hb` 1253, `sg` 1211.
