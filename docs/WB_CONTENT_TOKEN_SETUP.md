# Токены WB «Контент» с записью — для правки габаритов карточек

> Зачем: массовая правка ДхШхВ карточек через WB Content API (`cards/update`). Текущие токены
> `WB_TOKEN_ACC1`/`WB_TOKEN_ACC2` дают **401 «token scope not allowed»** — у них нет категории
> «Контент» с правом записи. Нужны ОТДЕЛЬНЫЕ токены (нынешние не трогаем — на них висят статистика/цены).
> Поток: gab. Блокер снят, когда обе строки ниже появятся в `.env`.

## Шаг 1. Создать токен в каждом кабинете (по отдельности)

Кабинеты разные — заходить в каждый под своим логином:
- **Цифровой квадрат** = `wb_acc1`
- **Дисквэр** = `wb_acc2`

В ЛК каждого продавца:
1. **Настройки → Доступ к API** (Профиль → Настройки → Доступ к новому API).
2. **Создать новый токен**. Имя любое, напр. `mp-analytics-content`.
3. Категория — отметить **«Контент»**.
4. ⚠️ **НЕ ставить галку «Только на чтение»** (и не «Тестовый контур»). Именно она резала запись.
5. Сгенерировать → **скопировать JWT сразу** (показывается один раз).

## Шаг 2. Внести в `.env` (секрет — редактируем В СВОЁМ терминале, НЕ через чат)

⚠️ **Не вставлять токен в окно Claude и не делать `echo "...=токен" >> .env`** — так он попадёт в историю
команд и в лог. Редактируем редактором `nano` в собственном SSH-терминале.

1. Подключиться к серверу по SSH (свой терминал, не окно Claude):
   ```
   ssh <пользователь>@<сервер>
   ```
2. Перейти в проект:
   ```
   cd /opt/mp-analytics
   ```
3. Открыть `.env` в nano БЕЗ переноса строк (важно — токен должен быть одной строкой):
   ```
   nano -w .env
   ```
4. Стрелкой вниз (или `Ctrl+End`) спуститься в САМЫЙ низ файла, с новой строки вписать/вставить
   (вставка в терминале — обычно `Ctrl+Shift+V` или правая кнопка мыши):
   ```
   WB_TOKEN_CONTENT_ACC1=<сюда JWT из кабинета Цифровой>
   WB_TOKEN_CONTENT_ACC2=<сюда JWT из кабинета Дисквэр>
   ```
   Проверить: **никаких пробелов** вокруг `=`, токен **одной строкой** (не разорван переносом), кавычки не нужны.
5. Сохранить и выйти: `Ctrl+O` → `Enter` (записать), затем `Ctrl+X` (выйти).
6. Ужать права файла (сейчас 644 → надо 600):
   ```
   chmod 600 /opt/mp-analytics/.env
   ```
7. Проверить, что строки на месте (покажет только ИМЕНА, без значений):
   ```
   grep -oE '^WB_TOKEN_CONTENT_ACC[12]=' .env
   ```
   Должно вывести две строки `WB_TOKEN_CONTENT_ACC1=` и `WB_TOKEN_CONTENT_ACC2=`.

## Шаг 3. Сказать в сессии gab

После этого я:
1. Подключу резолвер к новым переменным (запись габаритов идёт через `WB_TOKEN_CONTENT_ACC{1,2}`,
   остальные вызовы — через прежние `WB_TOKEN_ACC{1,2}`).
2. Проверю скоуп реальным `cards/update` в **dry-run** (без изменений).
3. Прогоню правку батчами: **лог до/после каждой карточки + возможность отката**, начиная с 3 дефолтных
   шаблонов (①②③, 633 карты / 78 538 ₽/мес — главный рычаг).

## Проверка (после внесения)

Скоуп подтверждается только реальным вызовом `cards/update` (бит read-only в JWT врёт — так уже
обожглись на пилоте 15 карт). Поэтому первый шаг после токенов — dry-run одной карты на каждом аккаунте.
