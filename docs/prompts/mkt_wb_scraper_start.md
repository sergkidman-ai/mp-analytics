# Старт сессии: скрепер конкурентов ВБ (поток mkt)

Прочитай CLAUDE.md и docs/BRIEF_MKT.md — и больше при старте ничего.

## Задача
Построить сбор публичной поисковой выдачи Wildberries по нашим моделям картриджей, чтобы понять,
где мы сильны и где держать маржу выше. Курс Сергея: ниша комплектов, наборов и редких позиций,
высокая маржа важнее объёма, гонку бюджетов не устраиваем.

## Что уже известно (проверено 18–19.09.2026)
- Публичный поиск работает без ключа и бесплатно: `https://search.wb.ru/exactmatch/ru/common/v14/search`
  (параметры appType=1, curr=rub, dest=<регион>, query, resultset=catalog, page, sort=popular, spp=30).
  v18/v9/v5 отвечали 429, v14 и v7 — 200. Товары лежат в `products` (или `data.products`).
- Пилот 40 запросов по нашим прибыльным моделям: 26–74 продавца-конкурента на модель, мы чаще дороже
  медианы, но продаём, иногда с 1-го места. Сравнивать «модель с моделью» нельзя: в выдаче по W2070A
  лежат и одиночные картриджи, и чипы за 117 ₽. Нужно сопоставление ТОГО ЖЕ товара.
- Цена покупателя и остаток карточки — публичный `card.wb.ru/cards/v4/detail` (им уже пользуются
  collectors/wb_market_price.py и ops/wb_ad_enroll.live_stock). С того же IP сервера — не перегружать.
- Наши карточки: raw_wb_card_content (свежий); wb_cards_live — для acc1 НЕ обновляется (дыра, см. бриф).
- Склад стоит 67 ₽ на заказ; маржа-KPI 25 % от нашей промо-цены.

## Этапы
1. Сбор: collectors/wb_search_scrape.py → таблица wb_search_snapshot (миграция потока mkt, номер 1xx).
   Первая страница выдачи: позиция, nm_id, продавец (supplierId, supplier), бренд, название,
   цена после СПП, рейтинг, отзывы, наличие; время снимка и регион. Темп не выше 1 запроса в 3 с,
   пауза при 429, суточный лимит. Сначала 200 топ-моделей × 3 региона × 2 раза в день (~1 200 запросов).
2. Сопоставление «тот же товар»: модель, объём (std/XL/X/H), цвет, количество в бандле, комплект целиком.
3. Сигналы: где мы одни или почти одни с товаром в наличии; у кого из конкурентов пропало наличие
   или упала позиция; где наша позиция хуже по региону или времени суток. Сводка раз в неделю
   в PRC-бот (функция tg в ops/mkt_margin_watch.py).
4. Новые принтеры: модели принтеров из названий конкурентов, которых нет в наших названиях —
   список кандидатов для потоков цен и карточек.

## Ограничения
- Только чтение публичных данных. Никакой записи на ВБ (инвариант 6).
- Платные сервисы (MPSTATS и пр.) — только по «да» Сергея с суммой (инвариант 8).
- Прокси, смену IP, обход антибота не использовать без решения Сергея.
- Вывод команд ≤50 строк, данные — в файлы (инвариант 9). Ветка — в своём worktree (инвариант 10).

## Вопросы Сергею перед запуском по расписанию
1. Согласие собирать с IP сервера (риск ограничения IP ВБ, с него же ходят наши сборщики цен).
2. 3–5 регионов для старта.
3. Известные конкуренты, за кем следить в первую очередь.
4. Правило «мы одни — держим выше»: предложение — тест +10 % цены на 20 позициях с контролем 20.
