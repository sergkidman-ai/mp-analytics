## Порядок работы — что уже выполнено и проверено
1. «Оборот для премии»: `web/turnover_api.py`, `web/static/turnover.html`, регистрация в `web/app.py`, ссылки в меню. `/turnover` и `/api/turnover?months=6` дали HTTP 200 и шесть месяцев.
2. Графики: общая сумма и Ozon/ВБ/Маркет; переключатель «Оборот / Средний чек / Кол-во заказов». Средний чек = продажи ДО возвратов / количество. ВБ считает уникальные `srid` выкупленных позиций, Ozon — короткие номера заказов по положительным начислениям, Маркет — `order_id` положительной revenue. Это разные единицы; общий средний чек требует этой оговорки. Отсутствующие идентификаторы не заменяются нулём.
3. Проверены синтаксис JS, построение всех трёх графиков на реальных данных без NaN, поля количества/среднего чека в API.
4. Суточный кэш: ключ — число месяцев (1–24), срок — календарный день UTC, в памяти процесса с lock. Первый запрос за день/период выполняет семь запросов к БД, повторные используют кэш. После рестарта кэш пуст. Переключатели работают локально; фонового опроса страницы и запросов к API МП при открытии нет. Проверены повторное использование `calculated_at` и пересчёт при смене дня; время показано в Москве.
5. Код закоммичен и запушен: `0ad6a84` — раздел; `ac19223` — графики/меню (публикация merge `61d75a1`); `a772927` — суточный кэш (публикация merge `d446bea`).
