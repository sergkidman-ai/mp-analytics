## Авторизация (Laravel + Inertia.js/Vue)
- Форма рисуется JS (`/build/assets/app-*.js`), статического `<form>` нет.
- Логин: `GET /login` (сеет куки `XSRF-TOKEN` + `b2bvttru_session`) → `POST /validateLogin`
  form-data `login,password,remember` + заголовок `X-XSRF-TOKEN` (urldecode куки) + `X-Requested-With: XMLHttpRequest`.
  Успех: `{"result":true,"location":"https://b2b.vtt.ru"}`. Сессия живёт 6ч (Max-Age 21600).
- `POST /login` НЕ существует (405) — только `/validateLogin`. Выход: `POST /logout` c `_token`.

## Каталог
- URL: `/catalog/?category=КОД` — server-side рендер, товары в HTML (блоки `catalog_list_row`).
- Параметры: `onPage=100` (размер стр), `page=N`, `sort=price&sortOrder=asc`, `word=` (поиск по назв/арт), `view=list`.
- **Фильтр совместимости (ГЛАВНОЕ):** `notOriginal=1` = только совместимые; `onlyOriginal=1` = только оригинал.
- Счётчик: «Найдено N позиций».

### Поля товара (в списке)
`data-id`=код/артикул поставщика · `data-name`=полное название · `data-translit` · `data-img=/images/{code}.jpg` ·
остаток: `item_box_num` (кор.), `item_local_num` (локальный склад), `item_local_days` (срок) · наличие чипа · склад Москва.
Цена — за модалкой `#modal-price-*` («Цена?»), не в списке. Отдельных страниц товара нет (`/product/{code}` → 404).
Тип в названии: «Копи-картридж / Принт-картридж / Тонер-картридж …», маркер `(O)` = оригинал.

### ⚠ Габаритов/веса НЕТ
Ни в списке, ни в data-атрибутах (`data-id/name/img/days/cartid/amount/incart`) физических размеров/веса нет.

## Массовая выгрузка (эффективнее скрейпа)
Страница `/price-list` отдаёт готовые файлы:
- `/prices/<hash>/vtt.main.price.rub.xls.zip` (рубли)
- `/prices/<hash>/vtt.main.price.usd.xls.zip` (доллары)
Форма фильтрует: `brands[]`, `category`, `subcategory`, `spareCategory`, `spareModel`, `support-type`, `word`, `sort`.
Hash в пути привязан к сессии/аккаунту.
