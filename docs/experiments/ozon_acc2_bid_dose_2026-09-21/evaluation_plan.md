## Первичный анализ

1. DiD: `log(1+показы) ~ плечо × период + FE SKU + FE день`, плечи L и H против C.
2. Эластичность: наклон `log(показы)` по `log(ставка/ставка_до)` по фактической ставке SKU
   (L — log 2; H — log(ставка/8)).
3. Интервалы — бутстрэп по семьям (1 000 повторов), 90 % CI.
4. То же для кликов; CTR, CPC/ставка, доля SKU-дней с 0 показов — вторично.

Выбывшие SKU (не принятая API ставка, S3–S6) анализируются по назначенному плечу (ITT) и
отдельно по фактической ставке; в holdout не добавляются.

## Критерии перехода к 14/28-дневному тесту (все сразу)

1. Показы H ≥ 3× и L ≥ 1,5× к pre относительно holdout (медиана SKU); эластичность > 0, 90 % CI без 0.
2. CPC ≤ безопасной ставки в ≥ 90 % SKU-дней с кликами; CPC/ставка ≤ 1,15.
3. Ни одного S1/S2; S3–S5 — не более чем у 2 SKU.
4. Расход 4 дней ≤ 760 ₽; нет роста отмен и смены цен у treatment.

Не выполнено хоть одно — стоп, rollback, теста нет. Доза следующего теста: L, если клики L ≥ 50 %
кликов H при CPC ≤ 0,8 × безопасной; иначе H. Следующий тест — отдельный контракт и согласование.
