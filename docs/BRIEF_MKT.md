### Что мешает включить заводчик (разведка API 25.08)
- `POST /adv/v2/seacat/save-ad` **СОЗДАЁТ кампанию**, а не правит состав — прежняя запись в брифе
  была неверной. Правка состава — `PATCH /adv/v0/auction/nms` (405 на GET, `Allow: PATCH`).
- **Форма тела PATCH не подтверждена**: `{"advertId":…,"nms":[…]}` → 400 «can not deserialize
  response body». Перебор форм заблокировал классификатор Claude Code — нужно либо разрешение
  Сергея на сверхлимитные пробы (>50 номенклатур, применить не могут), либо форма из документации
  ВБ (`dev.wildberries.ru` с этого сервера недоступен, HTTP 498).
- **Геттера состава кампании у ВБ нет** — все `/adv/v1|v2|v3/promotion/adverts` дают 404 на обоих
  токенах. Наша оценка состава (`wb_ad_nm` ∪ `wb_bid_override`) — нижняя граница, поэтому в коде
  запас 5 номенклатур до лимита 50.
- **Ответы контура приходят из общего кэша ВБ** (`origin: camp-api-public-cache`) и один раз пришёл
  ответ про ЧУЖУЮ кампанию 33614302, которой у нас нет. Текст ответа не доказательство — состав
  после записи проверять отдельно.
- Рабочие методы разведки: `POST /adv/v2/supplier/nms` тело `[subjectId]` → 200 (acc2 14 441
  карточка доступна для кампаний), `GET /adv/v1/supplier/subjects` → 200.
- Лимит ВБ: **не более 50 номенклатур** в аукционной кампании.

## Рой — недельный движок ставок
Крон `12 8 * * 1` (пн 11:12 МСК) → `ops/wb_roy_weekly.sh`, оба аккаунта.
Правила: 🟢 +10 % · 🔴 −10 % · 🟤 в пол · ⚫ вывод в пол · 🟡 не трогаем.
Константы: пол 7.30 ₽, потолок 25 ₽, шаг +10 %, срез 0.90. Зелёным считается только позиция,
у которой ДРР профиля ниже СВОЕГО потолка (маржа − 25 %).
Карантин посева: `SEED_GRACE_DAYS = 14` — карточки `author='seed'` Рой не трогает 14 дней.
Авторы в `wb_bid_log`: `ladder`, `lower`, `roy`, `roy-rollback`, `seed`, `stock-guard`.

## Грабли, за которые уже заплатили
- **`wb_price.market_price` — НЕ цена рынка**, а наша собственная цена после СПП
  (см. docstring `collectors/wb_market_price.py`). Реальный рынок только из SERP-снимков
  `tools/core_<ГГГГММДД>_detail.csv` (крон `40 22 * * *`).
- **`wb_stocks` — FBO-only** и не является признаком доступности: карточка может продаваться
  с ФБС при нулевом FBO. Правда о наличии — `totalQuantity` с публичного card.wb.ru.
- Рабочие ФБС-склады в `supplier_stock`: `Удаленный склад`, `Звездный`, `Дисквер`.
- Мост карточка ↔ МойСклад: первые 4 цифры `vendor_code` → `ms_product.external_code`.
- Молчание card.wb.ru нельзя читать как «остатка нет» — иначе сторож уронит ставки в пол
  на ровном месте. Неответившие батчи пропускаем.
- Коррелированные подзапросы к `supplier_stock` по каждой карточке вешают прогон на 15 минут —
  агрегировать одним проходом (CTE по `ms_id`), а не подзапросом на строку.
- Недельные ряды сравнивать только одинаковыми днями недели (пн–чт к пн–чт).

## Параллельная работа (worktree-изоляция)
Общий чекаут всегда на `main`, ветку здесь не переключать. Работа в ветке — только в своём worktree:
```bash
git worktree add .claude/worktrees/mkt-<задача> -b mkt/<задача> origin/main
cd .claude/worktrees/mkt-<задача> && echo mkt > .workstream
```
