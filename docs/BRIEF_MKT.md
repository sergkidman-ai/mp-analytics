**Маржа-гейтед вид — ГОТОВ (2026-08-04), это основной полезный режим вкладки:**
- Причина: сортировка по позиции Джема бесполезна для решений; статистики per-SKU для микро-оптимизации
  ставок нет (0 SKU с ≥3 заказами/мес, ДРР общий 4.5% — реклама маржу не ест). Инструмент развёрнут
  под стратегию Сергея: маржа-гейт 25% (KPI от нашей цены) + потолок ДРР 10% (задан Сергеем).
- `GET /api/wb-bids?mode=margin` (по умолчанию) → `_margin_gated()`: решение по КАЖДОМУ рекл. SKU.
  **МАРЖА-ГЕЙТ = ЖИВАЯ** (`mkt_margin_control`, SELECT-only, `margin_own_live`): текущая цена × себест
  «купим сегодня» (TheCartridge). Помесячную `margin_by_sku` как гейт НЕ используем — реклама крутит
  сегодняшние цены, а помесячная маржа врёт на тонких месяцах (216421567 июль qty=1 → −22%, живая +34%).
  ГРАБЛИ: в `mkt_margin_control` ~14× дублей строк (166978/11927 уникальных) → джойн через
  `DISTINCT ON (nm_id)`, иначе всё размножается. `buy_status` no_price/unmapped → маржу не судим (⚪).
  `margin_by_sku` (SELECT-only, `article=nm_id::text`) остался ТОЛЬКО для флага «продавался» (⚫ dead).
  Рекл. агрегаты (spend/rev/clicks/orders → ДРР, CPO) — за ПОСЛЕДНИЙ ПОЛНЫЙ месяц (`_decision_period`;
  август MTD тонкий) + свежий Джем (позиция справочно).
- Вердикт `_verdict(sold,mp,drr,spend,ad_orders,repriced)`: 🟢 grow (маржа≥25 + реклама конвертит + ДРР<10 →
  поднять ставку) · 🟡 expensive (маржа ок, ДРР≥10 → вниз) · 🔵 keep (маржа ок, 0 рекл.заказов, цена ~прежняя
  → держать на полу) · 🟣 repriced (маржа ок, 0 рекл.заказов, но цена ≥25% ВЫШЕ той, по которой продавался —
  активность была из-за низкой цены → тест рекламой + смотреть склейку, не пойдёт — снять) · 🔴 cut
  (продаётся, маржа<25 → снять/поднять цену) · ⚫ dead (0 продаж/окно, реклама жгла → редкий-держим/снять)
  · ⚪ hold (нет сигнала).
- **Окно активности 3 мес** (`WB_ACTIVITY_MONTHS`, май–июль): продавался = qty>0 за окно (не только decision-мес).
- **Флаг repriced с порогом qty** (`WB_REPRICE_MIN_QTY=5`): дрейф = our_price(live) / (rev3/qty за окно). Базис q3<5
  = шум (продалась 1–2 шт по «кривой» цене возврата → дрейф +1000% мусор) → НЕ флагуем, уходит в keep.
  Из ~650 дрейф-кандидатов надёжных (q3≥5) только 79.
- **Склейка подмешана** (`raw_wb_card_content.payload->>'imtID'`): колонка ⛓ размер + продажи СОСЕДЕЙ за окно
  (`sib_q`). Сигнал: repriced с живой склейкой (соседи продают) — склейка вытянет, держим; мёртвая — снимаем.
- **⚠ Живая цена была ПРОТУХШЕЙ (снимок 20.07, разбор 2026-08-04 по 216448553):** в cron гонялся только

## Параллельная работа (worktree-изоляция)
Сессии идут одновременно — работай в СВОЁМ git worktree и доменной ветке:
```bash
git worktree add .claude/worktrees/mkt -b mkt/<задача> origin/main
cd .claude/worktrees/mkt && echo mkt > .workstream
```
Имя ветки `mkt/*` включает флаг территории автоматически.

## Флаг чужой территории
Активен git-хук (`tools/hooks/pre-commit` → `tools/territory_guard.py`). Правки ЧУЖИХ файлов из
ветки `mkt/*` блокируются с пояснением. Самопроверка:
```bash
python3 tools/territory_guard.py --status
```
Осознанный обход: `WORKSTREAM_OVERRIDE=1 git commit ...`.
