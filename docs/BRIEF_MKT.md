## Рекламная стратегия (что поднимаем, что опускаем)
Крон `12 8 * * 1` (пн 11:12 МСК) → `ops/wb_roy_weekly.sh`, оба аккаунта, автор `roy`.
Правила: 🟢 +10 % · 🔴 −10 % · 🟤 в пол · ⚫ вывод в пол · 🟡 не трогаем. Константы: пол 7.30 ₽,
потолок 25 ₽, шаг +10 %, срез 0.90, `--max-up 0` = без ограничения, `SEED_GRACE_DAYS = 14`.
Зелёной считается позиция, у которой ДРР профиля ниже СВОЕГО потолка (**маржа − 25 %**): маржа
30 % → потолок ДРР 5 %, 60 % → 35 % — чем прибыльнее, тем агрессивнее.
Сторож остатка (`ops/wb_stock_guard.py`) симметричен: нет живого `totalQuantity` → в пол, вернулся →
ТА ЖЕ ставка из `old_cpc`. Авторы `wb_bid_log`: `ladder, lower, roy, roy-rollback, seed, stock-guard`.
**Разница аккаунтов в материале, не в правилах:** acc1 1 799 SKU со ставкой (998 на полу), acc2 380
(96). **Две дыры:** нет правила по марже («маржа < 0 → пол + `delete`») и нет холдаута — правила
крутятся без контрольной группы, то есть их эффект до сих пор не подтверждён ни одним замером.
