## Параллельная работа (worktree-изоляция)
Так как сессии идут одновременно — работай в СВОЁМ git worktree и доменной ветке:
```bash
git worktree add .claude/worktrees/fin -b fin/<задача> origin/main   # или из текущего main
cd .claude/worktrees/fin && echo fin > .workstream
```
Имя ветки `fin/*` включает флаг территории автоматически.

## Флаг чужой территории
Активен git-хук (`tools/hooks/pre-commit` → `tools/territory_guard.py`). При коммите правок ЧУЖИХ
файлов из ветки `fin/*` — коммит блокируется с пояснением. Самопроверка в любой момент:
```bash
python3 tools/territory_guard.py --status
```
Осознанный обход: `WORKSTREAM_OVERRIDE=1 git commit ...`.

## Этап «себест реализации» 13–16.08 — СДЕЛАНО (детали: `docs/handoff/archive/fin_cogs_realized_2026-08.md`)

Ветка `fin/cogs-realized` влита в `main` (`a8dee8e`), статика — `ad27123`, всё запушено.

**1. FIFO вместо `cost_seb`.** Единственный источник себеста отгрузки — FIFO; `products.cost_seb`
(средняя по остатку карточки МС) себестоимостью списания не является. Модуль
`reports/fifo_fallback.py` (`unit` / `unit_ms` / `impute`) подключён в три коллектора `*_cogs_demand`,
`web/app.py`, `margin_by_sku`, `margin_ozon_sku`. Ozon янв–июл: COGS −353 669 ₽.

**2. Связи универсальных моделей (`analog_fifo`).** Один картридж продаётся под разными кодами
(Q2612A = Canon 703). Связи — `prc_tc_link` (поток **prc**, миграция 408, read-only для нас); шаг
`analog_fifo` в цепочке товар → набор → аналог, из кандидатов берём максимальный себест, без
миграции 408 работает как раньше (`to_regclass`). Денежный эффект = **0 ₽ и это правильно**: выше
стоит `cpu_hist` (факт FIFO по истории того же nm), 140 из 141 позиции. Шаг — страховка для нового
SKU, проданного по FBO раньше первой своей отгрузки. Отложенный пересчёт хвоста закрыт 14.08 **без
прогона**: `imputed` в закрытых месяцах = 0 строк (с 14.08 суррогат метится `need_manual`), dry-run
по 8 `need_manual` не дал себеста ни по одной. Δ = 0 ₽, заморозку не трогали.

**3. Себест только «до даты отгрузки»** (правило Сергея, коммит `0d8927e`). Цена из будущего
запрещена. Чинили два места: `fifo_fallback._by_ms` больше не берёт «первую ПОСЛЕ» (возвращает
`None`, управление идёт дальше по цепочке); `margin_by_sku._fallback_sources` (`cpu_hist`) режет
историю параметром `before` = первый день собираемого месяца (раньше пересборка января подставляла
цену августа). Пересобран весь 2026 (8 мес × 4 аккаунта): COGS **+25 831 ₽**, статика ВБ и Ozon
синхронизирована, сверка после = 0 расхождений.
**Покрытие 2026:** WB 16 055 шт — 90.5 % своя отгрузка МС, 8.3 % FIFO истории/товара, суррогат 5;
Ozon 11 375 отправлений — 96.8 % МС, 3.1 % FIFO, суррогат 8; выручка без COGS 17 748 ₽ (0.0 %).
**Вердикт: коллектор приёмок МС не нужен** — закрыл бы 11 позиций из 27 430 ценой постоянной
нагрузки на МС; вернуться, если суррогат вырастет выше ~1 %.

**4. Статус «нужна ручная себест»** (коммит `0f933bf`). Где FIFO нет нигде, строка метится
`method='need_manual'`: оценка по `cost_seb` в ячейке остаётся (месяц не едет), но строка ждёт
цифры человека. Метку ставят 3 коллектора + 3 кнопки «пересчитать» в `web/app.py`; ярлык, опция
фильтра «Способ», бейдж и поле ввода — в `mp_cogs_page` / `ya_cogs_page` / `mp_cogs_drill`. Ввод
цифры переводит метод в `manual` (побеждает всё, переживает прогоны).

**5. Локальная ошибка МС май–июнь добрана** (без правок кода). Нулевой себест в `ms_demand_cogs`
за 2026 был только в мае (18) и июне (45); МС починил — точечный перезапрос `byoperation_cogs`
вернул себест по 30 из 63 (33 913 ₽), COGS **+33 990 ₽**. Повторная проверка 14.08 (все 38 нулей
за 2025-11…2026-08) добрала ещё 4 (3 551 ₽) → `ms_fifo`, пересобраны oz_acc1 08 и oz_acc2 05/06,
статика обновлена. Регрессии нет: 30 контрольных `ms_fifo` и 17 `manual` совпали копейка в копейку.
**Ручного ввода не требуется нигде:** оставшиеся 8 `need_manual` — возвраты (Ozon 3 `return_ozon`,
WB 5 `unredeemed`), себест по ним сторнируется.
**Грабли:** обычный прогон коллектора эти строки НЕ перепроверит — `_known_map` пропускает всё
с `cogs>0`, `collect()` пропускает документы, уже лежащие в `ms_demand_cogs` (`cached`). Только
точечный перезапрос.

**6. Сторно = ровно начисленное** (правило Сергея). Ozon сторнировал по **средней** цене единицы
SKU за всю историю — заменено на себест **самой отгрузки**: `posting_unit_cost()` в
`reports/margin_ozon_sku.py` строит `norm_posting → cogs_отгрузки / штук` из
`OperationAgentDeliveredToCustomer`; фолбэки (средняя по SKU → FIFO товара → группа → ручная)
только когда моста к отгрузке нет, источник пишется в лог. Пересобраны 2026-01…08 × oz_acc1/acc2,
Δ COGS **+15 675 ₽**. ВБ (`margin_by_sku.py`) уже сторнировал по своей отгрузке — пересборка
05/06/07 × acc1/acc2 не дала ни одной строки «без моста»; Яндекс исключает себест возвращённого
заказа целиком; расхождений статика↔витрина по ВБ — 0.
**Месяц НЕ выравниваем — решение Сергея 14.08.** Раздел «Себестоимость» снимает себест в месяце
**отгрузки**, витрина/Отчёты МП — в месяце **денежного реверса**; сумма за период одна и та же,
различается только разбивка по месяцам. Вопрос закрыт, не возвращаться.
