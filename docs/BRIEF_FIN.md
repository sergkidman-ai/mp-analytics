> Первым делом прочитай этот бриф + `CLAUDE.md` + `ARCHITECTURE.md`. Ты — сессия домена **fin**.
> Параллельно может идти сессия домена **mkt** (Джем/реклама/воронка/ABC) — не лезь на её территорию.

> Актуальная передача по обороту для премии, экспрессам Ozon и сезонности (04.10.2026): `docs/BRIEF_FIN4.md`. Сначала прочитать её; старые следующие шаги этого общего брифа не заменяют состояние FIN4.

## Параллельная работа (worktree-изоляция)
Так как сессии идут одновременно — работай в СВОЁМ git worktree и доменной ветке:
```bash
git worktree add .claude/worktrees/fin -b fin/<задача> origin/main   # или из текущего main
cd .claude/worktrees/fin && echo fin > .workstream
```
Имя ветки `fin/*` включает флаг территории автоматически.

## Флаг чужой территории
Активен git-хук (`tools/hooks/pre-commit` → `tools/territory_guard.py`). При коммите правок ЧУЖИХ
файлов из ветки `fin/*` — коммит блокируется с пояснением. Самопроверка в любой момент:
```bash
python3 tools/territory_guard.py --status
```
Осознанный обход: `WORKSTREAM_OVERRIDE=1 git commit ...`.

## Сигнал от prc 14.09.2026: закупочная в карточках МС пересчитывается каждую ночь

С ночи на 15.09 `prc-enter-buyprice.timer` (23:05 МСК) пишет в buyPrice карточки цену её позиции
в актуальном оприходовании на «Удаленный» по ВСЕМ поставщикам, включая внешний API-загрузчик
(раньше — только почтовые прайсы). Цена по УПД перезаписывается ценой прайса (решение Сергея).
Первая ночь ≈8 078 карточек, у 3 151 изменение >20 %, почти всегда ВНИЗ (profiline −34 %,
rapid/ramis −20 %) — это давно не обновлявшиеся закупочные.
- **Что задевает у fin:** `ms_product.buy_price` (после `collectors/ms_products.py`) →
  `set_cost.cost` (min по внешнему коду) → ступени 7–8 себеста в `margin_by_sku`; фолбэк `buy_ms`
  в `collectors/yandex_monthly.py`. FIFO и `cost_seb` не задеты.
- **Ожидание:** на фолбэк-ступенях и в составе наборов себест снизится → маржа этих строк вырастет.
  После 15.09 сверить долю строк на ступенях 7–8 и дельту `set_cost`.
- Кто что поменял: журнал `prc_buyprice_write` (карточка, старая/новая цена). Детали — `BRIEF_PRC.md`.
