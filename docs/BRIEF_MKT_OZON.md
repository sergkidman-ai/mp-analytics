## Модель и правила счёта
- Потолок CPC: `ceiling_safe = (цена × margin_safe/100 − цена × PPO) × CR`, где
  `margin_safe = margin_own_live − 10,6 п.п.` — `margin_by_sku` завышает маржу Ozon (проверено
  транзакциями за июль, +1,12 млн ₽). Пока fin не починит витрину, скидка обязательна.
- CR: фактическая по SKU при ≥30 кликов и ≥3 заказов, иначе справочная по ценовой корзине;
  коридор ×0,3…×3 от справочной.
- Ставка меняется не более чем ×3 за шаг и только вверх до потолка.
- Когорты режем пополам со случайным контролем, половины пишем в журнал ДО отправки.
- Позиция решает всё: топ-10 → 19 заказов на 1 000 показов, 11–20 → 4, ниже 30 → 0,4.

## Инструменты
| Файл | Что делает |
|---|---|
| `tools/ozon_sku_scan.py` | паспорт всех живых SKU: ставка, реклама, поиск, продажи, маржа, потолок, тир → `docs/reports/ozon_<acc>_sku_scan.csv` |
| `tools/ozon_weekly_bids.py` | недельный разбор ±10 % (plan/review/seed) + `mkt_ozon_bid_journal` |
| `tools/ozon_bid_ramp.py` | шаг разгона (заморожен) и **режим `rollback`** — возврат доразгонных ставок |
| `tools/ozon_core_push.py` | шаг «ДРР 3 %»: подъём ставок только по ядру выручки, половина ядра — контроль |
| `tools/ozon_ramp_effect.py`, `ozon_lost_skus.py`, `ozon_cannibal.py` | замеры эффекта, выпавшие SKU, каннибализм |
- API: ставки `PUT /api/client/campaign/{id}/products` (`bid` — строка, микрорубли, меняет только
  перечисленные SKU); завести `POST .../products`; снять `POST .../products/delete`;
  состав `GET .../v2/products` (пагинация 30); отчёты `POST /api/client/statistics/json`
  (`NOT_STARTED` = очередь, ждать 1800 с и перезаказывать).
- Кампании acc1 — по ценовым корзинам: 10604674 (0–1000), 10651636 (1000–2000), 10626733 (2000–5000),
  10659294 (5000–10 000), 10659516 (10 000+), плюс 12704286 «Эксперимент1», 18816976 «Пустые РК»,
  35269704 «Вне РК», 35269713 «Бандлы». Бюджет у кампаний общий → ставки верхушки душат хвост.
- Таблицы: `mkt_ozon_bid_journal` (решения), `mkt_ozon_bid_step_log` (шаги разгона),
  `ozon_bids` (состав кампаний, снимок с 10.08, снимается утром), `mkt_ozon_ads_sku_daily`,
  `mkt_ozon_margin_control`, `ozon_search_query`/`ozon_search_product` (фразы, сбор по средам).
