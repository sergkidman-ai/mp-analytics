## Как устроено
- `cf/balances.py` — остатки на конец дня: Альфа `/jp/v1/statement/summary`, Сбер
  `/fintech/api/v2/statement/summary` → `cf_balance` (source=api). Озон Банк API нет: опорный
  остаток (source=manual) вводится на странице, дальше катится операциями выписки.
- `cf/plan_seed.py` — автоправила `cf_plan_rule` из факта за 3 полных месяца (половины месяца).
  Зарплата — правило Сергея: среднее (ФОТ+самозанятые) 50/50 на 1 и 15. НДС — треть квартала 28-го
  (база — регулярное «пополнение ЕНС»), УСН — аванс 28.04/07/10 (оценка). Ручные правила не трогает.
- `cf/mp_forecast.py` — выплаты площадок (разбор в `docs/cf_recon.md`):
  WB — пн W+5, итог отчёта ×0.999, просроченные сверяются с банком по сумме;
  Ozon — ср W+2 = Σ транзакций недели (до рубля); Яндекс — месячная база/нед, лаг 4 нед (оценка).
- `cf/build.py` — витрина `cf_line` (fact/plan, estimate), по понедельникам `cf_plan_snapshot`.
- `cf/run.py` — cron-точка. `web/cashflow_api.py` + `web/static/cashflow.html` — страница `/cashflow`.
- Поступления классифицирует `cf_income_rule` (миграция 802), переводы между своими = cp_inn=org_inn.
