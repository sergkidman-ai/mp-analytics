## Новые правила Сергея — 10.10.2026, заменяют прежнее добавление всех количеств

- Цветные лазерные/струйные: цвета и соответствующий набор; добавить собственные X2.
  Не ограничивать правило чёрным цветом: проверить все цвета каталога.
- Чернила: цвета и полный набор своей линейки, добавить X2.
- Разный ресурс с бандлами: разделить по точному товару/ресурсу и добавить свои X2/X6/X10.
  Ресурс числовой; список принтеров должен совпадать полностью, буквы XL/H недостаточны.
- Заправочный тонер: отделить от картриджей, объединить родитель + свои X2/X6/X10.
- Барабан + подходящие тонер-картриджи + их набор: сохранить компоненты, добавить X2
  тонер-картриджа. Бандлы барабана и другие количества картриджа — отдельно по семье.
- Одиночный картридж + его бандлы: точный внешний код, модель, цвет, ресурс и количество.
- Чипы строго отдельно: с чипом / без чипа / без счётчика / не указан. Старое разрешение
  смешивать чипы при отсутствии других осей отменено. Неизвестный рядом с известным —
  отдельный список ручного разбора; отсутствие упоминания НЕ означает «без чипа».
- Ленточные цветовые варианты сохранять; бандлы точного вида отдельно без родителя.
- Оставшиеся количества (например X6/X10 после ухода X2) объединять только внутри
  одной точной семьи, без родителя. Наборы не считать обычными однотоварными бандлами.
- Дочерние по принтерам: отдельный тест с рейтинговой карточкой, не массовая склейка
  по одному названию принтера; рейтинг и совместимость надо предварительно собрать.
