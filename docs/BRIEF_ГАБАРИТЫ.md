## Термины (закрыто, не переопределять)

Материнская модель — это ms_product.external_code ровно из 4 цифр. Это сам картридж. Единица учёта габаритов — она.

Дочерние карточки — карточки той же материнской модели, названные через модель принтера, для SEO. Физически это тот же самый картридж. На одну модель бывает 10 и больше дочерних. Один размер материнской закрывает все дочерние.

Наборы — составные позиции. Закрываются суммированием коробок компонентов. Метод не утверждён, наборы отложены.

Принтеры — товар у нас есть, но формального признака в данных нет. Регекс «принтер|мфу|копир|плоттер|сканер» для их поиска непригоден: дочерние карточки содержат эти слова по построению.

Работа ведётся и считается В МОДЕЛЯХ. Карточки — производная величина, приводить их можно только справочно.

## Правило двух слоёв

**Сырой слой** принимает любое значение, у которого есть указатель на строку источника, и хранит
счётчик подтверждений; ничего не выбрасывает.

**Решающий слой** разрешает менять размер в карточке WB только когда внешний источник расходится
с нашим больше допуска **И** это расхождение подтверждено вторым независимым источником.
Допуск — **2 см**, до миллиметра не гонимся.

## Указатель на источник — обязателен всегда

`src_file`, `src_locator` (лист!строка), `src_field`, `src_sha256`, `src_value_raw`.
Для WB — `nm_id` + `title`. Для Solutions Print — `url` + `code`.
Значение без рабочего указателя в слой не попадает.

## Метод сбора — один: по OEM-артикулу

Поиск по артикулу поставщика **отменён полностью**: метод показал ложные попадания на моделях
**0544, 0493, 0445**.

OEM-артикул берётся из `wb_cards.title`, часть до слова «для» (покрытие **2 069 из 2 540**).
Из `ms_product.name` **НЕ берётся**: у 1 304 кодов из 2 540 несколько имён, формат не фиксирован,
есть чужие торговые названия поставщиков.

**Подтверждением** считается только совпадение OEM-кода в `title` карточки **по границам слова**.
Совпадение внутри HTML-разметки, описания или списка совместимых принтеров подтверждением
не является.
