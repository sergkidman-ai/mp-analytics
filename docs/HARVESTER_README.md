# Харвестер габаритов конкурентов — инструкция по запуску

Скрипт `tools/competitor_harvester.py` ищет на **Wildberries и Ozon** карточки
совместимых картриджей того же кода у других продавцов и вытаскивает размеры
упаковки. Запускать **на вашем компьютере (Windows, обычный интернет)** — на
сервере проекта маркетплейсы заблокированы прокси.

## Зачем это вручную у вас
Из серверной среды WB и Ozon недоступны (прокси отдаёт пустую выдачу и блокирует
карточки). Ваш домашний/рабочий интернет — чистый, поэтому сбор делается у вас, а
результат вы присылаете обратно.

## Что понадобится (один раз)
1. **Установить Python.** Скачайте с https://www.python.org/downloads/ →
   кнопка «Download Python 3.x» → запустите установщик.
   ⚠️ На первом экране установщика поставьте галочку **«Add Python to PATH»**, затем «Install Now».
2. **Установить модуль requests.** Откройте «Командную строку» (Пуск → наберите `cmd` → Enter)
   и выполните:
   ```
   pip install requests
   ```

## Что нужно положить рядом со скриптом
В одну папку положите два файла (я вам их дам):
- `competitor_harvester.py` — сам скрипт;
- `residual_oem.csv` — список кодов для поиска (1163 позиции).

## Как запустить
1. Откройте «Командную строку».
2. Перейдите в папку со скриптом, например если файлы в `C:\gab`:
   ```
   cd C:\gab
   ```
3. Запустите:
   ```
   python competitor_harvester.py
   ```
4. Скрипт пойдёт по списку и будет печатать прогресс (`обработано 10/1163` и т.д.).
   Это может занять **несколько часов** (между запросами паузы, чтобы маркетплейсы не блокировали).
   Можно **прервать** (Ctrl+C) и запустить позже снова — уже собранное не повторяется.

## Что получится
Рядом появится файл **`competitor_dims.csv`**. В нём по каждой позиции:
- `source` — «конкурент-ВБ» или «конкурент-Озон»;
- `competitor_article`, `url` — чья карточка;
- `dimensions` — найденный размер упаковки;
- `status` — CANDIDATE (нашли), AMBIGUOUS (у разных конкурентов размеры разошлись),
  NOT_FOUND (размера в карточках нет).

## Что делать с результатом
Пришлите `competitor_dims.csv` мне обратно. На сервере пройдёт **независимая
проверка**, и только после неё размер получит статус CONFIRMED и попадёт в итоговую
таблицу. Ничего на WB при этом не отправляется — всё идёт вам на утверждение.

## Честная оговорка
Размеры упаковки — это поле продавца; часть карточек их **не показывает публично**
(особенно на WB). Поэтому по части позиций будет NOT_FOUND — это нормально, значит
размера в публичных данных нет. Ozon показывает «Размеры» чаще. Если по какому-то
источнику формат страницы изменится и скрипт начнёт всё подряд писать NOT_FOUND —
пришлите мне пару ссылок на карточки, поправлю разбор.
