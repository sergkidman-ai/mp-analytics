## Исходные файлы

- Изипринт: 2040 картриджей с мм и 2 строки чернил с неуказанными единицами. Последние не готовы к загрузке.
- Кактус: 4058 строк / 3942 уникальных артикула с размерами ИУ. Файл также содержит бренды G&G, PRINT-RITE, CopyRite. Мастер-короба не считались.
- Сакура: 1955 строк / 1948 уникальных артикулов; единицы различаются по листам. Считались размеры коробки, а не длина ленты.
- Рапид: актуальнее снимок API 14.10.2026, 1947 артикулов с ДШВ; старый июльский сохранён в реестре как архив. SF-T9451Bk/3065 по-прежнему требует проверки источника.
- Спринт: JSONL и 848 JSON от 14.10 — извлечённые поля страниц с URL, а не оригинальные HTML. 5519/5875 с 9×88×305 мм остаются неподтверждёнными. В архив оригинальных прайсов эти извлечения не включены.
- Профилайн: старый XLS — только вес и объём. В API 14.10 есть 1193 непустых dimensions_wb; единицы/оси не подтверждены, действующее правило запрещает их применение. Файл и статус отдельно в additional_sources_on_hold.json.
- Булат: в XML нет отдельных тегов ДШВ упаковки. Упоминания в описании за такие поля не принимались.
- Свежесть архивных Excel не подтверждена. Новые прайсы не загружались, сопоставление всех исходных строк с МС не выполнялось.

## Артефакты

- supplier_dimensions_summary.xlsx — сводка групп, юрлица МС, 45170 карточек, реестр источников, методика.
- supplier_original_dimension_sources.zip — три исходных Excel и снимок API Рапида 14.10, без изменения значений.
- source_rows.csv — 36003 строки исходников с файлом, листом, номером строки/индексом и исходными значениями; это реестр, не план записи.
- source_manifest.json — хэши и подтверждение оригинального архива; additional_sources_on_hold.json — Профилайн API и Булат.
- products_review.csv — все карточки с остатками и заполненностью ДШВ.

В МС и маркетплейсы ничего не записывалось.
