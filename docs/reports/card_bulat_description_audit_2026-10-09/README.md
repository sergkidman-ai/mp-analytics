Проверка 09.10.2026, только чтение. Фид повторно получен по `https://bulat-group.ru/price/clientapi.xml`; дата внутри `2026-10-09 04:30`, SHA-256 совпал с проверкой доступности. Остаток — `count > 0` сегодняшнего суточного фида, а не независимый остаток в реальном времени. МС прочитан живым API по всем трём контрагентам группы Булат, только активные товары. Наличие собственных/удалённых остатков МС не было дополнительным фильтром.

## Область и сопоставление

Прочитаны 4 192 активные карточки группы. Артикул МС сопоставляется с id offer или vendorCode того же поставщика; нормализуются только регистр и пробелы. Если получается более одного товара фида, карточка исключается. По названию или внешнему коду поставщика похожие товары не подбирались.

| Результат | Карточек МС |
|---|---:|
| Сопоставлены с положительным count и непустым name | 2 586 |
| Из них Описание точно равно name | 1 128 |

Нет соответствия в положительной части фида не означает автоматически нулевой остаток: артикул также может отсутствовать в фиде. Среди 2 586 сравнений 2 578 сопоставлены по id offer, восемь по vendorCode; это 1 905 внешних кодов ТК. Различия 1 458 не сводятся к регистру, пробелам или XML/HTML-сущностям; это различие текста, а не автоматически ошибка или устаревание МС.

## Нужно ли заменять Описание на name

**Массовую замену 1 458 описаний только на основании различия с name фида не рекомендую.** Название в name часто содержит сокращённый текст. У **1 119 из 1 458** нынешнее Описание МС уже присутствует в самом начале развёрнутого description этого же товара в текущем фиде (после удаления HTML и нормализации пробелов). Следовательно, отличие от name не доказывает устаревания этого описания. Для остальных 339 это конкретное совпадение не установлено; они требуют отдельной проверки, а не автоматической замены.

Пример **0860 / DAMTTK3500110**, count=50:

- name фида: «Тонер-картридж Kyocera TASKalfa 3500i TK-6305 (35k) e-Line»;
- Описание МС: «Тонер-картридж e-Line TK-6305 для Kyocera TASKalfa 3500i (Чёрный, 35000 стр.), с чипом»;
- description фида начинается с этого полного названия и далее также указывает наличие чипа.

Заменив Описание на name, мы потеряем информацию о чипе, которая подтверждается самим фидом поставщика. По задаче чипа нельзя читать только name и игнорировать description.

## Расхождения информации о чипе

В 11 карточках/11 внешних кодах явный класс чипа в name фида отличается от Описания МС:

- восемь: МС «с чипом», name фида молчит;
- одна: МС «без чипа», name фида молчит;
- две: name фида «с чипом», МС молчит — **3779 / AFBRHL2350030**, count=100, и **5777 / AFBRHL2350020**, count=51.

Развёрнутый description фида проверен для всех 11 случаев. У восьми первых положительных случаев он подтверждает наличие чипа; у отрицательного случая 3761 содержит «без чипа» и указание переставить старый чип. У 3779 и 5777 description фида также не содержит упоминания чипа, хотя name его содержит. Поэтому эти две карточки выделены для проверки/дозаполнения информации, а молчание name у других девяти не трактуется как изменение товара или отсутствие чипа.

Примеры остальных различий: 0002 / AFHPLJ1010130 — разные способы перечисления совместимости и марки; 0003 / BFHPLJ6015130 — разные способы записи модели, цвета, ресурса и восстановленного исполнения. Они не объявлены ошибкой товара на основании одного текстового несовпадения.
