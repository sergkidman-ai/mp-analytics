# Закрытие октября 2026 Ozon

По прямой команде пользователя закрыт октябрь в «Отчётах МП» для
Цифрового квадрата и Дисквэра. Применены существующие `_freeze_estimate`
и `_reconcile_final` из `reports.ozon_mp_freeze` только к 2026-10,
с одной атомарной записью под штатным локом истории и локом финансового пайплайна.
Остальные месяцы/площадки не закрывались.

Перед записью проверены обе реализации за полный октябрь:
№19610824 (Цифровой, 2097 строк), №19639127 (Дисквэр, 428 строк).
Неизвестных COGS в октябрьской витрине 0 у обоих юрлиц (1081/384 SKU).
Сохранены приватная резервная копия JSON/HTML/исходников и штатная копия истории.

## Сопутствующая целостность отображения

Октябрьская подстрока жалоб — Цифровой 644 ₽, Дисквэр 4347 ₽ (формат страницы).
Новая расшифровка не имелась в старых закрытых снимках. Для неё записана
метка `detail_from=2026-10`; генератор показывает недоступную прежнюю
детализацию прочерками, чтобы штатные технические нули при добавлении строки
не выглядели как доказанное отсутствие жалоб в прошлых месяцах и не давали
неполный «годовой» итог. Прежние суммы закрытых статей не менялись.

Старые ссылки `?period=2026-10` после закрытия корректно выбирают следующий
открытый месяц, ноябрь; закрытый октябрь остаётся отдельным столбцом таблицы.
Исправлен выбор открытого периода в общем JS, существующие открытые периоды
WB/Маркета сохраняются. Изменение не закрывает другие площадки.
