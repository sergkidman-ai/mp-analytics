## Что проверено

- Количество предметов сверено с названием и кодом; обычные одиночные артикулы со случайным X в суффиксе не считаются бандлами. Расхождение количества выводится в review.
- Модель, цвет и ресурс бандла сравниваются с основной карточкой и ТК. Фото-черный и черный различаются. Несовпадающий или отсутствующий ресурс не пересчитывается по догадке.
- Чип: правила 22.09 по МС/прайсам и ТК; несколько классов чипа, неизвестный чип и противоречие с карточкой/ТК требуют проверки. Условный вывод «без чипа» при >=3 молчащих товарах обозначен своим источником, а не выдан за явно заполненное поле ТК.
- У Дисквера длина случайного суффикса не отличает основную от карточки по принтеру. При нескольких кандидатах выбирается единственная карточка с точной моделью ТК; неоднозначные случаи остаются на проверку.
- Другие члены исходной группы блокируют автоматический выбор переноса. Состав группы основной сохраняется, перенос не разбивает ее.

Основные причины review — неизвестный чип, противоречие текста карточки источнику чипа, отсутствие ресурса и расхождение цвета. Это не утверждение, что все эти карточки имеют ошибку модерации WB: речь о достаточности данных для безопасного объединения.

## Техническая подготовка

ops/wb_bundle_plan.py выполняет только SELECT и read-only POST получения карточек. В нем нет --apply и вызовов moveNm. Состав групп и значимые поля защищены контрольной суммой; перестановка характеристик в ответе API не считается изменением данных.

ops/wb_glue.py переведен на Content API для проверки imtID до и после переноса. HTTP-ошибка, error=true даже при HTTP200 и неподтвержденный перенос теперь завершают выполнение с ошибкой. Публичный API витрины с HTTP403 не блокирует проверку групп через API кабинета; отображение покупателю остается отдельной проверкой.

Перед будущей разрешенной записью повторно проверить неизменность плана, без записи:

```bash
./venv/bin/python -m ops.wb_bundle_plan --verify-preview docs/reports/wb_bundle_plan_2026-10-04/3351_move_preview.json
```

Если состав или характеристики изменились — перестроить и рассмотреть план. Этот режим читает весь активный каталог затронутого кабинета и не перезаписывает утвержденный предпросмотр.
