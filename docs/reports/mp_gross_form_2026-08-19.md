## Единая экономическая модель

На всех трёх площадках одно и то же: **наша цена — база комиссии; площадка даёт покупателю скидку
за свой счёт; мы получаем «наша цена − удержания»**. Различается только способ доставки скидки:

* **ВБ** — СПП, финансируется внутри комиссии ВБ (payout/наша цена не зависит от глубины СПП);
* **Ozon** — баллы, приходят к нам деньгами в выплате, Ozon возвращает своё комиссией с полной цены;
* **Маркет** — субсидия, деньгами не приходит: Маркет гасит ею собственные услуги (`NETTING`).

Форма подачи теперь одна:

```
Продажи (оборот)
  Продажи — оборот (наша цена)          100.0%
    Выручка (деньги покупателя)
    Скидка площадки за её счёт          СПП / баллы / зачёт баллами
Удержания площадки (начислено)
  …
  Итого удержания
Итого к перечислению = оборот − удержания − возвраты
```

## Проверка неизменности: деньги не поехали

Сравнение статических HTML всех трёх вкладок с состоянием ДО этапа 1 (`f237e1a`), по всем месяцам
и обоим аккаунтам ВБ и Ozon:

```
reports.html         oz_acc1/oz_acc2   payout, net, cogs   макс |Δ| = 0 ₽   (7 мес)
reports_wb.html      wb_acc1/wb_acc2   itog,   net, cogs   макс |Δ| = 0 ₽   (8 мес)
reports_yandex.html  ya_acc1           payout, net, cogs   макс |Δ| = 1 ₽   (9 мес, округление)
```

У Маркета выросли только оборот и удержания — ровно на величину зачёта, который между ними
сокращается: `(оплата + зачёт) − (услуги + зачёт) = оплата − услуги`. Июль-2026: оборот
1 428 172 → 2 363 585 (+935 413), комиссия 359 601 → 1 145 703, итого удержания 633 350 → 1 568 764,
«Итого к перечислению» 769 481 без изменений (сверено с ЛК).

Штуки возвратов Маркета за январь (+1) и март (+7) сдвинулись — это свежее сырьё пересчёта витрины
(возвраты доезжают позже), а не эффект правки; деньги возвратов не изменились.

## Почему оборот Маркета = выручка + ЗАЧЁТ, а не выручка + субсидия

Субсидия по заказам (`subsidy`) живёт в месяце ЗАКАЗА, зачёт — в месяце АКТА, между ними лаг:

| месяц | зачёт по актам | субсидия по заказам | расхождение |
|---|---:|---:|---:|
| июнь-2026 | 909 098 | 730 154 | +178 944 |
| июль-2026 | 935 413 | 1 000 052 | −64 639 |

Обе части оборота-гросс должны быть из одного источника, иначе «Итого к перечислению» поехало бы
на эту разницу — и знак расхождения менялся бы от месяца к месяцу. Субсидия оставлена справочной
строкой. Это же соответствует Ozon, где оборот тоже берётся из отчёта о реализации.

## Закрытые находки

* **D** — база подсветки Маркета (`_hist_series` считал `revenue + subsidy`) не совпадала с базой
  процентов на странице (`revenue`). Теперь обе = `revenue + netting`.
* **E** — единая база оборота между вкладками: у всех трёх страница и модуль подсветки берут
  «нашу цену» (`sales` у Ozon, `own_price` у ВБ, `revenue + netting` у Маркета).
