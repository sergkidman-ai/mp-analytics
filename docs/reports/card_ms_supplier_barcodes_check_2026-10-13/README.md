# МС: проверка добавления EAN-13 поставщиков, 13.10.2026

Только GET, без записи МС/ТК/маркетплейсов/БД. Повторное чтение 73 текущих оприходований завершено 13.10 около 15:37 МСК. Проверены те же 6763 действующие карточки из предыдущего аудита штрихкодов поставщиков; три архивные карточки остаются вне охвата.

## Поле и принцип хранения

У карточки товара МС есть **массив `barcodes`**. Разные типы представлены отдельными объектами: `{"ean8": "…"}`, `{"code128": "…"}`, `{"ean13": "…"}`. Живые карточки уже содержат эти три типа одновременно. По уточнению пользователя: наши EAN-8 — для склада, Code128 — для маркетплейсов, EAN-13 — дополнительные коды поставщиков.

Добавить EAN-13 возможно, сохранив полный существующий массив и его порядок и дописав отсутствующий код. Такой подход сохраняет собственные EAN-8, Code128 и ранее загруженные EAN-13. Уже существующий код не нужно повторять, иной EAN-13 не нужно удалять. Это проверка возможности и предварительные данные, запуск записи не разрешён.

МойСклад официально допускает несколько штрихкодов для одного товара: [Как использовать штрихкоды](https://support.moysklad.ru/hc/ru/товары%20и%20склады/товары%20и%20услуги/как_использовать_штрихкоды).

| Поставщик | Пригодный EAN-13 получен для карточек | Уже есть точно такой EAN-13 | Отсутствует, можно подготовить добавление |
|---|---:|---:|---:|
| Профилайн | 1414 | 41 | **1373** |
| Рапид / SuperFine | 959 | 8 | **951** |
| Булат | 1314 | 1 | **1313** |
| Итого | **3687** | **50** | **3637** |

Все 50 совпадений находятся именно в записях типа `ean13`. Случаев, когда код поставщика сохранён под другим типом, или когда в карточке кандидата находится иной EAN-13, не обнаружено. Идентичность артикулов и внешних кодов с предыдущим срезом сохранилась.

Во всём проверенном охвате **65 карточек уже имеют EAN-13**: 41 Профилайна, 8 Рапида, 1 Булата и 15 Спринта. Все существующие EAN-13 проходят проверку контрольной цифры. Для 15 карточек Спринта сравнить код с сайтом поставщика невозможно: на страницах код не выдаётся. Их имеющиеся EAN-13 сохраняются. Проверка подтверждает наличие кодов, но не устанавливает, кем и через какой импорт они записаны.

Собственные коды в этом охвате: EAN-8 есть у 6692 карточек, Code128 — у 6613. Это отдельные сведения о заполненности; их исправление и генерация не выполнялись и в предварительное добавление EAN-13 не включены.
