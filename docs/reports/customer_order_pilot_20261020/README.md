# Пилот заказов Ozon Дисквэр — реализация 20.10.2026

Поток fin, worktree `/opt/mp-analytics/.claude/worktrees/fin-shipment-guard`.
Основной коммит реализации `12bce8b`; адаптер wb4c интегрирован через
`4069230` и `040fbc1`. [Инструкция запуска](../../CUSTOMER_ORDER_PILOT_RUNBOOK.md).

## Реализовано

- Вкладка «Склад → Заказы покупателей», `/warehouse/customer-orders`.
- Получение Ozon через общий адаптер v4, отдельные номера частей заказа.
- Первая проверка МС через 10 минут от first_seen, аренда и дедупликация заданий.
- Обновление отслеживаемых MP-статусов отдельной однократной командой refresh.
- Закупочная оценка из оприходования, предварительный FIFO заказа, FIFO отгрузки.
- Состав наборов из существующего справочника ТК; выбранный ТК товар не подменяется.
- Версии источников, история проверок, инциденты подтверждённого отсутствия в МС.
- Общая блокировка МС со сторожем отгрузок, отдельная общая блокировка Ozon.

## Ограничения запуска

Автоматический цикл сбора/проверок, вебхуки и Telegram-рассылка не включены.
Новые заказы и изменения появляются после явных команд sync/refresh/work.
Частота повторных проверок МС по-прежнему требует отдельного решения.
Старые активные заказы вне стартового окна требуют отдельного начального покрытия.
Отправитель инцидентов Наталии в prc — следующий этап, здесь подготовлено хранение.
Кооперативная блокировка Ozon начнёт защищать и финансовый процесс после
его перехода на новый код wb4c; старый запущенный процесс её не использует.
