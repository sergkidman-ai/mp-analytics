# Восстановление заказов по уведомлениям 06.11.2026

Причина: последовательное чтение всех оприходований поставщиков попадало на замену/удаление документа. Ответ MS 404 прерывал общий сбор цен и откладывал создание заказов. Два ранних сегодняшних уведомления уже были обработаны; три последних сначала отсутствовали в МС.

Исправление общего загрузчика: до трёх попыток чтения актуального списка оприходований с проверкой итогового digest; повторное использование позиций только при неизменных id и updated; максимум три параллельных GET. Недоступный документ не пропускается, неполный набор цен не сохраняется. Scheduler сохраняет digest подтверждённой итоговой версии.
