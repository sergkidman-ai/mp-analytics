# «Отчёты МП»: строка «удержано деньгами», починка графика Ozon, вид на последние месяцы

Правки 19.08.2026 (поток fin), ветка `fin/mp-tail-view`. Три пункта из запроса Сергея.

## 1. Маркет: под «Итого удержания» — из чего оно состоит

Начисленные удержания раскрыты двумя справками (порядок: сначала деньги, потом зачёт):

```
Итого удержания Маркета (без возвратов)        1 568 764   ← начислено (июль-2026)
  └ в т.ч. удержано из выручки (деньгами)        633 351   ← новая строка
  └ в т.ч. погашено баллами Маркета               935 413
```

`деньгами = начислено − зачёт`. Весь зачёт сидит внутри строк, входящих в `MP_EXP` (комиссия,
логистика, бусты, полки), поэтому разложение точное — Δ = 0 ₽ во всех девяти месяцах:

| | Ноя | Дек | Янв | Фев | Мар | Апр | Май | Июн | Июл |
|---|---:|---:|---:|---:|---:|---:|---:|---:|---:|
| начислено | 435 819 | 443 110 | 534 814 | 649 877 | 625 722 | 1 017 430 | 1 358 792 | 1 502 289 | 1 568 764 |
| деньгами | 435 819 | 443 110 | 332 854 | 446 827 | 373 930 | 492 767 | 535 810 | 593 191 | 633 351 |
| баллами | 0 | 0 | 201 960 | 203 050 | 251 792 | 524 663 | 822 982 | 909 098 | 935 413 |
| Δ | 0 | 0 | 0 | 0 | 0 | 0 | 0 | 0 | 0 |

Ноябрь-декабрь 2025 — зачёта нет (отчёт услуг начинается с января), поэтому «деньгами» = всё.

Живые столбцы тоже считаются: ключ `itog_money` добавлен в `KIND`, `_derive` и `_hist_series`
`reports/yandex_mp_report.py`, поэтому «тек.» и «прогноз» приходят из того же API
(`/api/yandex/mp-current`): тек. 423 873 + 704 778 = 1 128 651 ≈ итого 1 128 650 (Δ 1 ₽ округление).

Ни «Итого к перечислению», ни чистая не затронуты — строка справочная.

## 2. Графики Ozon: июль уезжал за край

Причина найдена. В `reports/ozon_mp_page.py` геометрия обоих графиков была **зашита под 6 месяцев**:
`bars_line` — шаг 75.3 px, `line2` — шаг 90.4 px при `viewBox 0 0 500 140`. С седьмым месяцем
подпись «Июл» вставала на x = 513.5 (столбики) и x = 566.4 (линии) — то есть за пределами холста,
и июль на графиках Ozon не отображался вовсе. У ВБ и Маркета те же функции давно параметрические.

Обе функции переведены на шаг от N (`step = (W−40)/N` и `(W−48)/(N−1)`), как у сестёр. После правки
на всех трёх страницах максимум по x: подпись 476.0, правый край столбика ≤ 465.7 — внутри 500.
Дальше страницы масштабируются сами при любом числе месяцев.

Заодно `colspan` заголовков секций Ozon был зашит числом 12 — переведён на `_C["N"] + 5`.

## 3. Таблица открывается на последних месяцах

Раньше таблица стояла на первом месяце и свежий месяц требовал прокрутки вперёд. Теперь:

- общий `TAIL_JS` (объявлен в `ozon_mp_page`, подключён на всех трёх страницах) ставит
  `scrollLeft = scrollWidth` каждому `#mpr .card` — прокрутка нужна **назад, в историю**;
- доводка повторяется по таймеру (0.5 с и 1.5 с), потому что живые столбцы «тек.»/«прогноз»
  дозаполняются fetch-ом уже после загрузки и расширяют таблицу; повтор отменяется, как только
  пользователь сам тронул колесо/тач/клавиши — свою прокрутку скрипт не перебивает;
- **первый столбец закреплён** (`position:sticky; left:0` для `td.lbl` и заголовка) — иначе на
  правом краю подписи статей уезжали бы из вида. Заголовок секции («Продажи (оборот)» и т.д.)
  обёрнут в `<span>` со `sticky; left:11px`, чтобы тоже оставался виден.

Сверка отрисованного HTML со старым (по `data-k`, все строки, все месяцы): на Ozon и ВБ
