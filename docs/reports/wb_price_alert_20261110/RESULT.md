## Первопричина

Ночной отдельный вход Цифрового в акцию3144 «11.11: финал» был запущен по
поручению другого потока09.11 23:59МСК. В10.11 00:08:04МСК создана запись
SQLite uploads.id=388 на100товаров; через25.3сек записано неопределённое состояние
`Transport/response failure after durable intent`. Подтверждённого uploadID нет.
При последующих проходах обработчик сохраняет состояние uncertain и account barrier.
Проверка08:41 видела77/100совпадений с запрошенными ценами. Совпадение текущей цены
не доказывает завершение неизвестной асинхронной задачи: ID отсутствует, часть
товаров может быть отклонена или изменена другими действующими акциями.

Автоматическая блокировка не позволяет новому отправителю менять тот же кабинет,
пока старая загрузка может изменить цены. Вручную удалять marker или повторять
неопределённый POST без сверки запрещено действующим core/wb_price_writer.py.
