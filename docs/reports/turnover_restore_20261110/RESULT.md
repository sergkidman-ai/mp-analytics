# Восстановление оборотов — 10.11.2026

Восстановлены существующие /turnover и /turnover/royalty. Расчёты премии и роялти,
выбранные бренды, ставки и источники выручки сохранены.

Причины неполадок:

- В корневой БД raw_ozon_attributes была пуста. Все продажи Ozon для роялти попадали
  в нераспределённые и исключались из базы.
- Обработчик прямой страницы /turnover/royalty добавлял подсветку меню глобальной
  заменой подстроки. Вместе с HTML менялся JavaScript CSS selector, скрипт останавливался
  до загрузки данных. Ошибка воспроизведена в браузере и устранена заменой полного тега ссылки.
- «6 месяцев» вычислялись вычитанием 31 дня на месяц: в ноябре показывались май–ноябрь,
  семь месяцев. Теперь окно июнь–ноябрь считается по календарю.

Из рабочей rev_recovery_20261103 прочитаны реальные полные снимки только 2478 карточек,
встречающихся в отчётах реализации с июля: 1775 Цифрового и 703 Дисквэра. Они добавлены
в raw_ozon_attributes корневой БД с исходными collected_at, без перезаписи существующих
карточек. Полный каталог повторно не запрашивался. Выбранные + исключённые + нераспределённые
продажи и возвраты сверены с полными отчётами реализации до копейки для всех account/month.

Роялти Цифрового: июль185888.47, август165440.71, сентябрь202998.69, октябрь250346.23.
Июль/август совпали с прежним сохранённым расчётом. Сентябрь теперь содержит полный ВБ,
тогда как старый снимок был по20.09. Ноябрь предварительный: месячных документов ещё нет.

У Дисквэра остаётся одна строка сентября на802.84 ₽ без бренда. Точечный бесплатный
read-запрос Ozon вернул ту же карточку с пустым брендом. Строка показана как неизвестная,
не распределялась по названию или догадке. Ставка роялти Дисквэра по-прежнему не задана.
Применяются прежние правила брендов: Цифровой квадрат у oz_acc1 и Dsquare у oz_acc2;
старый отчёт и действующий код совпадают, несмотря на неточную позднюю сводку брифа.
Бренд — сохранённое состояние карточки, история изменений не восстанавливалась.
