## Поля и подтверждения

- Кактус: I «Вес брутто шт. кг» — явные кг и брутто единицы; не вес мастер-короба. Прямой источник готов к подготовке плана при сохранении остальных ограничений.
- Сакура: лазерные AD «Вес кг» — кг подтверждены, брутто/нетто отдельно не подписано. Струйные Y «Вес коробки кг» — вес коробки в кг. Матричные S и наклейки Z «Вес коробки» — единицы не указаны. Подтверждение для разных листов нельзя переносить по аналогии.
- Изипринт: J «Вес» (картриджи), I «Вес» (чернила); единицы и брутто/нетто не подписаны. Числа похожи на кг, это гипотеза, не подтверждение.
- Рапид: Weight есть в свежем API. Единицы/брутто/нетто не указаны ни в поле, ни в полученной инструкции API из Dropbox. Требуется подтверждение перед записью.
