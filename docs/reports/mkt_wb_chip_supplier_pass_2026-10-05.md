# Чипы: дополнительная проверка прайсов поставщиков — 05.10.2026

## Что было сохранено и что проверялось повторно

В `ops/wb_chip_map.py` и `docs/BRIEF_MKT.md` сохранено правило от 22.09: все товары поставщиков внешнего кода плюс прайсы, далее ТК и карточки ВБ. Предыдущий глубокий отчёт уже учитывал названия МС и названия строк прайсов, связанных через `ms_id`. Поэтому найденные ранее 730 кодов acc1 **уже исключены** из неизвестного остатка: повторно вычитать их из 61 % нельзя.

В дополнительной проверке расширен охват: все сохранённые строки прайсов, сокращения поставщиков, последние полные файлы из пяти почтовых папок, полное наименование НВ-принта. ТК и карточки ВБ заново по API не запрашивались — использован проверенный срез предыдущего отчёта.

Два новых явных случая:

- внешний код **1664**: «с чипом» в связанной строке прайса;
- внешний код **1380**: «w/o chip» в названии товара поставщика МС, то есть «без чипа». Это восстановление за счёт сокращения, а не новая строка полного прайса.

Для кодов **3919 и 3924** в прайсе есть «с чипом», но автоматический путь связи через артикул пока не подтверждён. Эти позиции вынесены в CSV с исходными названиями и ссылками, без автоматического присвоения класса.

## Что реально охвачено

- В журнале 453 189 строк загрузок, в том числе 163 554 без `ms_id`; это исторические повторы, а не столько уникальных товаров.
- После свёртки одинаковых записей проверено 13 304 сочетания поставщика/артикула/названия/привязки из 12 ключей поставщиков.
- Дополнительно проверены 56 920 товаров МС и 19 282 строки последнего снимка остатков поставщиков.
- Прочитаны пять исходных файлов: Колортек, Одиссей, Сакура, Кактус и НВ-принт; всего 12 724 строк данных. Даты файлов — 01–05.10.2026.
- В исходных файлах найдено 1 108 неизвестных кодов с однозначной связью с нашим ассортиментом; с учётом журнала прайсов охвачено 1 184 из 2 842.
- Для остальных 1 658 неизвестных кодов в этой проверке не получена подтверждённо связанная строка прайса. Названия МС или остатки могут присутствовать, но это не эквивалент полного исходного прайса.

В проверенных таблицах отдельной колонки чипа не найдено; сведения находятся в названии/полном наименовании. У НВ-принта прочитаны также примечания. Для остальных поставщиков журнал содержит преимущественно несопоставленные товары, присланные внешним загрузчиком, а не полную выгрузку прайса. Поэтому **не заявляем, что все исходные прайсы всех поставщиков проверены целиком**.

## Почему 447 кодов Кактуса не записаны как доказанный чип

В `prices/profiles.py` сохранено `default_chip="chip"` для Кактуса. Это правило поставщика, а не явное поле конкретной строки. Из 447 таких неизвестных кодов 345 найдены в текущем исходном прайсе с надёжной привязкой, остальные 102 — по сохранённым строкам журнала.

Контроль правила по текущему прайсу обнаружил **10 внешних кодов**, для которых связанные названия других поставщиков явно говорят «без чипа». Поле ТК у этих десяти пусто. Возможные причины — неодинаковое исполнение у разных поставщиков, ошибка привязки либо слишком широкое правило Кактуса. Пока причина не разобрана, распространять правило на все 447 кодов как техническую истину нельзя. Контрольные случаи включены в JSON отчёта.

## Как продолжить

1. Проверить исходные свидетельства и привязку двух дополнительно найденных кодов; итоговые классы сохранены в отчёте, рабочие таблицы не менялись.
2. Разобрать два случая 3919/3924 и десять контрольных расхождений Кактуса. После этого определить границы применимости правила по конкретному исполнению, а не по всему бренду.
3. Для 1 658 кодов без связанной строки прайса получить полные исходные данные остальных поставщиков из внешнего загрузчика/API. Не повторять поиск по тому же сокращённому журналу.
4. Остальные неизвестные проверять по конкретному артикулу поставщика и по явному описанию исполнения; молчание оставлять отдельным статусом.

ТК и карточки ВБ уже проверены для этого среза. Повторный полный запрос сейчас не нужен. Возврат к конкретной карточке полезен при конфликте или подтверждении связи модели, а не как ещё один массовый прогон той же пустоты.
