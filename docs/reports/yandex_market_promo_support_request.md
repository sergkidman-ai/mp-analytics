# Обращение в поддержку Яндекс Маркета — акция «Бестселлеры», работа через Partner API

**Кабинет:** businessId 879051
**Акция:** cf_2002137 «Бестселлеры: Новая единая акция», период 17.09.2026 — 30.09.2026, механика DIRECT_DISCOUNT
**Как работаем:** только через Partner API (`/v2/businesses/{businessId}/promos`,
`/promos/offers`, `/promos/offers/update`, `/promos/offers/delete`). Кабинетом состав акции
не правим.

## Что делали

1. **17.09, 20:00 и 21:00 МСК** — методом `promos/offers/update` завели в акцию 1 420 товаров
   (цена по акции = уровень `topBestLevel` из `bestPriceLevels`, зачёркнутая цена — текущая
   цена каталога из `offer-prices`). Ответ API: `rejectedOffers` пустой у всех запросов.
2. **18.09** — проверка состава через `promos/offers` показала, что применились только 86 из 1 420.
   Остальные вернулись со статусом `NOT_PARTICIPATING`, при этом ни отказа, ни предупреждения
   API не возвращал, `assortmentInfo.processing` = false.
3. **18.09, 14:20 МСК** — повторили ту же отправку (1 325 товаров). На этот раз применились все,
   примерно за 1,5 часа. Состав акции: 1 417 товаров со статусом `MANUAL`.
4. **20.09, 10:50 МСК** — в акции осталось **87** товаров со статусом `MANUAL`. Выпали 1 332.
   Проверили: у всех выпавших наша цена по акции НЕ выше текущего `maxPromoPrice`, то есть
   условию акции они по-прежнему соответствуют.

## Вопросы

1. **Почему первая отправка не применилась?** API вернул успех без `rejectedOffers`, но в акцию
   попали лишь 86 позиций из 1 420. Как по ответу API отличить принятое от непринятого?
   Сейчас единственный способ — перечитывать состав акции и сравнивать.
2. **Почему товары выпали из акции 20.09?** Мы их не удаляли (кроме 127 позиций, см. п. 4 ниже),
   цена по акции не менялась и не превышает `maxPromoPrice`. По каким правилам товар,
   заведённый вручную, удерживается в «Бестселлерах» и когда пересчитывается состав?
3. **Можно ли отключить автодобавление товаров в акцию?** Маркет сам добавляет товары со
   статусом `AUTO`. Для части из них цена акции ниже нашей себестоимости с учётом удержаний,
   то есть продажа идёт в убыток. Мы удаляем их через `promos/offers/delete`, но они
   возвращаются: 19–20.09 одни и те же 103–127 позиций удалялись четыре прогона подряд.
4. **Как удалить товар из акции навсегда?** Удаление применяется, но товар снова оказывается
   в акции со статусом `AUTO`. Поле `minimumForBestseller` в `offer-prices/updates` мы не
   используем: по документации, отправка цены без этого поля стирает ранее заданный минимум,
   и мы не хотим задеть цены. Есть ли способ исключить товар из акции, не трогая цены каталога?
5. **Уточните применение изменений.** В документации указано 4–6 часов, по факту заведение
   применилось за ~1,5 часа, а часть отправок не применилась вовсе. Есть ли способ узнать
   статус конкретной отправки?
