## Защита очереди уведомлений

По ms-mass-change размеры — немое изменение для ТК. Свежая инвентаризация: единственный активный product.UPDATE — ТК, UUID и SHA256 URL зафиксированы. В каждом POST используется официальный заголовок X-Lognex-WebHook-DisableByPrefix с точным URL подписки, полученным GET в памяти. URL/токен не пишутся в журнал. Этот механизм подавляет только уведомление от данного запроса; подписки не отключаются и не изменяются. Прочие запросы, product.CREATE и операционные события сохраняют уведомления. Не нужен restore-таймер, так как глобальной мутации подписки нет.

Официальная документация: https://github.com/moysklad/api-remap-1.2-doc/blob/master/md/dictionaries/_webhook.md, раздел «Заголовок временного отключения X-Lognex-WebHook-DisableByPrefix через API».
