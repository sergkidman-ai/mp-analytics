## Вывод

Неделя слабее предыдущей: оборот −39,0%, расчётная прибыль −60,4%, созданные заказы −21,0%; доля услуг выросла с 61,52% до 68,48%, маржа снизилась с 17,08% до 11,08%. Рост недели 21–27.09 не продолжился. Это не доказательство причинного влияния сентябрьских изменений: недельные платежи и зачёты приходят с лагом, а себестоимость учитывается по дате создания заказа.

У 35 заказов этой недели статус DELIVERY/PICKUP (20/15), FIFO-себестоимость 29095,48 руб. уже включена в расчёт. Из 113 созданных 64 DELIVERED, 14 отменены на разных этапах. Не добавляем будущую выручку, не пересчитываем фактическую маржу гипотетическими продажами.

## Полнота и источники

Платежи/возвраты: свежий stats/orders API по всем семи кампаниям, диапазон создания 01.01–08.10.2026, пагинация завершена для каждой, 4270 уникальных заказов. Операции отфильтрованы по фактической дате платежа 21.09–04.10; есть операции за все семь дней новой недели.

Услуги: raw_yandex_services из официального отчёта, обновлённого 08.10 в 02:26 UTC; есть строки за все семь дней. Расходы = cost + netting, бонусы не считаются расходом сверх источника, категории продвижения не задваиваются.

COGS: прочитаны актуальные документы отгрузок МС и возвраты обоих контрагентов Маркета; для заказов двух недель 226 отгрузок, методы только ms_fifo. Используется уже сохранённый фактический FIFO конкретного документа; недостающего FIFO не обнаружено. Для всех доставленных заказов COGS найден. Статусы пересверены со свежим API и возвратами МС. Фолбэки, средние себестоимости и импутации не используются.

Методология: оборот = платежи покупателей + зачёт; услуги = денежные удержания + зачёт; прибыль = оборот − услуги − возвраты − COGS. COGS по дате заказа, остальные операции по своей дате. Значит, полная календарная неделя не равна закрытой группе заказов этой недели. Будущие доставки/возвраты могут изменить последующие расчёты.

Дополнительные меры: сначала сверить и обновить базу удержаний сторожа (см. предыдущий отчёт: 69,53% вместо 67,00% по полным платежам сентября), проверить фактическое участие продающихся SKU в акциях/конфликты с ТК, затем адресно анализировать одинаковые SKU. Массовое изменение цен из этих недельных агрегатов не обосновано.

Сохранены weekly.csv, daily.csv, свежие отчёты заказов и платежей, услуги, документы МС, COGS и проверки. БД, приложение и цены площадки не изменены.
