# Восстановление OPEX с начала 2026 года

Восстановлены остальные пропущенные правила, явно подтверждённые ручной разметкой пользователя. Пять правил и 19 дополнительных назначений, включая коммунальные платежи Курганмашзаводу → Аренда. Для общего фиктивного ИНН использован фрагмент Возврата, общий ключ не создавался. Исходные ручные назначения/разнесения сохранены.

Существующий банковский backfill загрузил январь–июль: 868 операций Альфы + 467 Сбера = 1335 новых; август–ноябрь уже были загружены. Исторический контроль до03.08: 881/474, совпадает с прежним описанием. По явным назначениям дополнены13 узких правил (ещё11 назначений). Часть платежей остаётся без подтверждённой статьи, видна в Выписках; пользователь продолжает их разбирать. Все22 месячных API двух фирм (январь–ноябрь) вернули200/source=fact. Отдельно проверена сохранность ручной разметки, отсутствие ошибок распределения копеек и соответствие авторазметки победителю правил.

Ранние месяцы прежде падали из-за round(None), когда финансовый результат МП ещё неизвестен. OPEX теперь сохраняет такие поля NULL и показывает доступные расходы; нулевая прибыль остаётся реальным нулём. Будущие периоды годового разнесения доступны, но перестали выбираться по умолчанию вместо текущего месяца.

Озон Банк не восстановлен: два ранних полных дампа и три recoveryБД не содержат bank_txn; девять свежих проектных дампов содержат только Альфу/Сбер. Исходников выписок в проверенных папках/Dropbox/Git не найдено. Старый импорт не сохранял файл, только операции в БД. Историческая загрузка по документации подтверждается, но доступных данных для повторной загрузки нет. Нужны исходные выписки или повторная выгрузка из банка. Отдельные МС-документы не подменяют банковскую выписку.

Для новых подтверждённых загрузок добавлено приватное архивирование исходного файла до записи операций, по sha256 с метаданными и атомарной записью. Dry-run файлов не пишет, повтор не создаёт дубликатов архива. UI сообщает сохранено ли правило, и показывает ошибку при сбое HTTP/сети.

34 регрессионных теста прошли, проверены живые API. Штатное расписание сохранено. Никаких платежей/записей МС или изменений margin_by_sku; коммит/push не выполнялись. Артефакты .private/opex_year_restore_20261110/.
