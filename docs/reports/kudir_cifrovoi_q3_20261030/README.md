## Сверка с данными Пульта: открытые расхождения

Для Ozon взята сумма `amount + bonus + bank_coinvestment +
pick_up_point_coinvestment + stars` официального отчёта о реализации
минус возвраты по тем же компонентам. Для WB — продажи минус возвраты
финансового отчёта. Для Маркета — выручка минус возвраты из финансовой
витрины. Это **управленческие и площадочные величины, не готовая налоговая
база**: период признания, НДС, баллы/субсидии и зачёты нужно сверять
по первичным документам.

Разница Ozon за квартал по этой методике 14 894 631 ₽. Она близка по
масштабу к колонке `bonus` («Баллы за скидки») отчёта о реализации; без
разбора её налогового смысла, НДС и зачётов нельзя ни добавить её в КУДиР,
ни признать книгу полной. [ФНС разъясняет](https://www.nalog.gov.ru/rn31/news/seminar/16585481/),
что для УСН доход от маркетплейса определяется по сумме, полученной от
покупателя агентом, а возмещение скидки площадкой учитывается отдельно;
это основание для сверки, не автоматическая корректировка книги.

По банку Цифрового в Пульте есть 714 транзакций за квартал. Из 174 строк
КУДиР с явным номером документа 142 находят документ с теми же датой и
номером в `bank_txn`. Ещё 31 июльская строка «Прочие поступления» на
90 120,27 ₽ отсутствует в нашей банковской выгрузке даже при поиске по
дате и сумме; в КУДиР они **есть**, значит это пробел сверки банковского
источника, а не доказанный пропуск дохода в книге. Одна дополнительная
строка без банковской пары — налоговая корректировка на −1 814,90 ₽.
