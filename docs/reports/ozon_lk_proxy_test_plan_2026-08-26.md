# Тест мобильного прокси под ЛК Ozon — что заказать и что делаем в два часа

Поток `rev`. Согласовано 26.08.2026: Proxy Seller, бесплатный двухчасовой тест; деньги за месяц —
только после вердикта «канал годится». Оплату проводит Сергей, сессия ничего не покупает.

## Почему вообще прокси

С сервера Ozon недостижим: адрес `155.212.189.66` (Beget, AS198610) забракован на входе — петля
`?__rr=1..5` и JS-челлендж `fab_chlg_…`, который не решается. Это не автоматизация: так же
блокируется покупательский `www.ozon.ru` и голый `curl`. Релей (Нидерланды) отпал — `403 Filtered`,
белый список только под OpenAI. Мобильный операторский адрес — единственный путь, оставляющий
браузер на сервере, то есть автономный.

## Что заказать (спецификация порта)

- **Тип: индивидуальный (приватный)**, не shared. На общих режут скорость и делят репутацию.
- **Регион: Москва** — совпадает с регионом продавца.
- **Оператор:** МТС или Билайн (годится любой из большой четвёрки, важен реальный операторский ASN).
- **Ротация: ВЫКЛЮЧЕНА.** Смена IP только вручную по ссылке. Прыгающий адрес рвёт сессию ЛК.
- **Протокол: обязателен HTTP(S)-порт** (мерялка ходит через него). SOCKS5 пусть дадут заодно.
- **Авторизация: логин/пароль** — проще. Если провайдер даёт только белый список, продиктовать ему
  наш адрес `155.212.189.66`.
- **Трафик: безлимит.**

Выданный адрес класть **в `.env` строкой `OZON_PROXY_URL=схема://логин:пароль@хост:порт`**.
В чат не присылать: инструменты читают файл сами и значение нигде не печатают.

## Регламент двух часов

Часы идут с момента выдачи. По шагам:

| Время | Действие | Команда |
|---|---|---|
| 0:00 | адрес в `.env` ключом `OZON_PROXY_URL` | — |
| 0:02 | вердикт по каналу | `./venv/bin/python tools/ozon_lk/probe_ip.py --browser --proxy-file .env` |
| 0:05 | если БЛОК — сменить IP по ссылке провайдера и повторить (до 3 раз) | — |
| 0:10 | поднять показ браузера | `./tools/ozon_lk/session_view.sh start` |
| 0:12 | туннель и VNC на своём компьютере | `ssh -L 5900:127.0.0.1:5900 root@<сервер>` |
| 0:15 | вход в ЛК руками (логин, пароль, СМС) | `DISPLAY=:99 ./venv/bin/python tools/ozon_lk/recon.py --login --proxy-file .env` |
| 0:30 | погасить показ | `./tools/ozon_lk/session_view.sh stop` |
| 0:35 | снять форму ответа с живого отзыва | `./venv/bin/python tools/ozon_lk/recon.py --review-url "<ссылка>" --proxy-file .env` |
| 1:00 | разбор отчёта, план транспорта | — |

Ссылку на отзыв брать из `docs/reports/ozon_lk_manual_reviews_2026-08-24.md` (21 отзыв с готовыми
ответами).

## Что считаем результатом

- **Годен:** `probe_ip` даёт «канал годится», вход прошёл, `recon` снял селекторы формы ответа.
  Тогда покупаем месяц (до 2 500 ₽) и пишем транспорт.
- **Не годен:** блок держится и после двух-трёх смен IP. Тогда пробуем другого оператора или
  провайдера — тоже тестом, не покупкой.
- **Отдельно фиксируем:** держится ли сессия после смены IP. Это решает, нужен ли порт без ротации
  навсегда и как часто потребуется человек с СМС.

## Границы

Вход в ЛК — единственный шаг, где нужен человек: Ozon подтверждает вход по СМС. Дальше сессия живёт
в профиле на сервере. Транспорт ответов в этот тест НЕ входит: разведка только читает, отправка
ответов на площадку — отдельная прямая команда Сергея.
