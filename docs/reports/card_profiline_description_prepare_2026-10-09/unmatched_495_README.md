# Профилайн: почему495 карточек не вошли в запись

Источник: полный API-каталог09.10 22:36, все8333 предложения без ограничения остатка. Карточки МС из живого снимка перед запуском. Это исключения сопоставления артикула, а не495 доказанных различий названия.

494 артикула МС отсутствуют среди vendorCode API при допустимой нормализации регистра/пробелов; у одной из этих карточек артикул пустой. Ещё1 артикул даёт2 разных товара API.

Для494 отсутствующих:9 имеют кандидатов, отличающихся только пунктуацией;263 — похожие артикулы с порогом0.85;221 — кандидатов с этим порогом нет;1 пустой артикул. Ни совпадение после удаления знаков, ни похожесть строки не подтверждают идентичность товара: проверить бренд, модель, ресурс, цвет, чип, тип и штрихкод. Совпадений штрихкодов МС с barCode API не найдено. Отсутствие артикула в API не доказывает снятие товара с производства или нулевой остаток.

Неоднозначность: внешний код4488, артикул `GP_W2013X_M_TNR` в API использован дважды: GP-W2013X/№659X/Magenta/29000 копий (штрихкод4680094709025) и GP-W2013A/№659A/Magenta/13000 копий (штрихкод4680094712087). У обоих остатки0/0. Требуется проверить, какой товар соответствует карточке МС; автоматический выбор запрещён.

`unmatched_495_detailed.csv` содержит все495:MS id, внешний код, артикул, поставщика, Наименование и Описание МС, причину исключения, штрихкоды, найденные кандидаты с полными названиями и остатками. То же в JSON; сводка `unmatched_495_summary.json`. Сходство артикула — исключительно подсказка, ни одна из495 карточек в текущий прогон записи не добавлена.
