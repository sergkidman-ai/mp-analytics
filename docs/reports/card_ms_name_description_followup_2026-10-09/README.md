# Задача на потом: Наименование и Описание в МС

Записана по команде Сергея09.10.2026. Статус: backlog, срок не задан; уведомление в Telegram не назначалось.

Проверить активные карточки МС всех поставщиков по очереди: согласованность сведений о чипе, цвете, ресурсе и типе товара в Наименовании и Описании. Сравнивать признаки по смыслу, а не буквальное равенство. Выделять противоречие, признак только в одном поле, отсутствие в обоих и неоднозначность. Молчание не означает отсутствие чипа; обычный чип и чип без счётчика различать.

Для спорных случаев сверять актуальный источник поставщика по точному артикулу; ресурс проверять вместе с единицами. Если понадобятся изменения Чипа в ТК, проверять набор и все компоненты по свежему составу. Подготовить реестр расхождений и предложения человеку. Автоматические изменения не разрешены этой задачей.

Внутреннюю сверку двух полей МС не ограничивать остатком; условие положительного остатка поставщика для прямого основания в текущей волне Чипа сохраняется. Машинная карточка задачи: `task.json`.
