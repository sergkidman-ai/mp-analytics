## Правила первой волны

1. Заполняем только пустые Длина, см.; Ширина, см.; Высота, см. Сейчас у всех 78 пусты все три поля. Уже заполненные значения и прочие атрибуты не меняем.
2. Только собственный источник поставщика и точное совпадение артикула (регистр и пробелы по краям нормализованы). Никакой подстановки коробки другого бренда, наследования или расчёта размеров.
3. Кактус — только ИУ, не МК. Сакура — явные поля коробки соответствующего листа. Изипринт — лист картриджей с единицей мм; чернила с неясными единицами исключены.
4. Если на один артикул источника приходятся разные тройки размеров — отложить, а не выбирать одну. Идентичные повторяющиеся строки сохраняются как несколько указателей одного значения.
5. При сравнении того же внешнего кода у других поставщиков стороны сортируются для сопоставления ориентаций. Сильное отличие: хотя бы по одной стороне одновременно больше 10% от меньшей стороны И больше 1.5 см. Это предлагаемый порог согласования.
6. Исходники других поставщиков — независимые свидетельства. Уже заполненные поля МС — дополнительный стоп при конфликте, но не доказательство правильного размера. Автоматического выбора «победителя» нет.
7. Дополнительные консервативные границы первой волны: сторона <1 см или >100 см, либо короб >25 л — отдельно на разбор. Это фильтр сомнений, а не утверждение, что все такие размеры неверны. Объём используется только для отбора, не для создания размера.
8. Исключены наборы/комплекты до отдельной проверки общей индивидуальной упаковки, брак, повреждённая упаковка, стоп-лист, чёрный список. Оригиналы Рапида не включены согласно предыдущему решению пользователя. SF-T9451Bk/3065 остаётся подозрительным.
9. Размеры конвертируются из явно указанных мм/м в см. Порядок сторон из исходника сохраняется. Для чисел Excel удаляются только хвосты сериализации сверх его 15 значащих цифр; округления до целых сантиметров нет. Исходные значения и указатели сохранены.
10. Рапид: подходящих новых пустых карточек для этой волны нет после ночной записи. Спринт, Профилайн, Булат и остальные поставщики — отдельные следующие этапы; новый сбор сайтов/уточнение единиц в первую волну не входят.
