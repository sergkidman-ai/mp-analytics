## Четыре исключения

| Площадка и заказ | Внешний код МП → базовый код | Причина пропуска |
| --- | --- | --- |
| WB `6176190006` | `6624 → 6624` | Нет наличия на складе заказа и нет подтверждённой закупочной цены ни у одной подходящей текущей карточки МС; нельзя выбрать самый дешёвый вариант. |
| WB `6176699856` | `1222 → 1222` | Нет наличия и нет подтверждённой текущей закупочной цены подходящей карточки. |
| Ozon `93364143-0132-1` | `6418 → 6418`, `21671 → 2167` | Две позиции; для `6418` нет доступного остатка и подходящей карточки поставщика с подтверждённой текущей ценой. Частичный заказ не создавался. |
| WB `6176952570` | `02741 → 0274` | В WB Statistics API нет однозначной строки `priceWithDisc` по `rid/srid`; полную сумму продавца подтвердить нельзя. |

Режим batch10 ограничен этими десятью номерами. В середине WB Statistics API вернул 429 до POST для `6177156618`; после восстановления лимита повторно проверены источники и созданы только два оставшихся разрешённых заказа. Повторов POST и дублей не было. Следующие заказы в эту партию не включались.
