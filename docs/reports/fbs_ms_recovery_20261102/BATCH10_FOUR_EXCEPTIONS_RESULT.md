# Четыре исключения первой партии — дополнительный импорт

По последующим прямым уточнениям пользователя три известных набора записаны
цельными карточками `msk`, без разложения на неподтверждённые компоненты.
Для четвёртого заказа WB пользователь отдельно разрешил цену из ЛК/Orders API
и карточку `0274t2`, так как `0274msk` в МС нет. Все четыре номера перед POST
повторно проверены по API площадки и точному поиску МС; один POST на документ,
intent/response/readback с правами 600 в `msk_sets/` и `batch10/`.

Независимый GET МС подтвердил точные номера, позиции, суммы, НДС 5% внутри
цены, Цифровой/Звездный/правильного контрагента, статус «Ожидает подтверждения»,
пустую плановую дату и отсутствие связанной отгрузки на момент проверки.
МС автоматически зарезервировал позиции. После создания API WB подтвердил
`new/waiting` для двух наборов, API Ozon — `awaiting_packaging`; маркетплейсы
импорт не менял. Для последнего WB статус `new/waiting` подтверждён непосредственно
перед POST; последующее отдельное чтение МС подтвердило результат.

Состав компонентов наборов по внешним кодам всё ещё не установлен: на временном
VPS нет `CARTRIDGE_API_KEY` и локальной БД справочника. Наборы сохранены цельными
позициями для ручного разбора, как разрешил пользователь. Следующие заказы и
расписания не запускались.
