Тот же сервис запускает `ops.fbs_ms_post_import_status --apply` через
`ops.fbs_ms_import_pipeline` после загрузчика, даже если отдельный заказ в

любой из шагов. Шаг обрабатывает
**только** документы загрузчика, которые в момент проверки ещё имеют точный
статус «Ожидает подтверждения», и не создаёт отгрузки. Если все текущие
позиции физически доступны на складе заказа с учётом своего и чужих резервов,
ставит «Подтвержден». При нехватке ставит «Неукомплектован» только если
сохранённый журнал импорта доказывает выбор карточки по актуальной закупочной
цене, а состав и карточки заказа не менялись. Наборы/ручной выбор, неоплаченные,
уже обработанные и изменённые сотрудниками заказы пропускает.

Плановая дата для подтверждённых: 03.11 до 03.11 12:00 МСК, затем 05.11;
для неукомплектованных — 05.11 сразу, поскольку 04.11 выходной. С 05.11
до 16:00 МСК план на текущий день, после 16:00 — на следующий календарный.

Расписание использует прямые API пяти доступных кабинетов, курсор с 2 часами
перекрытия и не более 10 новых заказов за проход. Уже подтверждённые номера
хранятся локально; неизвестные сверяются с МС по всем статусам. Перед каждым
POST повторно читаются статус площадки, точный номер МС, карточка и остаток.
POST однократный с закрытым журналом intent/response/readback; неопределённая
попытка не повторяется автоматически. Текущие закупочные цены кэшируются только
пока перечень актуальных оприходований не изменился. Отменённые заказы и WB
`declined_by_client` не импортируются. Курсор продвигается лишь после полного
разрешения окна; при ошибке заказ остаётся для следующего прохода или ручного
разбора. Состояние и последний результат в закрытом `all_import/schedule/`,
права файлов 600; секреты не выводятся.

Команды проверки на VPS:

```bash
systemctl list-timers fbs-ms-import.timer --no-pager
systemctl status fbs-ms-import.service --no-pager
journalctl -u fbs-ms-import.service -n 50 --no-pager
```

Остановить только это расписание: `systemctl disable --now fbs-ms-import.timer`.
Отгрузки, изменения статусов маркетплейсов, поставки WB и другие службы
таймер не запускает. При восстановлении старого VPS локальная блокировка
защищает только этот сервер; перед каждым созданием остаётся точечная
сверка МС, но атомарной уникальности номера в МС интеграция не обеспечивает.
