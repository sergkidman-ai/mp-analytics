# Сторож нагрузки склада — расчётная версия 09.11.2026

Поток fin. Источники МС только читаются; нет отправки сообщений, изменения
закупок, заказов, остатков, смен или статусов маркетплейсов. Регулярный запуск
не включён. Защищённый отчёт:
https://bi.beyindi.com/reports/warehouse-load-2026#warehouse-watch

## Запуск

```bash
./venv/bin/python -m ops.warehouse_load_watch --date 2026-11-10 --refresh --publish
```

Без `--date` берётся завтра по МСК. По умолчанию создаётся отдельный каталог
`.private/warehouse_load_watch/<дата>_<время-среза>`. `--output` позволяет задать
его явно. Не переиспользовать каталог для нового среза: хранить историю планов.
Без `--refresh` расчёт повторяется по snapshot.json из заданного каталога.
`--publish` обновляет только секцию существующего статического BI-отчёта;
маршрут, авторизация и службы не меняются. Полные исходники остаются в .private.

Параметры: `--finish 18:00` (пока предположение, не утверждённое время смены);
`--large-extra-minutes N` — измеренная добавка на крупный заказ, не множитель
и не размер короба. Без замера добавки нет и это явно показано как ограничение.
В отчёте есть интерактивный калькулятор для условных сценариев.

## Что считается

Два юрлица; только физические собственные склады по UUID. Плановая дата
purchaseorder/customerorder и дата документа supply. Полные позиции, без услуг.
Остаток PO считается построчно quantity-shipped. Связанные приёмки не суммируются
с PO второй раз. Самостоятельные непроведённые приёмки на целевую дату добавляются.
Непроведённый PO включён в видимый план и не называется подтверждённой поставкой.
Статус «Закрыт» PO не заменяет проверку полученного количества.

Очередь: «Неукомплектован», отдельно «Подтвержден», без связанных отгрузок.
Это не проверка текущих остатков/резервов и не доказательство покрытия закупкой.
Нужен отдельный расчёт покрытия по складу, точному внешнему коду, чужим резервам,
целым наборам и всем компонентам; общий объём запаса его не заменяет.

K = человеко-минуты очереди / человеко-минуты до целевого окончания.
Три упаковщика × 15 заказов/час. Крупный заказ учитывается один раз; при известном
замере добавляется его дополнительное время. Будущие заказы, приёмка, наборы,
перерывы и неуказанная работа не входят. Это коэффициент условной очереди,
не готовая вероятность задержки и не полный калиброванный коэффициент дня.
Фактическое время готовности включает приёмку ЦК, обработку МС и печать.
Равномерная готовность всей очереди в заданное время — открытое допущение.

Габариты: только точное совпадение MS UUID в проверенном собственном источнике
поставщика из аудита 15.10.2026, без дефектов. Изипринт/Сакура/Рапид/Кактус.
Никакой синтетики, переноса размеров между поставщиками, восстановления по модели.
Сигнал крупного короба: сторона ≥40 см или объём ≥10 л. Порог не норма времени.
Неизвестные размеры показаны отдельно. «Бандл» — только явный атрибут МС;
отсутствие флага не исключает цветовой набор. Несколько строк не доказательство набора.

Связь не доказывает задержку машины: включает длительность самой приёмки.

Хронологическая проверка 148 дней: обучение только на предыдущих 60 днях,
признаки день недели с/без объёма. MAE 54.8 → 38.5 мин.
Использован фактический принятый объём, не снимок закупки накануне: это проверка

этим же ошибкам ещё требует независимой будущей проверки. Интервал 10–90%
остатков — описательный диапазон ошибок, не калиброванная вероятность приезда.
