# Спринт → размеры МС: подготовка 14.10.2026

Записей в МС, ТК и маркетплейсы нет. Подготовлен read-only проект дозаполнения.

Область: 848 активных товаров в 9 текущих оприходованиях `s_print_msk_2026-10-14` на удалённом складе. Текущих документов `s_print_spb` при двух проверках не найдено. Это покрытие выбранных оприходований, а не всех 3474 активных карточек группы Спринт. Пользователю задан необязательный вопрос об области; до ответа применён прежний принцип проверки по текущим оприходованиям. Состав документов повторно проверен, ID не изменились.

МС прочитан 14.10 около 14:38 UTC; страницы поставщика собраны после авторизованного входа в этом же прогоне. Точные времена и ссылки сохранены по каждому товару. Сопоставление по числовому коду `SP<код>[_MSK]`, совпадение кода на странице обязательно. Размеры только основного товара, рекомендации исключены.

В МС используются дополнительные строковые поля «Длина, см.», «Ширина, см.», «Высота, см.». Источник — «Габариты, мм» Спринта. Перевод мм→см выполнен делением на 10 без округления. Порядок сторон сохранён: первая→длина, вторая→ширина, третья→высота; он точно совпадает с уже заполненными полями 832 карточек. В самой таблице Спринта оси отдельно не подписаны. Размеры не сортировались и не рассчитывались по объёму или аналогам.

Две позиции исключены из проекта загрузки: 5519 / SP353616_MSK (W1420A) и 5875 / SP353617_MSK (W1420X). Источник у обеих — `9x88x305` мм, то есть `0.9×8.8×30.5` см. Сторона 9 мм у лазерного картриджа требует уточнения. Это флаг проверки, а не доказанная опечатка; заменять 9 на 90 без подтверждения запрещено. Исходные данные сохранены.

Файлы:

- `sprint_dimensions_review.xlsx` — итог, все 848 карточек, 14 для дозаполнения, 2 на проверку.

- `upload_fill_empty_preview.json` — 14 проектов payload, сохраняющих весь массив остальных атрибутов. Не является разрешением на запись. Перед отдельной командой записи необходим свежий GET и повторный контроль пустых полей и идентичности товара.
- `preview_dimensions.json` — логические изменения только размеров для тех же 14 товаров.
- `supplier_cards/` — извлечённые характеристики с URL и временем; секреты и cookies не сохранялись.
- `ms_attribute_metadata.json`, `receipt_cards.json`, `current_positions_expanded.json` — слепки МС.
- `candidate_live_verification.json` — повторный GET всех 16 первоначально пустых карточек: размеры оставались пустыми, карточки активные, артикулы совпали.
