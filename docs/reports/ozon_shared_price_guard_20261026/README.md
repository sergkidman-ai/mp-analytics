# Сторож Ozon: общая предельная цена, 26.10.2026

Ветка `mkt/ozon-unified-price-guard`, отдельный worktree. Первоначальный сухой прогон не менял Ozon; после прямой команды пользователя код установлен в `/opt/mp-analytics` и выполнен рабочий запуск. Расписание не менялось.

## Что исправлено в ветке

- Для действующих пересекающихся акций одного товара рассчитывается одно значение общей предельной цены. При экономическом пороге не выше порога акции товар остаётся в ней; иначе ожидается выход. На товар отправляется не более одной исходной записи через `/v1/actions/products/update`, затем проверяются все затронутые действующие акции и общая цена через `/v5/product/info/prices`.
- Если первый запрос явно отклонён или после подтверждения цена продажи ниже экономического порога, допускается одна запасная запись для вывода товара из действующих акций. При тайм-ауте и при расхождении общей цены с целевой автоматический повтор не выполняется: возможна другая параллельная запись.
- Лимит `--limit` применяется к товарам, поэтому связанные строки акций одного товара не разделяются. Неоднозначное пересечение (разные текущие цены, неизвестный порог, неподдерживаемый тип акции) уходит на проверку без записи.
- Будущие акции не сравниваются с текущей ценой продавца как с будущей акционной. Исходный `action_price` сохраняется отдельно. Если он ниже экономического порога, сторож показывает внешний код, лимит, порог и текущую общую цену, но не меняет цену до начала акции. Если общая цена выше порога акции и сохранится, ожидается автоматический выход; это проверяется после старта.
