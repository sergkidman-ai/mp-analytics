## Исправление кода

- Новый `collectors/yandex_finance_basis.py`: сохранённые/resumable report jobs, ограниченные запросы/повторы, полное покрытие кампаний/страниц, сверка, Decimal, отдельные статусы и атомарные записи под блокировками. Запросы с ошибками не публикуют complete.
- run_daily собирает отдельное проверенное report-evidence перед monthly. Evidence не переключает `active.json`. Старый partial closure не заменяет проверенные календарные PAYMENT/REFUND при последующем recompute/collect.
- `recompute(..., until=..., preview=True)` позволяет пересчитать только сентябрь без DB writes, с существующим COGS. Два пересчёта идентичны. Точечные updated_at ограничены фактически пересчитанными месяцами.
- Freeze хранит отдельно календарное закрытие, бухгалтерский provisional и пригодность. Страница показывает источник и ожидание closure. Изолированные `hist_candidate.json` и `report_preview.html` сформированы; живые файлы не опубликованы.
- Ценовые читатели Маркета используют отдельный активированный snapshot: собственные месяц/источник/версия, без UI hist и без молчаливого отката на август. При отсутствующей/непригодной базе Yandex guard/push останавливаются до записи, карантин пропускает Маркет с явным сообщением и сохраняет WB/Ozon. Все provisional больше не выбирают последний partial.
- Изменения интеграции guard/push ограничены финансовым источником, точностью и явным исключением 7200. Стратегия акций не менялась. Чужие локальные изменения quarantine сохранены в общем checkout и baseline; в коммит включён только финансовый патч.
- Ветка перенесена на актуальный удалённый origin/main `067c10b` после проверки ls-remote. Цепочка SKU COGS повторно прочитана с актуальными исправлениями WB bundles; изменился один SKU, 6982. Эти чужие исправления в собственные коммиты не включены.
