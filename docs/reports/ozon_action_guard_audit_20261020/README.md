## Почему нет нового исключения после уведомления

1. События заказов/customer_guard_incidents не подключены к запуску action guard.
   Customer runtime пишет/уведомляет о проверке, action guard по cron читает только
   текущих участников акций. Уведомление Наталии не является запросом на исключение.
2. После уведомлений ещё не было планового запуска; дневные до них сорвались
   в snapshot oz_acc1. Дляoz_acc2 этих запусков нет ни решения поSKU, ни запроса
   изменения участия, ни ответаAPI. Нельзя называть это «Ozon отказал снять».
3. Сейчас снимать эти4товара из указанных акций нечего.0328/1262 уже сняты нашим
   сторожем18.10.0447/1265 сейчас также отсутствуют, но история их участия/исключения
   не восстановлена: никаких положительных доказательств участия в журнале нет.
   Низкая цена здесь остаётся обычной ценой карточки, не текущей скидкой этих акций.
4. Правило action guard предусматривает поднять акционную цену до пола, если позволяет
   потолок; иначе снять, с проверкой результата. Даже новый заказ ниже пола сам по себе
   не обязывает всегда удалять товар при таком алгоритме. Цена вне акции им не исправляется.

весь main, включая следующий кабинет. Сегодня не завершились два дневных запуска;

Минимальная правка отдельной задачей: зафиксировать action_id/requestcursor/response
при сбое, воспроизвести новый контракт last_id/total/пустойстраницы, исправить завершение
пагинации без принятия неполного списка за полный; изолировать ошибку кабинета,
чтобыoz_acc1 не блокировалoz_acc2, и явно уведомлять об аварии прогона.
Исторические сырые ошибочные ответы не сохранены: по traceback нельзя утверждать,
был ли это пустой ответ с ненулевым курсором или повтор ранее виденного курсора.
Оба случая сейчас объединены в одной ошибке ops/ozon_actions.py:85.

Если требование — автоматически действовать сразу по уведомлению заказа,
нужна явная интеграция с независимым решением по4SKU и повторным чтением API, а не
изменение порога прибыли у заказов. Если требуется поднять обычные низкие цены,
это отдельная ценовая задача: исключение из акции уже отсутствующийSKU не изменит их.
