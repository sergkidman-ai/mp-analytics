## 8. Что и где логируется (п.3 брифа)

Отдельного журнала авто-ответов НЕТ. Всё, что есть, лежит в `raw_feedback` (одна строка = один отзыв):

| что | где | есть? |
|---|---|---|
| текст отзыва | `body`, `pros`, `cons` | да |
| рейтинг | `rating` | да |
| артикул | `article` | да у WB; у Ozon пусто (та же дыра, что и по вопросам) |
| площадка/аккаунт | `platform`, `account` | да |
| товар, карточка | `product_name`, `item_id` | да |
| дата отзыва / черновика / публикации | `created_at`, `draft_at`, `posted_at` | да |
| маршрут и уверенность | `draft_route`, `draft_confidence`, `draft_category` | да |
| **какой шаблон подставлен** | — | **НЕТ идентификатора**; хранится только готовый текст `draft_text` и человекочитаемая пометка `draft_grounding->>'note'` |
| факт публикации | `posted_ok`, `is_answered`, `answer_text` | да |
| повторы отправки | `feedback_send_attempts` (attempts, last_error, blocked) | да |

Глубина: сами отзывы собраны с **2024-05-09**, но черновики (`draft_at`) существуют только
с **2026-07-15** — то есть история решений бота ~8 недель, всё, что раньше, не размечено.

Дыры, которые мешают разбору:
1. **Нет id шаблона.** Какой именно вариант ротации ушёл, восстанавливается только пересчётом
   `_pick(variants, ext_id)` (детерминированная функция от `ext_id`) — при правке списка вариантов
   история станет невосстановимой.
2. **117 авто-строк с пустым `draft_grounding`** — по ним не видно вообще ничего, кроме текста.
3. **`article` пуст у Ozon** — топы по артикулам приходится строить по `item_id`.
4. Тип обращения (совместимость / дефект / расход) у отзывов не пишется вовсе — в отличие от
   вопросов, где есть `draft_category`.

## 9. Слепая ротация поверх содержательного текста

Отзывов, в тексте которых есть маркер проблемы (не работает / ошибка / не подошёл / брак / полосит …),
а ответ ушёл авто-маршрутом: **11**, опубликовано 9. Из них:

- **7 закрыты позитивным шаблоном-ротацией** (5 опубликовано) — то есть на «жаль, что не подошла
  к принтеру» ушло «рады, что всё подошло»;
- 4 — ответ LLM (по всему потоку авто с `llm=true` всего 8).

Примеры с текстами — `docs/reports/rev_auto_gap_examples_2026-09-07.md` (11 кейсов, кандидаты
в gold set для блока H).
