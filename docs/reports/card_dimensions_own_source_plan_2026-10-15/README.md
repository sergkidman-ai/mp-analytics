## Источник и отбор

- Кактус: исходный Excel, столбцы индивидуальной упаковки ИУ (не МК), артикул PartNo.
- Сакура: исходный Excel, поля коробки с явными единицами по листам.
- Изипринт: исходный Excel, лист картриджей, поле Размеры мм. Поле чернил без единицы не используется.
- Рапид: собственный API 14.10; новых подходящих пустых позиций не осталось. Ранее исключённые оригиналы, чёрный список и SF-T9451Bk/3065 не включены.
- Совпадение артикула точное с нормализацией регистра и пробелов по краям. Разные размеры в дублирующихся строках собственного прайса — неоднозначность, а не повод выбрать одну.
- Никакой подстановки коробки другого поставщика, наследования размеров и расчёта новых сторон. Чужие итоговые таблицы габаритов не используются.
- Чёрный список, брак, повреждённая упаковка и стоп-лист остаются исключениями области.
- Нет автоматического запрета большого короба или набора. У 364 кандидатов могут оставаться диагностические метки BOX_OVER_25L и SUPPLIER_SET_PACKAGE: они сами по себе не запрещают запись.
- Миллиметры/метры переводятся в сантиметры, порядок сторон собственного источника сохраняется. Удаляются только хвосты числовой сериализации Excel, не производится округление до целых сантиметров.

## Изменения уже заполненных полей

Прямые отличия от собственного источника отдельно проверены. Найденные 11 различий Кактуса меньше 0.005 см и точно совпадают после представления источника с хранимой точностью 0.01 см. Существующие размеры использованы только для пропуска уже совпадающих значений в этой же карточке. Они не блокируют размеры другой карточки и не служат подтверждением правильности источника.

## Ошибки и исключения самого источника

Из первоначальных 382 кандидатов отложены 18 строк:

- Кактус, 2 набора: CS-CLI521BK/M/C/Y (0141) и CS-CLI426BK/M/C/Y (0204). Указано 85.5×37×15.5 мм для набора из четырёх картриджей — размер похож на один компонент, общая упаковка не подтверждена.
- Сакура, SA006R01179 (0260): 43×75×75 см, тогда как в той же строке объём 0.002419 м³. Источник противоречит сам себе примерно в 100 раз; нельзя определить правильные стороны без уточнения.
- Сакура, 8 SAW2000–2003 A/X: повторяющиеся 39×39×39 см дают 59.319 л, собственное поле объёма около 10 л. Ни одна сторона не исправляется догадкой.
- Сакура, SIC13T741200/300/400/X00 (5281–5284): для литровых чернил указано 50.5×33×50 см (83.325 л), в той же строке объём 2.931 л. Индивидуальная упаковка не подтверждена.
- Сакура, SACF237A (2320): 10×10×10 см для полного лазерного картриджа, при собственном объёме 12.863 л; похоже на заглушку.
- Сакура, SADR2510 (5959): 31×90×21.5 см; сторона 90 см выглядит ошибкой единицы/десятичного разделителя для одного фотобарабана. Не заменяем на 9 см догадкой.
- Изипринт, TC-HW1106AL (6864): 52×33.5×50 см для одиночного картриджа HP107, похоже на транспортную упаковку; не переносим в поля ИУ.

Это список исключений с основаниями для проверки. Противоречие полю объёма не доказывает, какая именно ячейка неверна; размеры этих строк не считаются установленными. Объём служит только проверкой противоречия в собственном источнике, никогда не восстанавливает длину/ширину/высоту. Правдоподобные размеры не отбрасывались автоматически только из-за неправильного поля объёма.

Неоднозначные дубли, отсутствие размеров, чёрный список и остальные причины доступны на листе Отложено с источником и в review.csv.
