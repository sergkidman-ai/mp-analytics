# Дубли артикулов после прогона «кириллица в артикулах» (19.08.2026)

Разбор по вопросу Сергея 20.08.2026: как в МС попал товар с артикулом `CS-THM247`,
который в МС уже был. Разбор — читающий; запись (архив 9 клонов) сделана отдельно
по команде Сергея, см. раздел «Сделано».

## Что произошло

1. Карточка `48c2e864` «Картридж лазерный Cactus CS-THM247…», код `5742cs`, вн. `5742`,
   артикул **латиницей** — живёт с 17.08.
2. Рядом жила карточка-опечатка `a243159e` с тем же кодом `5742cs` и артикулом
   `CS-THМ247`, где `М` — **кириллическая** (U+041C).
3. 19.08 в 16:25:50 параллельная prc-сессия прогнала исправление кириллицы:
   `a243159e` ушла в архив с очисткой Артикул/Код/Внешний код, и через 150 мс была
   создана НОВАЯ карточка `7efae98b` с латинским артикулом, тем же кодом `5742cs`,
   тем же вн. кодом и тем же Code128.
4. Проверки «а нет ли уже живой карточки с таким артикулом» в этом прогоне не было.
   Поиск артикула в prc везде побайтовый и к гомоглифам слеп — латинский оригинал
   при поиске кириллического артикула не находится. Итог: вместо переименования
   получилось клонирование.

Опознавательный признак клонов: в «Наименовании» и «Коде поставщика» кириллица осталась,
исправлен только «Артикул».

## 8 пар с гомоглифами — разобрано 20.08.2026

Правило Сергея: **прайс поставщика — источник данных, его не правим.** В МС артикул пишется
ровно так, как в прайсе, иначе оприходование не встанет на «Удаленный склад». Значит из пары
остаётся та карточка, **на которой есть остаток** (её и находит матчинг прайса), остальные —
удалить из МС; что МС удалить не даёт («объект уже используется»), то в архив с обнулением
Артикул/Код/Внешний код.

Остатки: весь остаток по этим карточкам лежит ТОЛЬКО на «Удаленном складе»; на «Звездном»
и «Дисквере» (и на Озон / Москва для ФБО / СПБ для ФБО / Кантемировская / Транзит / Брак) — нули.
