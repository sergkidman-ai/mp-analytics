# Чип: проверка двух гипотез Сергея перед правкой ТК (21.08.2026)

Только слепки: `supplier_stock` (склад «Удаленный», привязки за 60 дней — 23 949 пар
код+поставщик+название, 5 230 внешних кодов), `prc_tc_model`, `set_cost`. Чип из названия —
`prices.features.chip` (уже понимает «б/ч»).

## Г1. «Товар поставщика привязан не к той карточке ТК»

Сравнил чип из названия поставщика с чипом карточки ТК, к которой он привязан:

| | кодов |
|---|---|
| совпало | 629 |
| поставщики про чип молчат | 201 |
| **часть строк не совпала (под кодом смешение)** | **13** |
| **все строки против ТК** | **3** |
| в ТК чип не заполнен / модели нет — сравнивать не с чем | 4 384 |

Гипотеза подтверждается, но масштаб маленький: **28 строк под 16 кодами** —
`prc_chip_wrong_link_2026-08-21.csv`. Отдельно: смешение комплектаций под одним внешним кодом
за 60 дней — **15 кодов из 5 230**, и **ни один из них не входит в наши 266**
(`prc_chip_mixed_codes_2026-08-21.csv` пуст).

Важно: проверка возможна только там, где чип в ТК заполнен (846 кодов из 5 230). Пока поле пустое,
кривую привязку ловить нечем — заполнение ТК и есть условие для такого контроля.

## Г2. «С чипом дороже, чем с чипом без счётчика, а тот дороже, чем без чипа»

Одна модель картриджа, соседние коды ТК с разной комплектацией, медианы закупки:

| сравнение | подтвердилось | опровергло | медиана отношения |
|---|---|---|---|
| с чипом vs без чипа | 53 | 8 | **2.24×** |
| с чипом vs с чипом без счётчика | 27 | 8 | **2.36×** |
| с чипом без счётчика vs без чипа | 14 | 11 | 1.06× |

Первая половина правила подтверждается уверенно: чиповый в 2+ раза дороже. Разницы между
«без счётчика» и «без чипа» в закупке нет — по деньгам это одна полка.

## Риск, который остаётся: «молчуны»

Под нашими 266 кодами за 60 дней 2 796 строк поставщиков. Про чип говорят **485 — и все «с чипом»**;
остальные 2 311 в названии про чип молчат. Явного «без чипа»/«б/ч» под этими кодами нет ни одного.

Проверка ценой (дешёвый «молчун» = вероятно другая комплектация):

- среди строк, которые ВСЕ говорят «с чипом» (449 кодов), строка дешевле 55 % медианы —
  у **11 %** кодов (естественный разброс брендов, медиана min/медиана = 0.78);
- «молчун» дешевле 55 % медианы чиповых (1 054 кода) — у **31 %** кодов (медиана 0.68);
- по нашим 266: **79 кодов из 209 сопоставимых, 154 строки** —
  `prc_chip_cheap_silent_2026-08-21.csv`.

Асимметрия 11 % против 31 % говорит, что часть «молчунов» — действительно более дешёвая
комплектация, а не просто бренд подешевле. Цена одна отличить их не может (бренд, ресурс,
восстановленный), но как фильтр для ручного взгляда работает.

## Что из этого следует

1. Правку ТК по 266 кодам делать можно: под ними за 60 дней нет ни одной строки «без чипа»,
   смешения нет, наборы согласованы.
2. Защита не в поле ТК, а в **гейте привязки**: при связывании строки прайса с моделью ТК
   сравнивать чип из названия — противоречие не линковать, а отправлять на разбор.
   Сегодня такой гейт работать не может: у 4 384 кодов поле в ТК пустое.
3. «Молчун дешевле 55 % медианы чиповых под тем же кодом» — рабочее правило для очереди
   на ручную проверку (154 строки в текущей партии).
4. 28 строк с явным противоречием (`prc_chip_wrong_link_2026-08-21.csv`) — чинить привязку
   (или ТК) до закупки.
