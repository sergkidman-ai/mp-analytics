## Проверка чипа перед будущей записью

Среди1205 различий11 Описаний МС явно содержат «с чипом», а новое название сайта молчит о чипе. Они вынесены в chip_information_review.csv/json:это не доказательство ошибочного чипа в МС. Перед заменой текста сверить значки/характеристики/примечания основной карточки и сохранить подтверждённую информацию. Новые значения Чипа в ТК/МС этим аудитом не устанавливаются. По одному отсутствию слова в названии нельзя считать товар без чипа.
