# Документы по странице «Печать заказов» для Дисквера

Отчёт подготовлен по структуре предыдущего отчёта: исходная задача, этапы,
оценка трудозатрат и результат. Оценка — 148 человеко-часов, не хронометраж.
Отчёт не содержит календарных дат, упоминаний второго юридического лица
и названия учётной системы.

```bash
python3 docs/reports/print_orders_diskver/render_template.py
```

Договор ПБ-05 от 11.11.2026 подготовлен на основе предоставленного ПБ-04.
Условия: 148 часов × 3 500 ₽ = 518 000 ₽; 25 календарных дней;
два платежа по 259 000 ₽. Стороны и реквизиты сохраняются из шаблона.
Отчёт и договор доставлены адресату через Dropbox-бот.

```bash
python3 docs/reports/print_orders_diskver/contract/build_contract.py \
  --template /path/to/private/PB-04.docx \
  --output-dir /path/to/private/output
```

Исходный шаблон и договор с реквизитами, а также подтверждения Telegram
хранятся отдельно от публичных исходников. Генератор не отправляет документы.
