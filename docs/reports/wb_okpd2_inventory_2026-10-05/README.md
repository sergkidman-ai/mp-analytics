Точные связи с ТК установлены для 22 839 карточек из сохранённого плана и совпадений полного внешнего кода. Для 21 644 производных артикулов связь пока не подтверждена (`wb_unresolved_tc.csv`); префикс артикула не выдаётся за проверенную связь.
