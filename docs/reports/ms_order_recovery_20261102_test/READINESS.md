## Команды для одного заказа

В существующий обработчик добавлен отдельный режим; старые `collect`, `apply`, `shipments` не изменены. Обе команды требуют **один точный номер** и не выбирают очередь:

```bash
cd /opt/mp-analytics
./venv/bin/python -m tools.customer_order_fresh_fulfillment_20261022 single-check НОМЕР_ЗАКАЗА
./venv/bin/python -m tools.customer_order_fresh_fulfillment_20261022 single-apply НОМЕР_ЗАКАЗА
```

`single-check` только читает МС и справочник ТК, сохраняет снимок в `docs/reports/ms_order_single/НОМЕР_ЗАКАЗА/`. `single-apply` требует этот снимок, повторно проверяет точный номер, статус «Подтвержден», одну товарную позицию, отсутствие набора и отгрузки, складской остаток с собственным и чужими резервами. При изменении заказа после проверки прекращает работу до записи. В статусном PUT передаёт только статус «Собирается» и плановую дату; состав, количество, цены, склад, организацию и контрагента не передаёт. После чтения результата ждёт не менее пяти минут и использует существующий `shipments` для проверки связанных/одноимённых отгрузок и создания ровно одной при необходимости. Intent/response/readback сохраняются, повторная попытка при существующем intent блокируется. Если другой процесс уже изменил статус или создал отгрузку до первого PUT, заказ пропускается.

**Обязательная предпосылка:** `CARTRIDGE_API_KEY` был пуст при последней проверке. Режим намеренно блокирует заказ, пока не сможет подтвердить по ТК, что SKU не является комплектом. Наличие ключа перед боевым запуском здесь повторно не проверялось. Параллельный внешний обработчик не выявлен и не отключён; сотрудников нужно попросить оставить конкретный номер за нами. Между последним GET и PUT МС нет атомарной блокировки внешней системы, поэтому даже после проверки гонка теоретически возможна.

На маркетплейсах новый режим **не выполняет действий**. Он не переводит Ozon или Яндекс Маркет в какой-либо статус и не добавляет WB-заказ в поставку. Сопоставление заказа МС с кабинетом площадки этим режимом пока не автоматизировано; перед боевым применением его требуется подтвердить отдельно. Для Яндекс Маркета отдельный переход именно к «сборке» не подтверждён; переход в «Готов к отгрузке» не выполняется.
