# Заказы МС «Неукомплектован» — чтение 02.11.2026

Метаданные МС подтвердили точное название статуса. Очередь менялась во время чтения: 98 → 95 → 94 документа; итоговый срез не является атомарным. Из 94 заказов 26 имеют более одной товарной позиции, 68 — одну товарную позицию без уже связанной отгрузки. Для каждого из 68 прочитан остаток исходной карточки именно на складе заказа; физическое наличие с учётом всех резервов и собственного резерва не обеспечило требуемое количество ни для одного. Пример проверки `0100887007-0412-1`: количество 2, собственный резерв 2, физический остаток 0, общий резерв 2 — физического товара нет. Срез и причины в `uncompleted_stock_preflight.json` (600).

Подходящего заказа для тестового перевода в «Собирается» и создания отгрузки в текущем срезе нет. МС и маркетплейсы по этой задаче не изменялись. Карточки других поставщиков с тем же внешним кодом не подставлялись; состав набора без текущего справочника ТК не считался подтверждённым. Массовый запуск не выполнялся.

Официальный API Яндекс Маркета переводит `PROCESSING/STARTED` в `PROCESSING/READY_TO_SHIP` только после подготовки к отгрузке; это более поздний этап, чем «Собирается». Искусственный переход не выполнялся. Для Ozon/WB действий не было из-за отсутствия тестового кандидата МС.
