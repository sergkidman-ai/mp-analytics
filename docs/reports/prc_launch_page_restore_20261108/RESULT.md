# «Новинки → Запуск на МП»: восстановление отображения данных, 08.11.2026

Причина пустой страницы: API отбирал только модели с подтверждённой датой первого появления в МС. После переноса базы таких дат сохранилось 3. При этом наблюдения по 6723 моделям и пяти витринам (33615 записей) в БД были целы; 6654 действующие модели без дат полностью исключались из списков.

Восстановлено отображение существующих наблюдений отдельным блоком «Сохранённые размещения без даты заведения». По умолчанию показаны 331 модель с незавершённым размещением, доступен весь набор из 6654. Есть поиск кода/названия, переключение на все модели, пагинация по 100 строк и фильтр поставщика. Выводятся текущие сохранённые статусы пяти витрин, остатки, отгрузки и первая продажа. Отдельная сводка даёт состояния всех действующих моделей без даты.

Поставщик отсутствует во всём сохранённом supplier_stock. Для восстановленного блока группы получены из ссылки supplier сохранённых сырых карточек МС и действующего справочника поставщиков: 14 групп. Если у модели несколько поставщиков, они все выводятся и участвуют в фильтре.

Дата переноса/UUID/первая продажа не используются как выдуманная дата запуска модели. Отсутствующие даты явно показаны как «дата не восстановлена»; эти модели не попадают в когорты по месяцам и расчёт времени запуска. Три подтверждённые исторические даты и остальные наблюдения не изменены. По умолчанию окно датированных моделей — «всё, что знаем», поэтому три сохранённые модели видны сразу.

Данные БД при восстановлении страницы не переписывались; запросов записи в МС/МП, платных исследований и уведомлений не было.
