# Сверка статусов заказов МС с маркетплейсами, 02.11.2026

Область: существующие заказы покупателей МС с датой `moment` от 01.09.2026
до 30.11.2026 включительно и текущим статусом «Собирается» или «В пути».
Проверяются Ozon ACC1/ACC2, WB ACC1/ACC2, Яндекс Маркет ACC1. Два прямых
заказа МС исключены. Состояние МС и маркетплейса перечитывается перед каждой
записью. Товары, суммы, отгрузки и статусы маркетплейсов не меняются.

Сопоставление: подтверждённая передача перевозчику/доставка до пункта выдачи
→ «В пути» (только из «Собирается»); доставлено → «Доставлен»; отменено →
существующий статус МС «Отменен - сроки» (название в МС отличается от
формулировки «Отмена-сроки» в поручении). WB `complete:waiting` не считается
передачей перевозчику. Без точного статуса площадки заказ не меняется.

Предпросмотр без записей: 1 140 заказов МС, из них 1 138 маркетплейсов.
По текущему API 182 потенциальных перехода в «В пути», 221 в «Доставлен»,
29 в «Отменен - сроки»; 702 без перехода, 4 заказа Маркета API не вернул.
Цифры не являются результатом записи: люди и площадки могут изменить заказы
до запуска. Построчные проверки и результаты находятся в `journal.jsonl`.

Разовый запуск запланирован systemd таймером
`ms-market-status-sync-20261102.timer` на 02.11.2026 20:15 UTC
(23:15 МСК). Перед первой записью и после 200 изменений проверяется
успешное состояние штатного импортёра FBS; при неисправности — стоп.
Ночной исполнитель ограничен 3 000 изменениями в час и 1 200 за запуск,
после первых 200 делает паузу 10 минут. Каждая запись имеет отдельное
намерение, результат API и перечитку МС. При неопределённом PUT он
останавливается без слепого повтора.

Команды ручной проверки после запуска:

```bash
systemctl status ms-market-status-sync-20261102.service --no-pager
journalctl -u ms-market-status-sync-20261102.service --no-pager -n 30
tail -n 3 docs/reports/ms_market_status_sync_20261102/journal.jsonl
```

Фактический запуск 02.11 в 20:03 UTC: после 200 подтверждённых изменений
выполнены пауза 10 минут и контрольные чтения, затем проход продолжился.
Всего 406 PUT получили HTTP 200 и подтверждены повторным GET МС. Пять
заказов с непроверенным статусом площадки пропущены без изменений.
В 20:53 UTC PUT по Ozon `0241251301-0133-1` завершился ReadTimeout;
исполнитель остановился с кодом 1 без повторной записи. Немедленный и
последующий точечный GET МС показали прежний статус «В пути» (намерение —
«Доставлен»). Этот заказ оставлен для отдельного разбора; оставшиеся
кандидаты после остановки не обрабатывались. Разовый timer отключён,
автоматического повторного запуска нет. Свежий срез кандидатов сохранён в
закрытом `prewrite_*.json`, намерения и ответы — в закрытом `journal.jsonl`.
