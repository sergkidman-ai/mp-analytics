## Рапид

Свежая API-выгрузка, дата поставщика `2026-10-14 17:53:35`. `GabarityDlina`, `GabarityShirina`, `GabarityVisota` передаются в метрах; единицы подтверждены существующим `collectors/rapid_dims.py` и совпадением всех 325 заполненных карточек после ×100 в сантиметры. Расчёт размера из объёма не используется. Наименования осей явные, перестановки нет.

448 карточек имеют три положительных размера: 325 точно совпадают с МС; 123 имеют пустые поля МС. Из последних 122 подготовлены, одна исключена как подозрительная:

- 3065 / SF-T9451Bk, EPSON T9451 WorkForce Pro M5210/M5710. API сообщает `0.029 × 0.013 × 0.04` м = **2,9 × 1,3 × 4 см**, вес `0.1` кг. Требуется проверка поставщика. Размер не исправлялся и не выводился из веса, объёма или аналога.

У остальных 958 выбранных товаров нет полного комплекта подходящих размеров; их поля не заполняются. Итоговый проект — 122 карточки, 366 пустых полей. Существующие значения и прочие атрибуты сохранены. Перед будущей отдельной командой записи требуются свежий источник, GET и проверка пустоты/идентичности; этот отчёт разрешением не является.

## Булат

XML-фид `2026-10-14 04:30` не содержит отдельных полей длины, ширины, высоты или габаритов упаковки. Описания всех 2653 сопоставленных товаров также проверены на упоминания размеров. Две найденные позиции JFEP0ERC31020 и MFBRPTH110010 описывают ширину и длину красящей/маркировочной ленты, а не короб: их не использовать для полей Д×Ш×В. Контрольная попытка чтения страницы тонер-картриджа на сайте вернула HTTP403. Утверждение ограничено доступным фидом: наличие размеров в иных закрытых источниках поставщика не установлено.

## Профилайн — новый источник обнаружен, использование не разрешено правилом

Свежий API `2026-10-14 18:00` содержит `params[].code=dimensions_wb`, имя «Габариты в упаковке», и отдельно `dimensions_wob` / «Габариты без упаковки». Проверялась только упаковка. Во всём каталоге поле упаковки непустое у 1193 записей; в текущих оприходованиях три положительных числовых размера найдены у **515 карточек**. У всех 515 поля размеров МС пустые. Ещё одна строка содержит `-`, это не размер; остальные не дают полного размера упаковки.

Это новое фактическое наличие данных не отменяет явное правило `.claude/rules/gab.md`: «Профилайн — источник ТОЛЬКО веса. Размеры от него не брать». Поэтому 515 строк сохранены отдельно, в проект загрузки не попали. Само поле API не подписывает единицы и порядок осей; перед использованием необходимо уточнить их и пересмотреть ограничение источника. Размеры без упаковки и размеры, вычисленные по объёму, не подставлялись.
