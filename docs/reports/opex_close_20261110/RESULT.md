В БД — версии снимков, отдельно —20приватных JSON в .private/opex_closed_months/ (0600). Ноябрь открыт.

Закрытые периоды больше не меняются от правил, удаления авторазметки, повторной загрузки или переименования статей. Защита есть в API и PostgreSQL. В следующих месяцах используется кнопка закрытия; нового расписания автозакрытия нет.
