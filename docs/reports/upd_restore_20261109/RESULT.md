# Восстановление страницы «УПД по выкупам», 09.11.2026

Причина: wb_redeem_notice пустая после восстановления сервера, основной маршрут
отдавал старую HTML-копию. Старый run_daily с загрузкой документов не входит в
восстановленный финансовый pipeline. Выбранные старым кодом токены не имели
действующего доступа к «Документам».

Использован существующий collectors/wb_documents.py. Доступ подтверждён GET
для обоих кабинетов: у Цифрового подходящий действующий JWT находится в
WB_TOKEN_FEEDBACK_ACC1, у Дисквера — WB_TOKEN_ACC2. Значения ключей не менялись.
Выбор ключа проверяет категорию «Документы» (бит12) и срок действия. Для списка
добавлена пагинация, для API — общий межпроцессный лимит11сек на кабинет.
Кабинеты загружаются независимо. Оригинальные ZIP с XLSX и подписями сохраняются
в .private/wb_redeem_sources/<account>; повторный разбор не требует API.
