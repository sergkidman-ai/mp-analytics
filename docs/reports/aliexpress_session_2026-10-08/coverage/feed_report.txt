Проверка фида AliExpress 08.10.2026
Источник связи: https://digitalsquare.ru/feeds/ds_kartridge_aliexpress.xml
Источник ТН ВЭД: только API ТК, ved_eaes_code, сохранённая полная выгрузка 08.10.2026 09:41 UTC.

Фид: 11172 предложения, уникальные offer id. В нём нет отдельного поля ТН ВЭД.
Связь Ali -> фид: sku.code = offer/@id (строго, без удаления ведущих нулей). Дополнительная проверка названия/модели или изображения.
Связь фид -> ТК:
- Точное совпадение barcode с ms_barcode, затем ms_product.external_code -> TC external_code: 4557 предложений фида. МойСклад используется только для идентификации.
- Формат ORG<external_code><буквенный суффикс><номер> встречается в 6370 предложениях. Встроенный код связывает варианты «картридж для принтера» с моделью расходника ТК. Это вывод по данным, а не документированная спецификация. Код проверялся по модели/точной совместимости с принтером, типу, доступным цвету и ресурсу.
- Для DS[A-Z]{3}<7 цифр> проверялся цифровой суффикс с обязательной сверкой признаков. Такой путь применён к 239 предложениям, не связанным по точному штрихкоду МС.

Из 20175 оставленных карточек Али в фиде найдено 9800 по точному SKU. Для 7182 удалось проверить всю цепочку Ali -> фид -> ТК. Из них 3473 прежде не имели предварительного единого кода.
С учётом предыдущих кандидатов предварительное покрытие выросло с 12441 (61.7%) до 15914 (78.9%).
Осталось без проверенной связи или предыдущего модельного кандидата: 4261.
Конфликтов ТН ВЭД между проверенными связями фида и предыдущими кандидатами: 0.

Пример: Ali SKU 79687, «Картридж OkiData C844 совместимый» -> offer id 79687 -> barcode ORG3970UFCR1 -> ТК external_code 3970, модель 47095708; API ТК прямо перечисляет OKI Data C844 в совместимых принтерах; ТН ВЭД 8443999000.

Не подтверждены: 1563 пары Ali/фид требуют проверки идентичности названий; 1043 имеют ключ, но неполное/противоречивое подтверждение характеристик; 12 не имеют однозначного ключа ТК. 10375 SKU Али отсутствуют в текущем фиде (часть уже имеет кандидатов по моделям).

Предварительное покрытие не означает готовность всех строк к автоматической записи: существующие ТН ВЭД Ali ещё не прочитаны целиком, формат ORG выведен из данных; для записи нужно проверить окончательные связи и выполнить согласованный пилот.
