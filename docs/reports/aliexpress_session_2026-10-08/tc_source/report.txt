ПРОВЕРКА ТН ВЭД В ЖИВОМ API ТК
Дата: 2026-10-08T09:41:23Z.
Источник: POST https://thecartridge.ru/api/catalog/cartridge_models.
Параметры чтения: page=N, limit=200. Авторизация Api-Key, значение ключа в отчёт не записано.
Прочитано 35 страниц, включая завершающую пустую; 6735 уникальных моделей.
Внешний код external_code заполнен у всех; дублей нет.

Поле API: ved_eaes_code.
У всех 6735 моделей поле присутствует, не пустое и начинается с 10-значного кода.
Пример external_code=0001, модель Q2610A:
ved_eaes_code = 8443999000 - Части и принадлежности, прочие.
Для передачи в AliExpress использовать код строкой из 10 цифр без описания.

Распределение кодов в ответах ТК:
8443999000: 6441 моделей.
3215900009: 145 моделей.
3707909000: 149 моделей.

Это подтверждение наличия и формата кодов в доступной выгрузке моделей ТК.
6735 моделей могут соответствовать нескольким товарам поставщиков / SKU AliExpress.
Для заполнения 20175 сохраняемых карточек Али необходимо подтвердить связь
каждого SKU с конкретной моделью ТК. Наличие ТН ВЭД у всех моделей ТК само по себе
не означает, что уже найден источник для каждой карточки Али.

По указанию владельца единственный источник кодов для Али — живой API ТК.
Коды WB / Яндекс Маркета и коды по предположению категории не используются.
Неизвестная связь SKU ↔ модель ТК — отдельное исключение, без кода из другого источника.
В этой проверке записи в карточки, справочники и БД не выполнялись.

Файлы: all_models.csv — полный список моделей и кодов,
missing_or_invalid_tnved.csv — только заголовок, исключений нет,
summary.json — счётчики, page_metadata.json — контроль чтения,
raw/page_*.json — исходные ответы API без заголовков авторизации.
