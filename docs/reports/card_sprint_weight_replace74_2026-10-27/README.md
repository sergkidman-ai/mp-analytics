# Спринт: замена 74 отличающихся весов, 27.10.2026

По решению владельца первоисточником веса товара Спринта считается карточка поставщика в авторизованном ЛК. В 1421 ранее доступных карточках ЛК среди характеристик массы найдено только поле «Вес» (у 1418); отдельных полей «брутто», «нетто» или «вес с упаковкой» нет. Единицы 74 целевых значений явно указаны как кг или г и приведены к кг для МС. Размеры в этом прогоне не менялись.

Перед записью повторно прочитаны 57 точных страниц ЛК, проверены числовые коды товара и текущий вес 74 активных карточек МС. Все 74 веса ещё отличались от значений поставщика, дрейфа МС относительно исходного отчёта не было. Сделаны 4 пакетных запроса МС по 20/20/20/14 карточек; все 74 ответа HTTP 200 и все 74 веса подтверждены чтением после записи. Остальные поля каждой карточки проверены на сохранность. Снимки источника, `before/`, `payload/`, `after/`, `journal.jsonl`, `plan.json` и `summary.json` сохранены в этой папке.

Из 743 карточек, размер которых нельзя было сравнить по срезу 23.10, примеры: внешний код 3484 / `SP351122` — текущий поиск ЛК не дал единственную карточку поставщика (`NO_UNIQUE_URL`); внешний код 6516 / `SP137556` — карточка поставщика найдена, но пригодного поля «Габариты, мм» нет (`SOURCE_MISSING_OR_INVALID`). Структура остатка: 726 без однозначного URL, 8 без пригодного размера в доступной карточке, 7 без сопоставимого артикула МС, 2 с ошибкой чтения карточки поставщика. Эти 743 записи не были целью обновления.

Размеры 54 карточек и пустой вес 3 карточек были заполнены ранее в `../card_sprint_dimensions_weight_fill46_2026-10-27/` и `../card_sprint_dimensions_fill10_2026-10-27/`. Следующий шаг по размерам — восстановить точные карточки поставщика для 726 без уникального URL; у найденных без «Габариты, мм» запросить источник измерения, не оценивать размеры расчётом.
