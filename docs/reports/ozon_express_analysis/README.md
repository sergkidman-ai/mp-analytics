Расходы партнёров: 10,95% и 15,94%; часть компенсирует перечисление за доставку от покупателя (включено в amount, его нельзя забывать). Полный денежный результат — сумма amount всех привязанных операций минус фактический COGS, без повторного вычитания комиссии.

Это вклад заказов, а НЕ окончательная чистая прибыль: эквайринг, реклама и прочие операции, у которых нет точного номера отправления, не распределены; зарплата/упаковка/время склада не включены. Приходы по номеру заказа из двух сегментов требуют отдельного распределения между отправлениями. Отсутствие этих расходов в строке не означает нулевой расход. Периоды и ассортимент у режимов различаются; разница среднего результата не доказывает, что перевод заказа в FBS сохранит спрос.

439 экспрессов без возвратов дали 804 362 ₽ прямого вклада за три месяца. Это верхняя граница бюджета на остальные расходы и обработку, не автоматически потерянная прибыль при отказе: часть покупателей может перейти на FBS, часть уйти. Для решения нужен дополнительный труд на экспресс и фактическая стоимость часа склада, плюс сравнение одинаковых товаров.

Файлы: orders.csv — все заказы, фактические категории расходов, себестоимость, результат и флаг возврата; summary.json — агрегаты; calculate.py — воспроизводимый расчёт (только SELECT, пишет файлы отчёта).
