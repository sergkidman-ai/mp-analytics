# Тест мобильного прокси под ЛК Ozon — результат

Поток `rev`, 27.08.2026. Проверялся бесплатный двухчасовой порт Proxy Seller (Билайн, Одинцово,
`AS16345 PJSC Vimpelcom`). Ничего не покупалось, на площадку ничего не отправлялось.

## Вердикт

**Канал не годится, но причина не в браузере и не в нашем окружении — отказ выносится по адресу.**

Меняли по одной переменной, ответ Ozon оставался побайтно тем же (`403`, титул «Похоже, нет
соединения», URL застревает на `?__rr=1`):

| Переменная | Было | Стало | Результат |
|---|---|---|---|
| адрес | сервер, Beget AS198610 | мобильный Билайн, Одинцово | без изменений |
| браузер | Playwright Chromium | настоящий Google Chrome 152 | без изменений |
| окружение | Linux X11, программный WebGL | Windows-отпечаток, ANGLE/Intel, `webdriver=false` | без изменений |
| сайт | `seller.ozon.ru` | покупательский `www.ozon.ru` | без изменений |

## Решающая улика

Проверочный вызов самого антибота — `POST /abt/result` — отвечает **403**, и ни одной куки Ozon
не ставит (`document.cookie` пуст). То есть челлендж не «не решился»: его ответ не принимают
к рассмотрению. Оценка отпечатка до этого места просто не доходит.

Отсюда прямое следствие: маскировка браузера («стелс», подмена WebGL и платформы) задачу не
решает вообще — тратить на неё время не нужно.

## Что это значит для плана

Схема остаётся прежней и остаётся автономной: браузер на сервере → операторский адрес → ЛК.
Не подошёл конкретный адрес, а не подход. Бесплатный тестовый порт по своей природе общий: его
до нас перебирали другие тестеры, и репутация у него соответствующая.

Следующий шаг — **другой мобильный IP**. Оба выданных порта (HTTP `nproxy.site:10621` и SOCKS5
`oproxy.site:10621`) выходят с одного и того же адреса, поэтому второй попытки в этом тесте нет.
В панели Proxy Seller у порта есть ссылка смены IP — по ней канал проверяется заново за две минуты
командой:

    ./venv/bin/python tools/ozon_lk/probe_ip.py --browser --proxy "<адрес порта>"

Критерий прежний: прошли челлендж — покупаем месяц приватного порта (до 2 500 ₽) и пишем
транспорт; держится 403 после трёх смен IP — меняем оператора или провайдера, снова тестом.

## Побочно

На сервер поставлен настоящий Google Chrome 152 (`playwright install chrome`) — он честнее
Chromium из комплекта Playwright и пригодится любому браузерному сбору. Виртуальный экран и показ
погашены.
