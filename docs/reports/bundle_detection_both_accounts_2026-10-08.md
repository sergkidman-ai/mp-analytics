# Определение бандлов: WB и Ozon, оба кабинета

Проверены код, каталог WB (обновлён 08.10) и кэш Ozon (Цифровой — 30.09, Дисквер — 07.10). Четыре карточки Дисквера дополнительно перечитаны точечным Product Info API Ozon. Каталог не равен текущим участникам акций.

## Найдено и исправлено

1. Предыдущая правка Ozon принимала только точные XXXX XN. Она не покрывала бандлы Дисквера с суффиксом, например 3933X6HHWDS8. В кэше Дисквера обнаружены 10362 таких бандла с подтверждённой кратностью.
2. Ozon теперь получает полное, не обрезанное до 60 символов название. Общий WB bundle_multiplier принимает суффикс только при названии «Комплект … N шт» и совпадении N с кодом. Обычный сторож передаёт эту же проверенную кратность в cost_map; stock/regional — в cogs_map и floor_price. Без metadata другие клиенты cost_map сохраняют прежний расчёт.
3. WB plan_raise теперь берёт стоимость и кратность из wb_promo_guard.cogs_map по nmID, как основной сторож, вместо отдельного cost_map по vendor_code и regex без суффиксов. Существующий локальный SQL фильтра текущих плановых цен сохранён.
4. Вспомогательный wb_bundle_plan.is_bundle перестал считать бандлами X0/X1 и случайные суффиксы наборов. Точный XN с конфликтом количества остаётся кандидатом review; суффикс требует подтверждения названием. Из снимка Дисквера исключены 8 обычных наборов, включая 3216X0V1FNDJ. Основной сторож WB уже исключал их правильно.

## Проверка

После исправлений пропущенных бандлов с совпадающими кодом N и названием «Комплект … N шт» в проверенном каталоге нет. Уникальных кодов, распознанных бандлами: WB Цифровой 7729, WB Дисквер 9522, Ozon Цифровой 7773, Ozon Дисквер 10362. Это числа каталога/кэша, не участия или наличия. На WB у одного кода есть несколько карточек, поэтому подсчёт карточек и кодов различается.

3933X6HHWDS8: кратность 6; обычный Ozon guard COGS1278 (supplier_min_x6), stock/regional COGS1368 (историческая закупка родителя228 × 6). Разница обусловлена сохранёнными разными источниками стоимости; в обоих путях минимальная прибыль1800. Цветовые 3216X0V1FNDJ/4692X5BV7567/0916X1TWMYE3: кратность бандла1, даже при нескольких предметах в упаковке.

66 тестов (определение, Ozon/WB пол, WB подготовка/склейки) прошли; все операции отправки в них замоканы. Правки установлены в общий main без переключения ветки; ни цены, ни карточки площадок этим поручением не отправлялись, БД не менялась. Маркет не переводился на новый пол. Коммит/пуш не выполнялись.

Исправление прежних чисел: в утренний состав из1715 ошибочно включены4 обычных набора Дисквера, корректный состав бандлов той выгрузки1711 (946+765). Прежняя оценка по ценам1247 тоже завышена на4: корректно1243 (812+431) на момент прежней проверки цен. Это не свежий состав участия. В старый JSON отчёта добавлена явная поправка, исходные измерения сохранены.
