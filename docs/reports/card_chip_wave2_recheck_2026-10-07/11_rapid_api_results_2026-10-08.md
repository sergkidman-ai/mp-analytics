## Каталог и остаток

Получено 8 135 товаров. Дата выгрузки в ответе: `2026-10-08 16:18:26` (часовой пояс в API не указан). JSON 10,5 МБ сохранён локально без вывода содержимого в переписку. Согласно инструкции, выгрузка обновляется каждые 15 минут; отдельный эксперимент частоты обновления не проводился.

Поле `CodeID` — артикул для сопоставления; `Name` — наименование поставщика; `UnitsFree` — свободный остаток, `UnitsRezerv` — резерв, `UnitsTotal` — сумма свободного и резерва, `UnitsExpected` — ожидаемый приход. Для задачи используем **UnitsFree > 0**, резерв и ожидаемый приход положительным основанием не считаем. В этой выгрузке все остатки числовые; 1 942 товара имеют положительный свободный остаток. Инструкция также допускает `many/medium/little/no`, но в данном ответе их нет.

Во всех 34 полях полученного JSON **отдельного признака чипа нет**. Есть характеристики ресурса (`KolCopy`), цвета (`ColorFake`), габаритов и других свойств. Отсутствие поля чипа относится к этой документированной выгрузке, а не ко всем возможным внутренним методам поставщика.

«БЕЗ СЧЕТЧИКА» при наличии упоминания чипа имеет приоритет над обычным «С ЧИПОМ», даже если слова разнесены по названию. Например, `SF-CRG071(ЧБС)` содержит «БЕЗ СЧЕТЧИКА … С ЧИПОМ» — это чип без счётчика. «БЕЗ ЧИПА» не читается как положительное указание. Суффиксы артикула `(СЧ)`, `(ЧБС)`, `(БЧ)` встречаются и согласуются с примерами; универсальное правило по одним суффиксам не утверждалось.

## Живая выборочная проверка МС

Всего 12 товаров: восемь из второй волны, четыре дополнительных примера с чипом без счётчика и без чипа. В каждом случае артикул и поставщик проверены, свободный остаток API и удалённый остаток МС положительны. Для расширения выборки специально выбирались расхождения описания в локальном снимке: долю несовпадений нельзя переносить на весь каталог.

- **11/12 «Наименований» МС дословно совпадают с Name API**; у OEM CRG057H(ЧБС) в МС добавлен суффикс `(2)`, остальной текст совпадает.
- **4/12 «Описаний» совпадают после нормализации пробелов**, восемь отличаются содержательно.
- **12/12 классов чипа в Описании совпадают с API** в проверенной выборке; отсутствие указания также сравнивалось как неизвестное, не как отсутствие чипа.

Примеры:

| Код / артикул | API и Наименование МС | Описание МС |
|---|---|---|
| 0252 / OEM 106R01379 | ресурс 4K | ресурс 6K |
| 0724 / OEM CF210X/CB540A/CE320A | совместимость также CRG716/CRG731 | эти модели не указаны |
| 5404 / OEM CRG057H(ЧБС) | чип без счётчика | совпадает с API |
| 3219 / OEM W2030A(БЧ) | без чипа | другое оформление названия, тот же признак «без чипа» |

**Вывод:** для Рапида нельзя считать Описание МС автоматически актуальным названием поставщика. В текущей выборке актуальный текст совпадает с Наименованием МС у 11/12, у одного отличается только суффикс `(2)`, а часть описаний содержит другие сведения. Это наблюдение о данных, не доказательство реализации внешнего загрузчика: его код здесь отсутствует. Для чипа у Рапида берём актуальный `Name` API с `UnitsFree > 0`, затем сравниваем оба поля МС. Подтверждённое правило обновления description почтовым загрузчиком сохраняется для почтовых прайсов.

Основная выборка: [10_rapid_live_ms_samples.csv](10_rapid_live_ms_samples.csv); дополнительные примеры: [10_rapid_extra_chip_type_samples.json](10_rapid_extra_chip_type_samples.json); общая проверка: [11_rapid_validation_summary.json](11_rapid_validation_summary.json). Первоначальная выборка совпадала после пробелов; специально расширенная проверка выявила содержательные расхождения, отражённые в итоговых файлах.
