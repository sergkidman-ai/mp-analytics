# Вторая волна «Чип»: проверка без изменений, 07.10.2026

**Уточнение 08.10:** почтовый загрузчик сохраняет название поставщика в поле «Описание», а не переименовывает существующий товар. Во всех 16 проверенных карточках описание совпало с прайсом. Различия поля «Наименование» не доказывают устаревание данных МС. Подробнее: [аудит сохранения названий](08_ms_name_storage_audit_2026-10-08.md). Статусы волны ниже рассчитаны 07.10 и пока не пересчитаны с учётом описаний.

Исходный список — `../tc_chip_wave2_left_2026-09-24.csv`, 691 уникальный внешний код. Порядок проверки: актуальное название поставщика против живого МС → положительный остаток и упоминание чипа → справочник формулировок → наборы ТК. В ТК, МС и БД ничего не изменено. Созданы только локальные инструмент и отчёты.

## 1. Актуальность наименований

Выборочно сверены 18 товаров пяти поставщиков: 16 по последним доступным прайсам Колортек, Кактус, Одиссей и Сакура; два по сайту Булата. Для каждого прочитана живая карточка МС, проверены внешний код, поставщик и точный артикул. 5 наименований совпадают дословно, 13 отличаются, в одном случае различается информация о чипе. Выборка специально включает разные формулировки и несовпадения; это не оценка доли устаревших названий во всём каталоге.

**0968, Кактус, GG-C9403A:** в прайсе 5 шт., название заканчивается «без чипа»; в живом МС это уточнение отсутствует. Поэтому использовать только название МС как доказательство нельзя. Однако другой товар того же внешнего кода, CS-C9403, есть в прайсе в количестве 62 шт. и явно указан с чипом. Для 3487 аналогичное различие: GG-CL446 без чипа, 24 шт.; CS-CL446XL с чипом, 139 шт. Оба кода удовлетворяют правилу «хотя бы один товар поставщика с чипом», но отмечены как различающиеся варианты.

Прайсы Колортек, Кактус и Одиссей получены 07.10, Сакура — 06.10 (последний доступный файл). Для 16 товаров остаток положителен и в прайсе, и в снимке удалённых остатков МС от 07.10. Для двух товаров Булата актуальность названия подтверждена сайтом, а остаток — только снимком МС; количество на сайте независимо не проверено.

Полная выборка: [01_all_supplier_vs_ms_samples.csv](01_all_supplier_vs_ms_samples.csv). Оригинальные источники, даты и хеши: [source_inventory.json](source_inventory.json), `raw/`.

## 2. Перепроверка 691 кода с учётом остатка

В удалённых остатках МС от 07.10 найдены 3 088 карточек поставщиков с положительным остатком, соответствующих 532 кодам. Для 159 кодов положительного остатка нет: их названия не использованы как самостоятельное основание. По правилу пользователя такие коды могут попасть в итог через состав набора.

Из 3 088 карточек актуальное наименование сопоставлено с положительной строкой прайса у 1 026, ещё два наименования проверены на сайте Булата. Сопоставление — точный артикул и группа поставщика, без нечёткого поиска. Одна строка с неизвестным остатком в актуальном источнике исключена из доказательств. Остальные источники остаются явно помечены как непроверенные названия МС.

| Статус кода | Количество | Значение |
|---|---:|---|
| Упоминание подтверждено источником поставщика | 200 | 199 обычный чип, 1 чип без счётчика |
| Положительное упоминание только в МС | 150 | Требуется актуальный источник поставщика |
| Явного положительного упоминания не найдено в проверенных данных | 181 | Не означает доказанного отсутствия чипа |

200 подтверждённых включают 198 кодов по прайсам с положительным количеством и два по сайту с остатком из МС. Шесть кодов исходной волны отсутствуют среди активных моделей в текущем локальном снимке ТК; это отдельный флаг, не дополнительная строка таблицы. Полная актуальность названий всех 14 групп поставщиков **не подтверждена**: четыре прайса и два товара на сайте — доступное покрытие, а не весь каталог поставщиков.

[02_wave2_results.csv](02_wave2_results.csv) — каждый код и статус; [02_in_stock_supplier_evidence.csv](02_in_stock_supplier_evidence.csv) — товары-основания с остатком, названием, формулировкой и источником; [03_supplier_coverage.csv](03_supplier_coverage.csv) — покрытие по поставщикам.

## 3. Справочник формулировок

Подготовлен локальный справочник из 12 наблюдаемых сочетаний «поставщик / формулировка / класс / уровень источника»: [03_supplier_chip_inclusions.csv](03_supplier_chip_inclusions.csv). Непроверенные названия МС отдельно помечены; это рабочий справочник проверки, не утверждённое изменение производственного классификатора.

- «с чипом», самостоятельное «чип» / `chip` при отсутствии отрицательного контекста → **с чипом**.
- «чип без счётчика», «чип безлимит», `chip unlimited` / `chip no count` → **с чипом без счётчика**; требуется упоминание чипа.
- «без чипа», «б/ч», «чип отдельно», «требуется чип» → не положительное основание.
- **Только Блоссом:** `W/chip` трактуется как «без чипа» по ранее подтверждённому правилу владельца; на других поставщиков это исключение не переносится.
- Отсутствие упоминания, `Longlife` и «многоразовый» сами по себе ничего не доказывают. Значение по умолчанию для Кактуса здесь не используется.

Приоритет отрицательных и специальных формулировок предотвращает чтение «без чипа» как наличия чипа и подмену чипа без счётчика обычным. Правила и исходные файлы: [03_rules.json](03_rules.json).

## 4. Наборы и все компоненты

По кэшу справочника составов ТК обнаружена связанная область исходных кодов; для 147 возможных наборов прочитана актуальная `mix_data`. Ответы: 144 действительных состава, три кода не являются наборами, ошибок чтения нет. Прямые и вложенные связи объединены, включая внешний код самого набора и все его компоненты. Совместимость моделей не использовалась как состав набора.

Получено 743 связанных кода, включая 52 вне исходной волны:

- 383 кода в связанных группах имеют подтверждённое основание: 378 для обычного чипа, пять для чипа без счётчика;
- 254 имеют только непроверенное основание из МС в своей группе;
- 106 не имеют подтверждённого положительного основания.

Это список для проверки, **не число необходимых правок**: среди 383 есть уже заполненные значения, четыре расхождения типа чипа и одна неактивная модель 4370. Статус активности и текущее поле ТК взяты из локального снимка моделей, не из отдельного живого чтения каждой модели. Для 52 добавленных кодов собственные остатки отдельно не проверялись: основание наследуется по правилу набора.

**Особый случай T09:** Сакура SAT09BK-ECO, внешний код **5550**, в актуальном прайсе 6 шт., «перезаправляемый чип без счетчика копий». По правилу пользователя значение распространяется на **5550, 5638, 5639, 5640 и набор 5641**. У 5550 поле пусто, у остальных четырёх сейчас обычный чип. Эта группа выделена для проверки различия типов, никаких значений не меняли.

Составы: [04_live_tc_sets.json](04_live_tc_sets.json). Полный связанный список с основанием, текущим значением, активностью и конфликтами: [04_tc_family_review.csv](04_tc_family_review.csv).

Ограничение обнаружения: исходная обратная связь взята из кэша составов ТК, обновлявшегося в июне–августе, после чего найденные составы перечитаны. Все 993 набора ТК глобально заново не обходились; новый набор вне кэша, ссылающийся на эти коды, может не попасть в область. Перед будущим изменением требуется актуализировать глобальный справочник связей и модели ТК.

Перед подготовкой окончательного списка правок обновить глобальный справочник наборов и значения моделей ТК. До этого список 743 кодов остаётся проверочным, массовое заполнение по старым названиям не обосновано.

Инструмент: `tools/card_chip_wave2_recheck.py` (стадии `collect`, `names`, `evidence`, `kits`). Все внешние обращения — чтение: GET МС, чтение почты без отметки просмотра, публичный сайт, read-only POST `mix_data` ТК. БД — SELECT. Проверки уникальности, положительных остатков и исключения названий без подтверждённого количества прошли: [verification.json](verification.json). Коммитов и публикаций нет.
