## Что с этим делать

1. **Класс C (101) — в ТК.** Наш дожиматель бессилен по устройству: пока контент не изменится,
   повтор вернёт тот же вердикт. Приоритет — 51 карточка «Не создан», это прямые потерянные продажи.
2. **Код маркировки (611 + уже закрытые 80) — данные, а не контент.** Мост
   `offer_id → внешний код МС` рабочий (`tools/ozon_card_marking_codes.py`), выгрузка по любой
   группе делается чтением за минуту.
3. **ТН ВЭД (55 + 2)** — значение вне справочника Ozon; правится выбором из списка.
4. **W (2 acc1)** — ничего не делать, крон дожмёт 25.08 после истечения backoff.

## Правка инструмента

`tools/ozon_card_c_report.py`: разбивка по аккаунтам считала **строки ошибок**, а не карточки —
у 6 карточек по две отбивки с одним кодом, поэтому в задании 23.08 стояло «acc1 15, acc2 6»
при 15 карточках в виде. Теперь считаются уникальные `offer_id`; дата среза в шапке и имя
md-файла берутся из текущей даты, а не зашиты строкой.
