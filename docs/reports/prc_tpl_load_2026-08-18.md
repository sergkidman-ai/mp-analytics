- **Название WB, 3 строки** (`4357gp`, `4365gp`, `4478gp`): человек скопировал значение с родни
  `4365sp` вместе с чужим брендом — «Картридж **SP** TK-8365C для Kyocera голубой». SP — это Sprint,
  бренд другого поставщика; норма родни (5 из 6) — «Картридж TK-8365M Kyocera пурпурный».
  Убрали «SP», цвет и «для» оставили.
- **Связь `4529pl` → `7091`** (решение Сергея 19.08.2026, ставим только новой карточке).
  `7091` — одна карточка `7091bs` «Тонер-картридж Sharp MX-60/61GTYA» (Blossom), тот же товар
  под отдельным кодом ТК.

Связь больше никому не нужна, хотя два артикула выглядят универсальными: у `4529pl`
MX-60GTYA/MX-61GTYA оба кода уже под внешним кодом 4529 (соседний 4530 — набор из четырёх цветов,
не близнец), у `6054gp` B235000/B2300A0 — оба под 6054. `2415gp` — комплект TK-8115 четырёх цветов,
по правилу 25 идёт обычной карточкой.
