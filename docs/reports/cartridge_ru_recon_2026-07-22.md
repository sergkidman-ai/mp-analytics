## Структура сайта

- **Движок:** 1С-Битрикс. `robots.txt` карточки товара НЕ запрещает (закрыты только
  admin/personal/basket/order/search/b2b). Вежливый сбор допустим.
- **Sitemap:** `sitemap.xml` → индекс; каталог в `sitemap-iblock-1.xml` = **~10 087 карточек товара**
  (плоские URL `/catalog/{slug}/`). `iblock-6` = ~10 987 страниц принтеров (навигация, не товары).
- **Готового YML/Excel-фида НЕТ** в публичном доступе: проверены `sitemap*/catalog.xml/price.*/
  export.xml/yandex.xml/bitrix/catalog_export/*` и путь выгрузок — все 404.
- **B2B-портал** `/b2b/` — только форма авторизации (логин/пароль/регистрация). «Оптовым покупателям»
  (`/for-business/`) — маркетинг + контакты (info@cartridge.ru, +7 495 982-51-53), файла нет.

**Полный набор характеристик (одинаков на всех карточках):** Производитель принтера / Производитель /
Вид товара / Оригинальность / **Аналог (OEM-модель)** / Цвет / Ресурс / Страна / Гарантия. Плюс
schema.org-микроразметка: `sku`, `mpn`/`model` (= OEM-код), `gtin` (штрихкод!), `brand`, `price`.
`shippingDetails` = только сроки доставки (DAY), НЕ упаковка.

## Ключ матчинга — хорош (если габариты добудем иначе)

- `mpn`/`model` = OEM-код: `Xerox 106R01033/106R01034`, `Canon C-EXV11`, `HP 83X (CF283X)/Canon 737`,
  `Brother TN-3480`. Ровно то, что в наших названиях SKU. Плюс есть `gtin` (штрихкод) — прямой мост к
  `ms_barcode` (наша связка WB↔МС по баркоду).
- Нормализация: upper, убрать пробелы/дефисы/слэши, разбить мультикоды `A/ B` на несколько ключей,
  снять бренд-префикс. Матч и по OEM-коду, и по gtin=barcode.

## Развилка (нужно решение) — сбор со страниц смысла НЕ имеет, размеров там нет

1. **B2B-логин** — если у нас есть учётка Solution Print на cartridge.ru, размеры/упаковка могут быть
   в личном кабинете/партнёрской выгрузке. Нужны креды.
2. **Запросить фид у поставщика** — почтой/менеджеру: YML/Excel с габаритами (для маркетплейсов такие
   фиды обычно есть внутри). Самый чистый и высоконадёжный путь.
3. **gtin-мост** — штрихкоды с карточек уже дают связь site↔наш SKU; если у поставщика есть отдельный
   источник размеров по gtin — состыкуем.
