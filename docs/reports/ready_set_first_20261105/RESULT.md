# Готовый набор перед разложением — 05.11.2026

В штатном `inspect` сначала проверяется свободный остаток целой карточки
по точному внешнему коду набора на складе заказа. При достаточном количестве
сохраняется одна исходная позиция набора с количеством, ценой и скидкой МП.
Физически собранный набор MSK/DSK не требует наличия поставщика или текущей
закупочной цены для выбора собственного остатка.

Если целого набора недостаточно, используется прежний подтверждённый состав
ТК и штатный подбор компонентов. Учитываются резервы МС и ещё не отражённые
в МС обещания партии. Выбранные единицы локально вычитаются и между строками
одного заказа; входящий словарь партии не меняется при двух проверках до POST.
Склад и организация заказа сохраняются. Готовые наборы на удалённом складе
не подменяют проверку собственного остатка.

Изменён общий загрузчик: плановый импорт и автоматический подхват по сторожу
используют одно правило. Обработчик статусов принимает доказательство наличия
выбранной целой позиции; разложение готового набора повторно не выполняется.
Расписания и существующие заказы этим изменением не менялись.

количество 1, резерв 1, склад Звездный; связанная отгрузка уже существует.
Карточка d393fb1c-f847-11f0-0a80-0ec6000b4268. Заказ не изменялся.
