# Класс C — контентные ошибки карточек Ozon: задание для ТК

Срез 2026-08-24. Карточек в классе C: **101** (строк ошибок 109; на карточке бывает несколько отбивок). Полная таблица — `docs/reports/ozon_card_content_errors.csv`, там же поле, текст площадки и что менять по каждой карточке.

**Почему это задание для ТК, а не для нас.** Класс C — отбивки модерации по СОДЕРЖИМОМУ карточки. Приём, которым лечатся классы A и W (повторная отправка того же значения), тут бесполезен по устройству: пока текст/атрибут не изменится, площадка вернёт тот же вердикт. Контент карточек пишет ТК — правка её.

**Что горит.** 51 карточек в состоянии «Не создан» — товар не попал в продажу вообще, это прямые потерянные продажи. Ещё 41 карточек торгуют с висящей отбивкой: продажи идут, но карточка на карандаше у модерации.
