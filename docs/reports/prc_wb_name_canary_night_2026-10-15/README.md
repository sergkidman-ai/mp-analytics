## Совместимость с другой сессией

Проверено действующее расписание: общий запуск размеров и веса **605 карточек**
`card-dimensions-weight-20261015.timer` назначен на **23:20 МСК** / 20:20 UTC.
Он заменил прежний отдельный запуск размеров. Изменений его расписания не делали.
Штатная закупочная цена идёт примерно в 23:06 МСК, тоже вне нашего окна.

Наш жёсткий конец 21:45 раньше размеров/веса на 1 час 35 минут.
Дополнительно наш процесс держит **тот же flock**, который берёт другой исполнитель:
`docs/reports/card_dimensions_weight_night_2026-10-15/lock`. Это взаимная блокировка
на фактическом существующем lock-файле: второй исполнитель не сможет начать запись,
пока первый держит блокировку. Код чужого потока не менялся; блокировка освобождается
при завершении/остановке процесса, до времени 23:20.

Перед каждой пачкой проверяются активные массовые сервисы и их ближайшие таймеры.
Если другой писатель работает или его таймер переставлен внутрь нашего окна,
наш прогон останавливается. Не ждёт до чужого ночного окна и не запускает другую партию.
Фактические таймеры и состояния — `schedule_verification.json`.

## Исполнение и контроль

`tools/prc/wb_name_canary.py` использует замороженный план, SHA256 правил и кода,
свежие исходные поля ТК, чёрный список и живую карточку МС перед каждой пачкой.
Ручная правка WB-поля, смена товара/артикула/кода/поставщика/исходных характеристик,
архив/стоп-признаки и отсутствие обязательных полей дают skip; уже совпадающее имя — noop.
Вместо пропущенных карточек другие не подставляются, предел попыток — 200 сущностей.

Меняется только «Название WB». Отдельные поля габаритов/веса не передаются;
прочие дополнительные атрибуты копируются из свежей карточки и проверяются после записи.
До POST сохраняются срез и payload, затем FSYNC-запись намерения в журнал.
POST делается **один раз без автоматических повторов**, в том числе при 429/5xx/таймауте.
Неопределённый ответ останавливает прогон для аудита; существующий журнал блокирует
повторный запуск. Отказ не вызывает автоматического отката поверх возможной ручной правки.

Пачка до 50, пауза не меньше 60 секунд; при медленном ответе — 120 секунд.
После первых 200 кандидатов — пауза 10 минут, повторная проверка чтения заказов МС
и остановка **без продолжения всей очереди**. GET после записи подтверждает имя,
неизменность остальных полей и дополнительных атрибутов.
Доступность API заказов не объявляется доказательством доставки вебхуков.

Минимальный запас места проверяется перед каждым блоком: 16 МиБ для этой ограниченной
партии и её сжатых резервных копий/журналов. При нехватке места запись не начинается/
останавливается. Это не решение общей проблемы заполненного диска.
