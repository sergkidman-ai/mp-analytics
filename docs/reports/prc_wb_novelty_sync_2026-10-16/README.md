# Название WB: синхронизация Новинок и последующей проверки МС

По поручению пользователя исправлена подготовка исходных данных; формула wbname
2026-10-15.2, сокращения и геометрия этикетки не менялись.

## Исправление

- Реальная новинка18958, артикул `WB TN2355`: модель расходника находится после
  «для Brother». Явные семейства TN/LC (картриджи), DR (фотобарабаны) распознаются
  отдельно от HL/MFC/DCP и ресурса. Два кандидата или неподтверждённое семейство — HOLD.
- Результат без выдуманного цвета/чипа: `Картридж TN2355 для Brother`.
  `White Box` не обозначает цвет печати. Уточнение цвета требует отдельного источника.
- `ms_import.wb_details` разрешает источники, затем вызывает существующий
  `wb_fill.compose_details`. Неизвестный словарь, длина и геометрия не обходятся fallback.
- Форма показывает производное WB-поле, уточнения делаются через структурированные факты
  и источник подтверждения. Пересчёт — read-only endpoint; версия и семантический снимок
  перепроверяются перед созданием. Смена числа карточек не возвращает старое WB-поле.
- Обычное создание, twin/auto/CLI и Excel проходят общий валидатор всей партии.
  В Excel сохраняются исходный код модели и имя поставщика отдельно от новых кодов;
  старый нормализатор произвольного текста из `tpl_load` удалён.
- Миграция416 добавляет `prc_wb_name_source`. Источник сохраняется до POST; id МС
  прикрепляется после подтверждённого ответа. Незавершённая запись требует сверки,
  автоматического повторного POST нет. В dry-run источник в БД не пишется.
- `prices.wb_source.for_product` и `tools/prc/wb_source_audit.py` дают последующую
  read-only проверку с сохранённым исходным кодом, фактами и подтверждением.
  Для явно выбранных существующих карточек без записи источника используется текущий ТК.
