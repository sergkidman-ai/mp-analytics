## Расчёт и сохранность истории

Пилот получает проверенное актуальное правило через общий `shipment_rule`.
При неполной или устаревшей базе пол не рассчитывается. Округление совпадает
с остальными потребителями через `floor_from_retention`.

Первый локальный `reprice` добавил пять результатов без запросов в МС/Ozon.
Старые результаты, времена проверки в МС, снимки и источники стоимости сохранены.
Новый результат содержит ссылку на прежнюю проверку и период базы расходов.
Новая версия MP-заказа или незавершённая проверка исключаются из локального пересчёта.

Контрольный заказ `10879561-0077-1`:

| Показатель | Значение |
|---|---:|
| Цена продавца | 728,00 ₽ |
| Фактический FIFO | 69,28 ₽ |
| База расходов | 01–30 сентября 2026 |
| Старый пол | 828,60 ₽ |
| Новый пол | 941,85 ₽ |
| Отклонение | −213,85 ₽ |
| Расчётный остаток после средней доли расходов | +216,15 ₽ |

Остаток положителен; нарушение целевого пола не является убытком.
Используется общая доля расходов кабинета, включая рекламу/FBO/фиксированные услуги,
а не фактические начисления конкретного заказа.

## Проверки и публикация

152 теста и 44 subtests прошли с включёнными SQL-проверками в изолированных схемах.
Проверены общий пол до копейки, положительный остаток при отрицательном отклонении,
неизменность истории/времени МС, идемпотентность и пропуск изменённого заказа.

Playwright на рабочем dashboard подтвердил пол 941,85, остаток 216,15,
старый и новый результаты в истории; ошибок JavaScript нет.
Опубликован только `web/static/customer_orders.html`, атомарной заменой после
проверки исходного содержимого. Сохранён backup в локальном `before/`.
Перезапуск dashboard не требовался. Обработчик продолжает запускаться из worktree.

В таблице уточнено «Проверено в МС», показан период базы, отдельно расчётный
остаток/убыток. Время первой проверки названо сроком доступности, а не расписанием.
История отличает локальный пересчёт базы от нового обращения в МС.

При проверке состава найден старый формат `set_cost.components` у набора 3113:
вместо кода хранилась строка вида словаря с `external_code` и полями ссылок.
Чтение исправлено для верхних и вложенных наборов без изменения справочника.
Учитывается явный код и прежнее количество; ссылки не используются как замены.
Проверено на смеси строк/словарей и на повторном локальном пересчёте истории.

Автоматическая обработка, уведомления и вебхуки этим этапом не включались.
Ограниченный последовательный проход ожидающих заказов фиксируется в
`worker_runs.json`; первая партия до этого файла: 5 заказов / 36 запросов МС.
