Основной результат: 9022 SKU в наличии с наблюдаемыми переходами трафика;
4948 редки до/после, 4074 недостаточно точны или имеют ограничения сравнения.

без видимого улучшения после. Списки пересекаются по смыслу, не складывать.
1214 рекламировались без пригодного перехода для сравнения — 61,3% учтённого
годового CPC-расхода текущего наличия. Чтобы оценить их способность продаваться
без CPC, нужен отдельный согласованный тест сокращения; он не выполнен.

Редкий хвост — бизнес-кандидаты, **не доказанный нулевой эффект**. У 413 таких SKU

дата добавления ненадёжна. 4025 SKU сопоставлены с применённым E8-возвратом;
исторический E8 не становится новым назначением ноября. Полная методика — METHOD.md.
