`analysis_summary.json` — сводные числа; `validation.json` — проверки.

- `transition_episodes_currently_in_stock.csv`: 15 194 эпизода этих SKU.
- `rare_both_modes_currently_in_stock.csv`: 4948 кандидатов редкого спроса до/после.
- Остальные 4074 не имеют достаточной точности/зрелой базы либо имеют смешения.
- `selling_without_observed_cpc_in_stock.csv`: 154 SKU с продажами без наблюдаемого CPC.
- `selling_before_cpc_no_observed_gain_review.csv`: 107 для ручной проверки.
- `annual_sku_profile_currently_in_stock.csv`: 15 255 SKU текущего наличия.
- `no_usable_off_on_comparison_in_stock.csv`: 1214 без пригодного перехода.
- `demand_before_cpc_in_stock.csv`: спрос до CPC отдельно от реакции рекламы.

  возвратом E8 в августе; история, не новая ноябрьская группа.

Списки разных критериев могут пересекаться. Редкий спрос до/после не доказательство
нулевого эффекта; нет причинно подтверждённых групп роста или отсутствия эффекта.
Не делать отключений по этому списку без отдельного решения.

## Пересчёт без API

`analyze_year.py` использует `normalization_checkpoint.json` и готовые нормализованные
слои, затем запускает `analyze_year_streaming.py` с ограниченной памятью.
Первая попытка нормализации+анализа в памяти завершилась exit137 после сохранения
нормализованных файлов; это исправлено, успешный потоковый пересчёт завершён.
Сырые файлы не терялись, повторного сбора из-за этого не было.
`normalize_year.py` нужен только при отсутствии нормализованных слоёв.
`enrich_current_status.py` добавляет флаги текущего CPC/нового месячного пула;
`add_family_context.py` добавляет контекст и исторический журнал возврата.
Рендер: `../ozon_monthly_experiment_20261105/publish_reports.py`.
Артефакты `logs/`, `date_added_quality.json`, `SHA256SUMS` сохраняют аудит.
В «Дате добавления» 426 831 положительная строка предшествует записанной дате:
поле нельзя использовать как полный журнал on/off.
