# Solutions Print / cartridge.ru: существующий сборщик

Read-only проверка11.10.2026. Подтверждено документом `docs/GABARITY_SOLUTIONSPRINT_HANDOFF.md`:22.07 делался авторизованный обход B2B карточек cartridge.ru при работе с габаритами. Краулер назывался crawl_dims_ms.py; его расположение указано во временном scratchpad. В текущем репозитории файл с этим именем не найден; за пределами проекта поиск не проводился.

Исторический обход дал10053 товара,6115 с размерами,7652 с весом; загружены6005 решений supplier_dims. Текущая read-only SQL-проверка подтверждает6005 строк supplier=solutionsprint, у всех есть title и уникальный article. Это сохранённые исторические данные, не свежий каталог.

Сохранились `scratch_solutionsprint_join.py` (строгий подбор размеров по сохранённым данным), `tools/gab_sp_title_verify.py` (read-only сверка названий из прайса, не сетевой сборщик), `docs/solutionsprint_title_check.csv` и исходные HTML примеров в scratchpad_cartridge/. Указанный исторический загрузчик scratch_load_solutionsprint_dims.py в текущем чекауте отсутствует. Скрипты не запускались.

Исторически авторизованный парсер собирал URL, числовой код товара, title, размеры, объём и вес. Разведка обнаружила на карточке вид товара, цвет, ресурс, бренд и штрихкод. Поле analog исторически ошибочно попадало из сопутствующих товаров: для нового парсера читать только главный блок карточки, не использовать первый analog__content страницы.

Свежая проверка публичной главной страницы https://cartridge.ru/ подтверждает наличие названий, числовых кодов, цветов, отметок наличия и «без чипа». Открытие конкретной карточки web-инструментом завершилось timeout; текущую структуру всей таблицы свойств не подтвердили. В кабинет под логином не входили: в .env не найдено отдельных credentials Solutions Print; CARTRIDGE_API_KEY/URL относятся к ТК thecartridge.ru, это другая система.

Вывод: подход уже применялся, архив результатов и скрипты разбора сохранились. Для свежего сбора названий/свойств восстановить авторизацию Solutions Print и сам сетевой обходчик, ограничить извлечение главным товаром и проверять связь по числовому коду поставщика/штрихкоду. Никаких записей в МС, ТК, БД или площадки на этой проверке нет.
