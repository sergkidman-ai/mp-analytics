## Защита отметки «Напечатан»

Экспорт печатной формы через API МС может пометить документ как напечатанный,
хотя кладовщик его физически не печатал. Это нарушает рабочий фильтр склада.
**Для тестов экспортировать только отгрузки с `demand.printed=true`
до запроса**, непосредственно перед экспортом проверив флаг и связь заказа.
Ненапечатанные документы для теста не экспортировать; флаг автоматически
обратно не снимать. Просмотр списка не должен запускать экспорт.
Отдельно проверить влияние на связанные документы: прежний опыт подтвердил
только сохранение `printed=true` у отгрузки. Полученный PDF ≠ физическая печать.
