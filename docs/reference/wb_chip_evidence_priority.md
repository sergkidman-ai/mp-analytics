# Чипы ВБ: источники и границы вывода

## Последнее уточнение Сергея 05.10.2026 — приоритет над историческими правилами ниже

В проверке через МС использовать ТОЛЬКО фактическое указание чипа в товаре
поставщика: внешний код → оприходование (`entity/enter`, удалённый склад) →
точный ms_id → наименование, описание из прайса и явные обозначения артикула.
Нормализовать написания словарём и сохранять исходный текст. Не засчитывать
молчание нескольких товаров, брендовое значение по умолчанию или предположения
как закрытый код. «Название WB» не является названием товара поставщика.
Это уточнение заменяет применение таких эвристик в данной проверке;
рабочий старый `ops/wb_chip_map.py` ещё не переделан.

Итог после подключения словаря поставщиков и архивных товаров: 19 кодов с явным указанием в поставщицких полях МС,
17 новых относительно дополнительного прогона прайсов; 2 823 исходных кодов
в этом источнике не получили явного класса. Актуальный отчёт:
`docs/reports/mkt_wb_chip_supplier_facts_2026-10-05.html`.
Далее сохранена история проверки; условные 990/392 не являются итогом.

Правило Сергея повторно уточнено 05.10.2026: сведения искать по нашему внешнему коду
в ТК, прайсах поставщиков и карточках площадки. Если ТК и ВБ уже проверены,
остаток сначала прогонять по полным прайсам всех поставщиков этого кода.
Название одного товара МС не заменяет этот поиск.

- Раздельно хранить явный класс, источник, дату и основание сопоставления.
- Не путать поставщицкий код/артикул с нашим внешним кодом. Модель сама по себе
  не подтверждает одинаковое исполнение и не разрешает объединить версии чипа.
- Проверять исходные файлы, отдельные поля, полные наименования и примечания;
  сокращения «б/ч», «w/o chip» учитывать как «без чипа».
- «Не требуется чип» в шаблонном описании ВБ не считать независимым свидетельством.
- Чип без счётчика сохранять отдельно от общего «с чипом»; разные или неполные
  указания требуют разбора по конкретному товару.
- Правила по умолчанию и молчание поставщиков отмечать как вывод по правилу,
  отдельно от явного указания. Историческая эвристика «3+ товара молчат → без чипа»
  остаётся в `ops/wb_chip_map.py`; её применение не означает, что найдено явное поле.
- Не делать повторных массовых запросов к уже проверенным ТК/ВБ без новых данных;
  к отдельной карточке возвращаться для проверки привязки или конфликта.

Проверка 05.10: исходный остаток 2 842 кода. Расширенный прогон по журналу прайсов,

447 — только правило Кактуса; 2 — указание есть, привязка требует проверки;
2 391 — класс не установлен. Полные исходные прайсы всех поставщиков не получены:
подтверждённая связанная строка прайса есть у 1 184 из 2 842 кодов.
