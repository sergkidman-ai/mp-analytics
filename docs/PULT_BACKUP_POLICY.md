# Резервные копии: действующая политика

Поток: infra. Прямое решение владельца 16.11.2026: каждый проект копировать
один раз в сутки, удалять резервные точки старше трёх суток. Старые копии
разрешено удалить окончательно, включая прежние защищённые контрольные точки.

## Расписание и хранение

| Проект | Ежедневно, Москва | Ежедневно, UTC | Хранение |
|---|---|---|---|
| Rev | 04:30 | 01:30 | 72 часа, до 3 успешных дней |
| Beyindi | 05:10 | 02:10 | 72 часа, до 3 успешных дней |
| Пульт | 06:10 | 03:10 | 72 часа, до 3 успешных дней |
| Сокол | 07:30–07:45 | 04:30–04:45 | 72 часа, до 3 успешных дней |

Недельных и месячных точек нет. Ежедневно создаётся новая полная копия;
после успешной внешней проверки удаляются истёкшие собственные копии.
Удаление окончательное, без накопления в корзине. Чужие файлы/корзина и
ключи не затрагиваются. Последняя проверенная точка сохраняется при сбое,
даже если из-за продолжительного сбоя она окажется старше 72 часов.
Пропущенный успешный день не заменяется выдуманной точкой.

Это политика срока хранения, состав пакетов сохранён. Код и окружение пока
присутствуют в полных архивах; разделение ежедневных данных и версий
окружения/кода требует отдельной проверки восстановления.

Общие объекты Beyindi (фотографии/медиа, Docker-образы, инструменты) не являются
отдельными ежедневными точками. Они сохраняются, пока на них ссылается хотя бы
одна оставшаяся завершённая либо незавершённая точка. Удаление по возрасту
общих объектов нарушило бы восстановление свежих копий. У Пульта роли/ACL и
документы первой точки также сохраняются, пока нужны этой точке; новые пакеты
включают их внутри основного архива.

## Пульт: проверенная первая точка

Google Drive: https://drive.google.com/drive/folders/1BKUZSNDZv_xRXI1VFe9h5x36vd1xEeE4
Папка закрыта. Архивы AES256/GPG; используется подтверждённый владельцем
офлайн-пароль копий Сокола. Сам пароль не включается в Drive/Git/архивы.

Первая точка 16.11 состоит из трёх файлов:

- `pult-full-20261116T122651Z.tar.gpg`, 600432724 байта: дамп БД, рабочий код,
  конфигурация. Snapshot 12:12UTC, изолированное восстановление 12:44UTC;
  все 262 таблицы и количества строк совпали.
- `pult-bootstrap-20261116T123310Z.tar.gpg`, 450646 байт: роли/ACL PostgreSQL,
  проверены повторным скачиванием.
- `pult-documents-20261116T123929Z.tar.gpg`, 263342164 байта: 5649 оригинальных
  документов; после скачивания/расшифровки проверены все хеши.

Всего864225534 байта. В следующих копиях роли/ACL/документы включены внутрь
основного пакета. Каждая обычная копия Пульта проверяется скачиванием,
SHA256/GPG и реальным восстановлением в изолированный PostgreSQL16 без сети
и бизнес-процессов, со сверкой количеств строк всех таблиц. Код сохранён вместе
с рабочими незакоммиченными файлами и Git bundle; конфигурация/секреты находятся
только внутри шифрования. Зависимости Python переустанавливаются по списку
версий; это не образ всего VPS. Кэши API и производные пары этикеток исключены.

Восстанавливать только в новую отдельную БД, с отключёнными бизнес-таймерами.
Роли — перед БД, права — по инструкции bootstrap, затем код/документы.
Общий Caddy/nginx не подменять без проверки остальных проектов.

Статусы: `/var/backups/mp-analytics/pult-drive/latest_success.json` и
`latest_attempt.json`. Внешние автоматические уведомления не настраивались;
ошибки видны через systemd и эти файлы.

## Место

Пульт2.6GB, Сокол1.16GB, Rev0.58GB, Beyindi2.42GB с общими объектами.
Итого около6.8GB резервных данных; дополнительно место занимает почта и
прочие файлы аккаунта. Возможен рост данных и временный расход на новую копию
до удаления старой. Эта короткая схема заменяет прежний расчёт35/70/100GB;
увеличение платной ёмкости не подключалось.
