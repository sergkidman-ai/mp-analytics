# BRIEF_PRC — поток `prc` (прайсы поставщиков → МойСклад)

Обновлён 16.08.2026. Лимит брифа — 150 строк, поэтому он держит только состояние.
**Правила потока и знания о системе — `docs/PRC_RULES.md` (читать вместе с этим файлом).**
История этапов до 16.08.2026 — `docs/archive/BRIEF_PRC_история_до_2026-08-16.md`.

## Что делает поток

Забрать прайс поставщика с почты/телеграма → положить остатки и закупочные цены документом
**Оприходование** на склад «Удаленный» → зафиксировать позиции, которых нет в МС («новинки»),
и довести их до заведения карточки. Внешний загрузчик целиком не заменяем: часть прайсов идёт
по API и продолжит; убираем ручной труд по поставщикам без API, по одному, каждый со своим «ок»
Сергея на первый `--apply`.

## Ветка и запуск

- Ветка/worktree: `prc/colortek-loader` в `.claude/worktrees/prc-colortek` (заведена 05.08.2026).
- `./venv/bin/python -m prices.run --supplier <ключ> [--apply] [--file …] [--no-db] [--ignore-anomalies]`
- Ключи профилей: `colortek`, `odissey`, `sakura`, `kaktus` (= группа `kaktus_msk`).

## Территория потока

`prices/` (`profiles, mailbox, parser, cbr, loader, anomaly, blacklist, mailout, journal, run,
novelty, features, catalog, ms_import, waiting, research, supplier_group`, юниты
`prc-price-watch@.{service,timer}`) · `core/ms_api.py` (общий клиент МС, пишет пока только prc) ·
`ops/prc_price_watch.py` · `tools/prc/` (`tpl_check, tpl_load, tpl_verify, enter_audit, tc_bench,
tc_ms_diff, tc_links`) · `collectors/thecartridge_catalog.py` · миграции **400–408** ·
UI `web/static/novelties.html` + роуты `/warehouse/novelties`, `/api/novelties*`, `/api/blacklist*`
в `web/app.py` · отчёты `docs/prc/`, `docs/reports/`.

2. **Делают люди, не мы:** класс C дублей-ТОВАРОВ (15 пар внешних кодов: `5290`↔`7086`,
   `5944`↔`5952`, `1163`↔`2157` …) сливают Наталья/prc2 вручную; расхождения ТК↔МС (928 на
   865 карточках) правит человек; `0014` (106R01159) в каталоге моделей ТК нет — вопрос программисту ТК.
3. **Пары `msk`/`spb` Спринта** — нужно решение: ведущий склад или разводить в загрузчике

   `CS-I-PG440` — совет ошибочный (не проверяет полноту цветов внутри серии) и будет повторяться;
