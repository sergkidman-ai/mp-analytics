## Что делает поток

Забрать прайс поставщика с почты/телеграма → положить остатки и закупочные цены документом
**Оприходование** на склад «Удаленный» → зафиксировать позиции, которых нет в МС («новинки»),
и довести их до заведения карточки. Внешний загрузчик целиком не заменяем: часть прайсов идёт
по API и продолжит; убираем ручной труд по поставщикам без API, по одному, каждый со своим «ок»
Сергея на первый `--apply`.

## Ветка и запуск

- Ветка/worktree: `prc/colortek-loader` в `.claude/worktrees/prc-colortek` (заведена 05.08.2026).
- **Ветка задачи 18.08.2026:** `prc/unlinked-enters` в `.claude/worktrees/prc-unlinked` —

  дашборд перезапущен.
- `./venv/bin/python -m prices.run --supplier <ключ> [--apply] [--file …] [--no-db] [--ignore-anomalies]`
- Ключи профилей: `colortek`, `odissey`, `sakura`, `kaktus` (= группа `kaktus_msk`).

## Доступ сотрудника в «Новинки» (31.08.2026)

опер. расходы, отчёты МП, маркетинг, ставки) ему закрыт. Две линии, обе обязательны:

- **nginx** — файл `/etc/nginx/.htpasswd-novelties` (логин `novelty` + `max`, realm общий, поэтому
  владелец должен быть в обоих файлах). Привязан к пяти локациям в
  `/etc/nginx/sites-available/bi.metaverseworld.ru`: `= /warehouse/novelties`,
  `^~ /warehouse/novelties/img/`, `^~ /api/novelties`, `^~ /api/blacklist`, `^~ /api/unlinked`.
  Всё прочее остаётся на `.htpasswd-bi` и отдаёт оператору 401. Бэкап конфига — `*.bak-2026-08-31`.
- **приложение** — во все блоки добавлен `proxy_set_header X-Pult-User $remote_user;`, nginx его
  перетирает, подмена клиентом не проходит (проверено). В `web/app.py` — `NOVELTY_ONLY_USERS`,
  списки `NOVELTY_ALLOW_EXACT/PREFIX/DENY_PREFIX` и middleware `novelty_scope_guard`: 403 на всё
  вне раздела. Дублирование намеренное — одна опечатка в nginx открыла бы финансы.

**Платная «🌐 Спросить сеть» оператору закрыта** по правилу платных ресурсов: `/api/novelties/research`
и `/research/estimate` → 403, кнопки скрыты (`button.paid`), пункт инструкции о ней — тоже

## Аббревиатуры Булата: Smart Graphics и своя нумерация струйки (04.09.2026)

Кнопка «+МС» на «Новых моделях» отвечала «нет правил аббревиатуры для bulat» на 59 строках.
Причина не в поставщике, а в том, что у Булата бренд читался ТОЛЬКО из наименования
(`NAME_SUFFIX`), а в этих строках прайса бренда в имени нет вовсе: «Тонер-картридж Smart
Graphics 113R00668…», «Струйный картридж HP DesignJet T730/T830 728…». Артикул при этом
бренд несёт. Добавлено (`prices/ms_import.py`):

* `SG-…` → `sg` — Smart Graphics, отдельная марка Булата. В МС 1232 живые карточки из 1246
  с таким артикулом и 1242 из 1251 по имени бренда сидят на `sg`.
* `GF…`, `GD…` → `bt` — собственная нумерация струйки и чернил БУЛАТА: 203 из 205 и 40 из 40
  на `bt`, и все они названы «… БУЛАТ …» — в прайсе это слово просто теряется.
* `smart graphics` добавлено и в `NAME_SUFFIX` выше строки `булат`.

Сверка правила с фактом МС: 98 % (1475 из 1491); все 16 расхождений — накопленные ошибки
людей (9 карточек `SG-` на `bt`, 4 на `wb`, 2 `GF` на `q`).

Тем же заходом (решение Сергея 04.09.2026: «s-Line — sl, e-Line — el, bulat — bt», про
драм-картриджи Konica/Ricoh/Xerox без марки в имени — «этот Булат»):

* `e-?line` → `el` — марки не было в правилах ВООБЩЕ. В МС 235 живых карточек названы
  «Тонер-картридж e-Line …» (228 на `el`), слова «БУЛАТ» в имени нет — каждая такая позиция
  прайса падала на «нет правила аббревиатуры». Дефис у обеих марок сделан необязательным.
* Значение по умолчанию у Булата — `bt`. Раньше умолчания не было намеренно. Проверено по
  3889 живым карточкам: до умолчания доезжают 117, из них 111 стоят на `bt`, и НИ ОДНОЙ `sl`
  или `el` — марку s-Line/e-Line в наименовании пишут всегда. Плата: новый бренд Булата
  теперь молча уедет в `bt`, а не остановит человека. Если Булат заведёт четвёртую марку —
  правило в `NAME_SUFFIX` добавлять ДО умолчания.

Итог: из 349 строк Булата без аббревиатуры не осталось ни одной (bt 143, gf 93, sl 84, sg 18,
7q 10, ce 1). Сверка с МС — 98 % без учёта переименования `q`→`7q` (612 старых карточек).

## Синонимы типа расходника для «Название WB» (04.09.2026)

После правки аббревиатур строки Булата стали открываться по «+МС» — и уткнулись в пустое
«Название WB». Это не регрессия: поле собирает формула (правило 41) из каталога ТК, а у новой
модели кода ТК нет, и сырьё берётся из названия поставщика (`wb_from_price`). Тип там назван
не по-каталожному: в словаре ТК 15 типов, «Драм-картридж» и «Блок фотобарабана» среди них нет.

Решение Сергея: ТОЛЬКО три синонима, перевод однозначен —
«Драм-картридж», «Драм-юнит» → **«Фотобарабан»**; «Блок фотобарабана в сборе с блоком
проявки» → **«Фотобарабан + картридж»** (`ms_import.KIND_SYNONYM`, длинное написание первым).
Фотобумага, ленты и лампы Сакуры синонимами НЕ считаются: такого типа в ТК нет вовсе.

Эффект: в новинках 55 строк с этими словами, формула теперь даёт имя у 22 (было 0). Остальные
33 молчат по ДРУГОЙ причине — не вычленяется модель («Драм-картридж Xerox AltaLink B8145
013R00686 (R).»); это отдельная дыра разбора, её не трогали. Ветка синонима включается только
там, где тип НЕ найден, поэтому ни одно уже собиравшееся имя не изменилось.

Известное свойство запасного источника (не новое): бренд ПОСТАВЩИКА уезжает в модель —
«Тонер-картридж Smart Graphics 113R00668 для Xerox черный», «Картридж Cactus CS-CF259A для HP
черный». Так работает `wb_from_price` у всех поставщиков, и замечание «сверить модель и цвет»
для того и стоит.

По «Новым моделям» без нашего кода пусто остаётся 270 строк из 437: Сакура 243 (фотобумага,
ленты, лампы), Кактус 16, Булат 8, Одиссей 2, Профилайн 1. Поле в диалоге редактируемое.
