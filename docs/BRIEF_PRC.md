# BRIEF_PRC — поток `prc` (прайсы поставщиков → МойСклад)

Обновлён 16.08.2026. Лимит брифа — 150 строк, поэтому он держит только состояние.
**Правила потока и знания о системе — `docs/PRC_RULES.md` (читать вместе с этим файлом).**
История этапов до 16.08.2026 — `docs/archive/BRIEF_PRC_история_до_2026-08-16.md`.

## Что делает поток

Забрать прайс поставщика с почты/телеграма → положить остатки и закупочные цены документом
**Оприходование** на склад «Удаленный» → зафиксировать позиции, которых нет в МС («новинки»),
и довести их до заведения карточки. Внешний загрузчик целиком не заменяем: часть прайсов идёт
по API и продолжит; убираем ручной труд по поставщикам без API, по одному, каждый со своим «ок»
Сергея на первый `--apply`.

## Ветка и запуск

- Ветка/worktree: `prc/colortek-loader` в `.claude/worktrees/prc-colortek` (заведена 05.08.2026).
- **Ветка задачи 18.08.2026:** `prc/unlinked-enters` в `.claude/worktrees/prc-unlinked` —
  вкладка «Несопоставлено» + правило по архиву. **Влита в `main` 18.08.2026 по «ок» Сергея**,
  дашборд перезапущен.
- `./venv/bin/python -m prices.run --supplier <ключ> [--apply] [--file …] [--no-db] [--ignore-anomalies]`
- Ключи профилей: `colortek`, `odissey`, `sakura`, `kaktus` (= группа `kaktus_msk`).
