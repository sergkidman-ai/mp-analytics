# Разведка nix.ru — что сделать на домашнем компьютере

1. Открыть командную строку Windows (кнопка «Пуск» → набрать `cmd` → Enter).
2. Выполнить `pip install playwright`, дождаться окончания.
3. Выполнить `playwright install chromium`, дождаться окончания.
4. Создать папку, например `C:\nix`.
5. Положить в неё два файла: `nix_probe.py` и `nix_input.csv` (оба пришлю).
6. В командной строке перейти в папку: `cd C:\nix`.
7. Запустить: `python nix_probe.py`.
8. Откроется окно браузера — оно само вводит артикулы и листает страницы, трогать его не нужно.
9. Работа идёт неспешно, с паузами; на десять артикулов уйдёт примерно 10–15 минут.
10. Можно закрыть в любой момент (Ctrl+C): при повторном запуске продолжит с того же места.
11. После окончания в папке появятся `nix_found.csv`, `nix_network.csv` и папка `nix_raw`.
12. Прислать эти два файла и папку `nix_raw` целиком — больше ничего делать не нужно.
