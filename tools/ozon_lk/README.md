# Разведка ЛК Ozon — инструкция для машины сотрудника

Поток: `rev`. Отзывы Ozon по API закрыты навсегда (403 `PermissionDenied`, подписки не будет),
поэтому единственный путь — личный кабинет. Схема, к которой пришли 24.08.2026: браузер с
**постоянным профилем** живёт на рабочей машине сотрудника, вход выполняется **один раз руками**,
скрипт потом работает в этом же профиле как человек.

Почему не на сервере: сервер стоит в дата-центре Beget (`AS198610`). Разведка 23.08 показала, что
рвётся не скрипт, а сессия, и главная причина — смена IP/ASN. Память машины сегодня не аргумент
(16 ГБ, свободно 11), аргумент — именно адрес.

## Что этот шаг делает и чего НЕ делает

Делает: открывает ЛК под сохранённым профилем, доходит до раздела «Отзывы» и до карточки одного
отзыва, снимает селекторы и структуру формы ответа, кладёт отчёт и скриншоты в папку.

**Не делает ничего пишущего.** В `recon.py` нет `fill()`, `type()`, `press()` и `click()` — перед
каждым запуском скрипт сам проверяет свой исходник и останавливается, если ввод или клик появятся.
Кнопки отправки он только перечисляет текстом, помечая «не трогать». Отправка ответов на площадку —
отдельная прямая команда Сергея, её сейчас нет.

## Установка (один раз)

**Windows.** Поставить Python 3.11+ с python.org (галочка «Add python.exe to PATH»), затем в
PowerShell из папки со скриптом:

    py -m venv venv
    venv\Scripts\pip install playwright
    venv\Scripts\playwright install chromium

**macOS.** Python 3.11+ (`brew install python@3.12`), затем в Терминале:

    python3 -m venv venv
    venv/bin/pip install playwright
    venv/bin/playwright install chromium

Загрузка Chromium — около 150 МБ, разово. Всё бесплатно, платных ресурсов шаг не требует.

## Запуск

**1. Вход руками (один раз).**

    venv\Scripts\python recon.py --login        # Windows
    venv/bin/python recon.py --login            # macOS

Откроется обычное окно браузера. Войти в ЛК Ozon (логин, пароль, СМС), дойти до раздела «Отзывы»,
вернуться в консоль и нажать Enter. Профиль сохранится в `~/.ozon-lk-profile` — второй раз входить
не нужно, пока Ozon не разлогинит.

**2. Разведка.** Взять из отчёта `docs/reports/ozon_lk_manual_reviews_2026-08-24.md` ссылку на
любой неотвеченный отзыв и подставить её:

    venv\Scripts\python recon.py --review-url "https://seller.ozon.ru/app/reviews?review_id=..."

Скрипт напечатает путь к папке отчёта. В ней: `recon.md` (жив ли профиль, селекторы, кнопки,
список внутренних запросов), `review.html` (вёрстка карточки для разбора офлайн), два скриншота.

**3. Прислать на сервер** `recon.md` и `review.html`. По ним собирается транспорт.

## Что важно не сломать

- **Профиль — не выкладывать никуда.** В `~/.ozon-lk-profile` лежит живая сессия ЛК: это те же
  права, что у вошедшего человека. В репозиторий не класть, в чат не выводить, никому не пересылать.
- **Не запускать в headless.** Скрыть браузер — самый быстрый способ получить блокировку.
- **Не эмулировать внутренние запросы ЛК.** Список запросов в отчёте нужен для понимания, а не для
  повторения: именно на этом ловили сессию в прошлый раз.

## Дальше (когда разведка пройдена)

Транспорт встраивается ровно в одно место — внутрь `send_ozon_review()` в
`collectors/feedback_send.py:185`. Модерация, суточные лимиты, dry-run, алерты и машинный запрет
публикации `reports/publish_gate.py` остаются сверху и покрывают путь через ЛК автоматически.
Первая очередь работ — 21 отзыв с готовыми ответами из отчёта от 24.08.2026.
