# Сбор отзывов в Ozon Seller

Для проверки нужен компьютер с Python 3.10+ и обычным доступом сотрудника в оба магазина. Распакуйте архив в постоянную личную папку. При первом входе проверьте соответствие: oz_acc1 — Цифровой квадрат, oz_acc2 — Дисквэр. В открывшемся браузере выберите магазин и раздел «Отзывы» со всеми отзывами, в терминале введите точное название выбранного магазина так, как оно видно на странице. Коды вводите только в Ozon.

**Windows.** Установите Яндекс Браузер для «Цифрового квадрата» и Microsoft Edge для «Дисквэра». Запустите Setup-Windows.cmd. Сборщик создаёт для каждого отдельный постоянный профиль, поэтому потребуется вход в Ozon. Если Яндекс Браузер установлен в нестандартной папке, переменная REV_YANDEX_BROWSER задаёт полный путь к browser.exe. После входа в оба профиля он дважды проверит сбор и затем создаст задание «Rev Ozon Reviews» каждые 15 минут для текущего пользователя. Если Python отсутствует, установите Python 3 с python.org вместе с Python Launcher. Для отключения удалите это задание в Планировщике заданий Windows.

**macOS (Google Chrome).** Запустите из терминала `bash Setup-macOS.command` в распакованной папке. После двух проверок появится пользовательский LaunchAgent с интервалом 15 минут. Компьютер должен быть включён.

**Linux или ручная проверка с Google Chrome.** Из распакованной папки:
```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python collect.py login oz_acc1
.venv/bin/python collect.py login oz_acc2
.venv/bin/python collect.py poll all
.venv/bin/python collect.py poll all
```
После успешных проверок добавьте в пользовательский crontab строку с вашими абсолютными путями:
```cron
*/15 * * * * "/полный/путь/.venv/bin/python" "/полный/путь/collect.py" poll all
```

**Результат.** Первая проверка показывает seen (прочитано) и new (новых ID). При повторе на том же списке new должно быть 0. История хранится в ~/.rev-ozon/reviews.sqlite3, состояние последней попытки и время по кабинету — в файлах oz_acc1.status и oz_acc2.status рядом. На Windows это папка .rev-ozon в профиле пользователя. Для повторного входа запустите collect.py login с именем одного кабинета. Не пересылайте папки profile.

Это пробная версия для видимой таблицы отзывов. Скрипт читает до 10 страниц за запуск, если видит кнопку следующей страницы. Виртуальная прокрутка и полнота архива требуют проверки в живом кабинете. «Обработан» сам по себе не считается подтверждением ответа продавца. При незнакомой разметке, запросе входа или пустом списке сбор возвращает ошибку и сохраняет прежние данные. При ошибке сообщите только код из .status.

**Передача в Rev.** Если на этом ПК уже настроен SSH-вход по ключу с доступом к серверному приёмнику, добавьте к poll параметр --ssh ВАШ_SSH_АЛИАС или задайте пользовательскую переменную REV_OZON_SSH. Передаются только записи отзывов. Приёмник сохраняет их в отдельной таблице rev_ozon_lk_review. Без SSH работает локальная проверка. Отправка ответов покупателям и уведомления в Telegram в этом пакете не включены.
