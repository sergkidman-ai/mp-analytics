# Расчёт короба: наборы, тай-брейк, цветовые серии

Процедуры вынесены из `CLAUDE.md` (K4, 2026-08-24). Инварианты потока — в `.claude/rules/gab.md`.
Базовый запрет действует всегда: **придумывать, оценивать и рассчитывать габариты коэффициентами,
медианами и ужимкой ЗАПРЕЩЕНО**; единственное исключение — короб набора как сумма РЕАЛЬНЫХ коробов.

## Наборы (правило 6)

6. **Наборы (2, 4, 5, 6, 8 и более картриджей):** короб = сумма реальных коробов одиночек с учётом
   укладки. **Перед массовым применением показать Сергею 3–5 примеров расчёта на согласование.**
   Одиночный короб на набор ставить ЗАПРЕЩЕНО (грубое занижение).

## Тай-брейк расхождений поставщиков (правило 9)

9. **Тай-брейк расхождений поставщиков.** Согласие = коробки различаются не больше чем **на 10% ИЛИ ±1,5 см
   по каждой стороне** (сравнивать отсортированные ДхШхВ — ориентация не важна). Из согласующихся РЕАЛЬНЫХ
   коробов брать **БОЛЬШИЙ** (безопаснее от штрафа за занижение при перемере ВБ). Ничего не вычислять — только
   выбор из реальных значений поставщиков. Если один источник подозрительно похож на **мастер-картон** (объём в
   разы больше остальных) — отбросить его; но если после отброса осталось **меньше двух источников** или конфликт
   не решается — в **ручной разбор** (`docs/gab_discrepancies.csv`). Медианы/усреднение запрещены (правило 1).

## Укладка наборов (правило 10)

10. **Укладка наборов (короб = сумма реальных коробов компонентов).** Диапазон кодов раскрывать ПОЛНОСТЬЮ
    (W2200X-W2203X = 4 кода CMYK, не 2 конца). Геометрия укладки: **2 шт** — стопка по меньшей стороне;
    **3 шт** — в ряд; **4 шт** — квадрат 2×2; **5–6** — 2×3; **8** — 2×4 или 2×2×2 (выбрать компактнее).
    **Смешанный набор (компоненты разного размера, вне допуска 10%/±1.5см) — решение Сергея 2026-07-24:**
    каждую ячейку укладки считать по габаритам САМОГО КРУПНОГО компонента набора (по объёму), затем обычная
    геометрия по числу штук (4 → 2×2). Линейное суммирование разных коробов в ряд больше НЕ применять.
    Расчёты наборов по этим правилам Сергей СОГЛАСОВАЛ 2026-07-24 (метку «не согласовано» снять); на WB всё равно
    ничего не отправлять — итог идёт в таблицу на проверку.

## Цветовая серия = набор (правило 11)

11. **Цветовая серия = набор.** Если в названии набора ОДИН код БЕЗ цветового суффикса (`Картриджи 069`,
    `067`, `82`) — это серия по цветам: раскрывать в набор всех цветовых вариантов кода (069 → 069BK+069C+069M+069Y).
    Фактический перечень цветов определять по `supplier_dims` (коды с суффиксами BK/C/M/Y и вариациями: K, LC, LM,
    PK, MK, GY…) И по нашим материнским карточкам этой серии — брать НАЙДЕННЫЙ перечень, не фиксированную четвёрку
    (у широкоформатных HP цветов больше). Если цветовые варианты не найдены нигде — в `docs/nabor_unclear.csv`.
