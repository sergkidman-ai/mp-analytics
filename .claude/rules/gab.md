# Габариты (поток `gab`) — железные правила

Причина строгости: за неправильные габариты маркетплейс перемеряет короб и штрафует —
синтетический размер = реальный денежный убыток. В июле-2026 в WB ушло ~2.4–3.1 тыс. карточек
с синтетикой (медиана по модели + пропорциональная ужимка), всё откачено на оригинал.

1. **ЗАПРЕЩЕНО придумывать, оценивать или рассчитывать габариты** — коэффициенты, медианы по модели,
   пропорциональная ужимка `k=(rv/cv)^⅓` и любые другие расчётные методы. Синтетические размеры
   недопустимы. Единственное исключение — короб НАБОРА как сумма реальных коробов одиночек (Skill
   `gab-box-calc`).
2. **У каждого габарита — явный ИСТОЧНИК:** конкретный поставщик из `supplier_dims`, ссылка на сайт
   производителя, либо правило наследования (п. 4). **Габарит без источника = габарита нет.**
3. **Профилайн — источник ТОЛЬКО веса.** Размеры от него не брать и короб под его литраж не достраивать
   (у profiline в `supplier_dims` 0 строк с ДхШхВ).
4. **Наследование родитель→ребёнок:** материнская карточка = картридж, артикул РОВНО 4 цифры; дочерние
   = карточки принтеров, первые 4 цифры совпадают. Дочерняя ВСЕГДА наследует габариты материнской.
   Для цветных серий принтерные карточки ВСЕГДА получают габариты **ЧЁРНОГО** картриджа.
5. **Не найдено в чистых источниках → «РАЗМЕР НЕ НАЙДЕН»**, позиция в отдельный список, ничего не
   додумывать. Чистые источники: `solutionsprint, изи, sakura, cactus, rapid`. profiline — не источник размеров.
6. **ЗАПРЕЩЕНО отправлять изменения на WB / Ozon / Яндекс без отдельной прямой команды Сергея.**
   Наличие данных ≠ разрешение на запись. Dry-run и подготовку — можно; запись — только по команде.
7. **Каждый отчёт → файл `docs/reports/NN_название.md`.** В чат — короткая сводка цифрами и путь
   к файлу; большие таблицы в консоль не печатать.
8. **Приоритет источников** (итог аудита 78 пересечений, 2026-07-26):
   1) короб поставщика из чистых источников (тай-брейк — Skill `gab-box-calc`);
   2) веб-размер упаковки ОРИГИНАЛА — только если поставщицкого нет ни у одного чистого поставщика,
      помечать источник `веб-оригинал`;
   3) ручной замер Сергея.
   - 241 CONFIRMED веб-размеров **не применять** к карточкам, где уже есть поставщицкий размер — там
     web только для СВЕРКИ (web-конфликт в 71/78 = «оригинал vs совместимка», а не ошибка мэтчинга).
   - `solutionsprint` = внутренние числовые коды, OEM не проверяется артикулом → для приоритета
     считать НЕ чистым; 25.5 % базы «Покрыто» держится только на нём.
   - Физически невозможный короб поставщика (объём картриджа не влезает, напр. 775 мл в 175 см³) =
     брак строки прайса, а НЕ повод менять наш OEM-код. Отбраковывать размер, код не трогать.

Тай-брейк расхождений, укладка наборов и цветовые серии — Skill **`gab-box-calc`**.
Живое состояние потока — `docs/BRIEF_GAB.md`; паспорт габаритов — `docs/HANDOFF.md`.
