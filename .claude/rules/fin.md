# Финансовый слой (поток `fin`)

**Территория.** `margin_by_sku` пишет ТОЛЬКО поток `fin`. Другой поток — read-only: вопрос
фиксируется в своём брифе, файл не правится.

## Себестоимость

- Источник правды по товарам и себестоимости — **МойСклад**; артикул — единый ключ МС↔площадки.
- Себест для анализа — из витрины `margin_by_sku` (ключ `article` = nm_id).
  Наивный джойн `external_code → cost_seb` **ЗАПРЕЩЁН** — дырявый путь.
- Себест конкретной отгрузки — `report/stock` на **ДАТУ отгрузки**, не усреднённый, не `buyPrice`.
- В отчёте МС `report/stock/byoperation` поле `quantity` = остаток на сегодня
  (`stock − reserve + inTransit`), а НЕ штуки документа. Штуки брать из позиций отгрузки.
- Цепочка поиска себеста по внешнему коду: отгрузка → родитель → универсальная модель → набор → ТК.
- Нет цены (`null` или `<= 0`) — значит нет в наличии и позиция **не считается вовсе**; вместо
  оценки идёт алерт. Оценочную себестоимость не подставлять.

## Сторно COGS возвратов (WB / Ozon / Яндекс — реализовано по всем трём)

- Сторнируется **ровно тот себест, что начислили при продаже** — по себесту САМОЙ отгрузки
  (мост «отправление → документ отгрузки МС», себест/шт = cogs отгрузки / штук отгрузки).
- Средняя по SKU за историю, FIFO товара, группа и ручной ввод — **только фолбэк** и только там,
  где моста к отгрузке нет; источник фолбэка обязан писаться в лог.
- **Месяц сторно НЕ выравниваем** (решение Сергея 14.08.2026): раздел «Себестоимость» снимает себест
  в месяце **ОТГРУЗКИ**, витрина и «Отчёты МП» — в месяце **ДЕНЕЖНОГО РЕВЕРСА**. Сумма за период
  одна и та же, различается только разбивка по месяцам. Вопрос закрыт, не возвращаться.
- Менять семантику сторно — только по согласованию с потоком `fin`.
